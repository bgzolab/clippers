## Windows 线

### 启蒙

我对于技术的接触，开始于一台家庭电脑。那时诺基亚手机还是主流，平板电脑的发明还远远未及。

那是一台 Windows
PC，白色的机箱外壳在岁月中泛黄。机箱前侧配备了软盘驱动器，不过我从未使用过软盘。搭配使用的是白色外壳的阴极射线管显示器以及(应该是 IBM 的)白色键鼠。

这台 PC 运行的是 Windows XP 操作系统。虽然蓝天白云绿色草地壁纸加蓝色默认主题是大多数人对 Windows XP
的标准记忆，但对于刚接触电脑的人来说可能并不满足于默认设定，而是执着于折腾没有性能加成但 (用现在的话讲) 能提供「情绪价值」的个性化设置。

在桌面上 `右键-属性` 便可以打开一个个性化的窗口，里面可以切换桌面壁纸以及各种任务栏和窗口标题栏的主题。

![](https://cdnfile.sspai.com/2025/12/18/e9b57f34c4b2ccb4108a9a7d6881e7cb.png?imageView2/2/w/1120/q/90/interlace/1/ignore-

我曾试过将主题换成银色(配合现代风/太空壁纸)、金色(配合秋季/落叶壁纸)、黑色(配合钢笔/信笺商务风壁纸)等等，每种主题都能给人带来一种不一样的氛围，虽说「科技以换壳为本」是一种无能调侃，但在那个年代就是有一种简单纯粹的「外观愉悦」。

而现在「液态玻璃」的设计褒贬不一，20 年来 UI 设计领域实在是千变万化。

除了更换主题，更换光标指针也是一大热衷点。我曾经在一段时间里更换过数种不同样式的指针，并乐于观察不同指针在系统无响应时的不同设计。

![](https://cdnfile.sspai.com/2025/12/18/8bd0674825cbfea43be5a8053f848525.png?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)宽带登陆窗口

电脑上网需要手动点击宽带上网
(虽然不知道当时的「宽带」有多宽但它确实叫「宽带」)，里面有预设并勾选记住的用户名和密码。等几分钟，当屏幕右下角任务栏系统托盘区域网络图标中两台屏幕交替闪烁时，你就跟世界握上手了。

几年后有了一台新的笔电，就用上了 Windows 7。尽管 OEM 厂商只是给到了家庭普通版，那 Aero 界面不论再怎么阉割都是对 Windows XP
设计的降维打击(当然得知 Windows 7 有一堆版本之后还是想办法用上了 Windows 7 旗舰版)。Windows 7
旗舰版近似玻璃加光线映射的窗口边框、些许透明的桌面小组件 (小小的心灵大大的震撼)，加上 DWM 令 Windows 7
无论是看起来还是用起来都明显上了一个新台阶。

### n 战 Windows 8/8.1

Windows 7 的普及其实离 Windows 8 的推出已不遥远。Windows 8 的 Metro 设计可谓脱胎换骨(甚至比扁平化设计的 iOS 7
早一年推出)，铺天盖地的广告宣传配合「**Oh… I wanna be… Everything at once** 」
那深入人心的音乐不出意外应该又是一个时代记忆点。

那时候大概是真年轻吧，对新事物的接受力挺强，这么新颖的系统必然是要装上试一试。当时的电脑普遍搭载光盘驱动器，所以我尝试刻录了一张光盘，里面包含了
Windows 8 的安装程序。

安装过程却是坎坷。首次尝试运行升级程序希望保留所有资料和个人设置，然而盯着那富有弹性的由五个点组成的加载圈辛勤转了半天之后却只是在桌面上留下了一份兼容性报告就草草退出了。再试了几次也是这样那样的问题。最后实在没法子了只能下狠心全新安装，数据卒
qAq。

![](https://cdnfile.sspai.com/2025/12/18/f9f3339cc64123ee404d2db9773b34e2.png?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)开始屏幕与动态磁贴

进入 Windows 8 之后全新的锁屏、富有创意的图片密码、动态磁贴、加入 Ribbon 菜单的资源管理器以及非线形动画表明这是微软既 Windows
Vista 之后又一大作，至少「俘获」了我的心。虽然市场不是很买账，Windows 8 被指责过度为触控设备优化、抛弃传统桌面体验等等，但支持 NVMe
协议、UEFI 启动等技术也切实为后续系统的技术迭代和革新打好了基础。当然微软为了回应市场回应用户呼声还是选择做出一些改变而不是教育用户，因此就引出了
Windows 8.1。

Windows 8.1 的定位是针对 Windows 8 的细节完善版本。它总体继承了 Windows 8 的设计理念，把桌面模式左下角在 Windows
8 上消失的开始按钮又重新加了回来。而且重点是 Windows 8.1 **免费升级** ！作为本就对 Windows 8 持有肯定态度的用户，我认为既然
Windows 8.1 是免费的那自然是要升级体验一番。然而不出意外大概又要出意外了(又要折腾了)。

Windows 8.1 的免费升级同大力推广 Windows 10 时期的免费升级政策有着明显的差异，并且有许多前置要求。Windows 8.1
免费升级仅面向已经安装了 Windows 8 的 PC，并且(似乎是)要求已有的 Windows 8 必须以 Retail
模式激活，此外仍有数条要求。只有在满足全部要求的 PC 上，用户才能够在微软应用商店的首页看到 Windows 8.1 免费升级的宣传入口。

![](https://cdnfile.sspai.com/2025/12/18/88ccad67dffb4141a662e5dbf70ced33.jpg?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)![](https://cdnfile.sspai.com/2025/12/18/7514a3e889b0c3ee080d6a8e8d8d3e99.jpg?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)

可是当时我所使用的电脑并非采用 Retail 模式激活，在遍览有限的教程和帖子并跟随操作之后，微软应用商店**依旧固执地** 不展示任何有关 Windows
8.1 升级的内容。甚至有一次我能看到「Windows
8.1」文字已经在半透明的层上显示出来，但无法点击操作。怦怦心跳下颤抖的手再次刷新页面，哀叹它还是消失在应用的信息流中。出于疲惫和无奈最终还是选择直截了当用系统镜像安装。为了吸取此前的教训，这一次我选择安装双系统以避免数据的丢失。

![](https://cdnfile.sspai.com/2025/12/18/7139a60e61160ae9153aa977f21ce774.png?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)![](https://cdnfile.sspai.com/2025/12/18/6913401edef74e9744e9a43ee7b21437.png?imageView2/2/w/1120/q/90/interlace/1/ignore-

装完 Windows 8.1 之后还是能感受到微软在一些细节设计上花时间做了优化，并且 Windows 8.1 也是首个将高分辨率屏幕渲染技术
(HiDPI) 完善的 Windows 系统 (2013，只比 Retina MacBook Pro 晚了一年)。

可惜好景不长，也许是因为当时的思维还停留在一个系统一个版本的阶段上，没想到微软已经逐步将 Windows 更新转向阶段更新和内容更新了(虽然现在人使用
Windows 10 或 Windows 11 之后已经习以为常了)。已有的 Windows 8.1 并不能正确处理那些更新。

加上双系统的模式给家人的使用带来了困难，Windows 又总是将自身的系统盘定为 C: 盘。结果就是 A 系统里的 E: 盘是 B 系统里的 C: 盘，B
系统里的 E: 盘是 A 系统里的 C: 盘。这种不确定性给用户带来了困惑，相比起 Unix 或类 Unix 系统有着清晰唯一的挂载点的设计，Windows
的盘符分配是有一定缺点的。在一次合并整理中家人把某个盘直接格式化了，数据卒 qAq (again)。

于是痛定思痛决定决定再全部从头开始，安装了一个完全没有接触过 KMS 或者什么 Volume 的干净 Windows
8。终于，微软应用商店的首页展现了期待已久的 Windows 8.1 免费升级的入口 ( 内心感动 泪流满面 T_T )。

事实证明通过微软应用商店升级的 Windows 8.1 在某些系统行为和设计上与先前安装的 Windows 8.1
存在明显的区别。而在这时候，Windows 10 Technical Preview (技术预览版) 也悄然问世了。

![](https://cdnfile.sspai.com/2025/12/18/21ae6615e8d5e7296fc440ab06520226.png?imageView2/2/w/1120/q/90/interlace/1/ignore-

### 从 Windows 10 技术预览版到弃坑

或许「领先一步是先驱，领先三步是先烈」，总之各方面优化后的 Windows 8.1
依旧未被市场和用户完全接受，微软就一改激进风格转而开始稳扎稳打着手打造下一代 Windows。

Windows 10
技术预览版初期所呈现效果想必已经能够令大部分用户接受：将原先全屏显示的开始屏幕缩小并恢复成菜单的形态，同时又保留了具备不断更新信息优点的动态磁贴。任务栏上则新增了搜索和**多任务**
的图标。说实话，多任务是抛开所有尝鲜情绪之后一个吸引我更新的重要因素，至于具体原因这里先按下不表。

乘上了 Windows 10 技术预览版的快车，就意味着开启了大约为期一年的快速更新与体验之旅(因为 Windows
技术预览版大多都内置「时间炸弹」)。大约每两周甚至更短就有一个或数个构建版本，不断变化的系统图标、逐渐完善的新界面以及整体 UI
风格的成熟持续地给人带来新鲜感，即便是普通用户也能从中感受到 Windows 10 在快速成长。

与此同时，有的软件变慢/崩溃、有的无法启动；有些构建整体稳定反应迅速、有些则运行迟缓、日常错误频出。作为用户有时候需要敏锐区分系统问题和软件问题，并判断什么是可以通过某些手段缓解的系统问题、什么是软件重装或更新能解决的非系统问题等等。这样的体验对于追求稳定的用户来说或许疯狂到难以想象，而这种「在变化中使用，在使用中变化」的新鲜体验一定程度上也促进了我解决问题能力的提升。

![](https://cdnfile.sspai.com/2025/12/18/c842e49418633c8ee4aed91a8693b78b.jpg?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)一张 Windows 10 技术预览版用户应该都熟悉的壁纸

在一众 Windows 10 技术预览版构建版本中，我认为有两个相对经典的版本值得一提。第一个版本是 Build
10041，早期预览版中的里程碑。Build 10041 大幅完善了众多界面与功能，使其同 Windows 8.1
在方方面面产生了明显的区分，也提升了系统整体的稳定性。据说如今广为人知的微软式翻译「**坐和放宽** 」就源自这个版本。

第二个版本是 Build 10125，后期预览版中的阶段性版本。Build 10125 总体上已经接近 Windows 10
的首个正式版本，并大幅提升了系统的稳定性，给饱经 bug 和崩溃折磨的用户一种已经用上正式版的错觉 (流下了感动的泪水……)。

用上 Windows 10 首个正式版本，大抵也是暗示 Windows
经历线接近尾声。不久后笔电原厂电源适配器不再工作，三方适配器也在某次冒烟出火星的事故报废。另一方面，笔电本身的配置过时，尤其是面对日益复杂的系统无力继续支撑的机械硬盘，是我另寻别路的因素。尽管后续我在其他
PC 上使用过 Windows 10 版本 1511、1607、创意者更新、秋季创意者更新、1803 以及 Windows
11，但那些都已是乏味经历不值一提。

也许您会好奇，为什么 Windows 10 版本 1803 后面就一跃至 Windows 11 了呢？单从 Windows 本身的因素而言，Windows
10 版本 1809 的翻车风波让大众用户对于 Windows 系统的质量信任加速瓦解，并进一步开始怀疑 Windows 10 Insider 的开发模式。

后续微软也并未采取强有力的行动扭转公众对于 Windows 的看法，这一情况一直维持至今。微软在 Windows 10
推出初期所构画的全平台大一统宏伟蓝图令人兴奋，但最终却沉没在时间的流逝中，UWP 应用也只是不温不火苟延残喘的存在。

## Android 线

### 每月刷机

您或许无法想象，我刷机的动力可能源于三星的「不作为」。2014 年 Google 正式推出 Android 5.0，代号 Lollipop
(棒棒糖)。Lollipop 在方方面面都有着不小的提升，包括十分亮眼的 Material Design
设计风格。还记得其系统彩蛋就是一个棒棒糖，并且还藏有一个时兴的类 Flappy Bird 的小游戏。

![](https://cdnfile.sspai.com/2025/12/18/cef2039e1d9d3a50bb17c72f1af5a88f.png?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)![](https://cdnfile.sspai.com/2025/12/18/7b0c8501818a42f3fac1e7e42a008d36.png?imageView2/2/w/1120/q/90/interlace/1/ignore-

error/1)![](https://cdnfile.sspai.com/2025/12/18/a31edf2cc499fe8ed262bc40e264da03.png?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)

然而那时候家里的三星 Galaxy Note 2 别说 Lollipop，就连 Android 4.4 Kitkat 都没吃上。三星那 TouchWiz
系统一直停留在 4.3 版本，在屏幕与 S Pen 之间透出一分老旧的气息。

望着 Lollipop 和 Material
Design，内心已经在幻想这一切呈现在自己手中的效果，要刷机的野心估计已经飞出地球之外。总之我实在无法按耐，决定为 Note 2 刷入其他系统。

当时正值刷机的朝阳时期，各种刷机软件和刷机论坛层出不穷。对比了不同方案，我选择了刷机精灵作为入门软件选项。刷机精灵提供了从刷机包分享下载到刷入
Recovery、刷写系统的全流程功能，可以说对新手是十分友好了。

而在刷机论坛中，XDA
论坛则是大名鼎鼎。刷机仿佛为手机打开了一扇崭新的大门，全新的开机动画、清爽的用户界面、流畅的系统动画无不证明刷机为手机焕发二春的正确性。

![](https://cdnfile.sspai.com/2025/12/18/ae01def4696fe1fd8ef49b88de9ce807.jpg?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)![](https://cdnfile.sspai.com/2025/12/18/5b20bbead5bacb72857538ac1fc2758b.JPG?imageView2/2/w/1120/q/90/interlace/1/ignore-
error/1)

得益于当时良好的社区环境和互联网精神，当时的 ROM (刷机包) 可谓是百花齐放，争相斗艳。有用户定制优化包、社区统一开发包，甚至有品牌方下场制作的
ROM，包括 MIUI、Flyme 等。

互联网三巨头也推出了自家的 ROM，分别是阿里 YunOS、百度云 OS 和腾讯
TOS。即便每次刷机需要清除用户数据，但由于当时的手机并不存储大量个人信息，因此我可以几乎毫无顾虑地根据个人喜好常常更换不同的 ROM
进行体验，最频繁时大约不到一个月一换。那一种刷机带来的新鲜感、兴奋感以及横向对比不同 UI/OS 交互的愉悦感应该是难有替代的。

当然在所有 ROM 中最富盛名的当属 CyanogenMod。CyanogenMod 是最为接近原生 Android 的 ROM，它充分保留了
Material Design 设计风格，是「原生党」的第一选择。当我首次刷入 CyanogenMod

那某些意义不明的板块分割、落后写实的图标以及不知道用什么颜色就直接上纯黑的背景，简直就是天壤之别。

## iOS 线

### 首次翻车

曾经家里人使用一台 iPhone 3GS。某一次，她抱怨微信无法安装。我一看提示，好嘛，iOS 过旧，请先升级
iOS。我一拍手心想「害，这还不简单，更新一下 iOS 就成」。当时的 iOS (应该是 iOS 3.x) 还不支持
OTA，于是啪的一下拿出数据线插上电脑打开 iTunes，很快啊！整个过程不带半点犹豫实在是一气呵成。

iTunes 也是通人性解人意啊，直接就自动弹出了可用 iOS
更新的提示。接下来就是常规流程，下载固件、解包、刷入。眼看着手机完成重启进到新系统欢迎界面，下一步、下一步，然后 iOS
就卡在「无法激活」了，死活进不了系统主界面。到这时候人一下子就懵了，心想完犊子了，难不成系统更新还能把手机给干坏了？尴尬地把成砖的 iPhone 3GS
还给家里人，只好给修手机的铺子送业绩去了。iPhone 3GS 的事就此告一段落。

### 越狱时光

之后玩起了家人换下的 iPhone 4。iPhone 4 的设计可以说是前无古人，双面玻璃加金属中框的三明治设计，不仅远远优于 iPhone 3GS
聚碳酸酯的曲面后壳，还影响了未来(至少十年)智能手机的结构设计。

当时 iOS 越狱是数码科技爱好者的一大话题。毕竟面对功能尚不完善但设计比较封闭的 iOS，越狱所能带来的新玩法新功能实在是数不胜数。正好盘古团队也已推出
iOS 7 完美越狱工具，一下子降低了越狱的门槛。有如此利好条件，我自然是不会放过。

现在人或许并不认识 saurik，但只要您在当时越狱过
iOS，那么您必然使用过他开发的软件——Cydia。我们知道越狱提高了用户的权限，可以安装一些越狱软件或插件。而 Cydia
是个软件包管理器，几乎所有越狱软件/插件都可以通过它来安装。

包管理器本身并不提供软件/插件，用户需要添加软件源才能让包管理器拉取服务器上托管的软件/插件。在一众软件源当中，我看到有一个软件源的名字叫
Ultrasn0w……

没有想到的是，岁月轮转，先前那台 iPhone 3GS 又有机会回到了我的桌上。而这一回我已知道它的真面目，一个曾经让我翻车的大坑。这是一台美版 AT&T

时下 iPhone 3GS 最高支持的版本已是 iOS 6.1.6，而手中这台实际运行的是 iOS 4.x。iOS 4.x 仍不支持 OTA
功能，也几乎不可能再运行 App Store 上的新软件。既然控制权已在我手，虽然已不可能穿越回去告诉以前的自己修正错误，但升级系统解开心结必然是一个
Tech guy 要做的事。

### 降级遗憾

与 iPhone 3GS 升级相对的，则是 iPhone 4 的降级。当时的 iOS 7 用焕然一新的设计打动了所有人，正好 iPhone 4
也在支持列表之中。可到了真正用上 iOS 7 时，iPhone 4 那孱弱的 A4
芯片是抗拒的，系统响应是迟缓的，用户体验是不能保证的。在时光的轮转中，当我有机会试图降级 iPhone 4 的 iOS 版本时，苹果早已关闭了验证服务器。

虽然苹果已经给官方降级判了死刑，但这并没有阻止第三方努力的脚步。爱思助手提供了不完美降级的选项，配合刷写固件后的越狱流程可以让 iPhone 4
正常进入系统。然而这一变通方式存在诸多的问题：iOS 会在熄屏状态下无故睡死(睡死后只能重新刷机，有越狱插件避免)；每次开机进入 DFU
循环，需要电脑软件引导正常启动(无解)。另一个叫 Odyssey 的三方 iOS 降级工具声称可以将已越狱并获取 shsh 文件的 iPhone 4
完美降级至 iOS 6.1.3，但在实操中获取 shsh 文件和降级的流程曲折坎坷、错误频出，终究未能抵达完美降级的彼岸。

## macOS 线

### Hacintosh (黑苹果)

对于数码科技爱好者来说，macOS 自然是绕不开的话题。我与 macOS 的交集开始得并不算晚。当时苹果的桌面系统还未改名 macOS，而是叫 OS X
(ten, 罗马数字「十」)。

Mac 弃用 PowerPC 芯片转而采用 Intel CPU 为 x86 PC 安装 OS X 提供了可能。于是在各大社区论坛的讨论中，Hacintosh
(黑苹果) 的概念映入眼帘。我首先将目光瞄准了搭载奔腾 CPU 和 ATI 显卡的笔电(就是首次使用 Windows 7
的那台)，系统则采用当时有名的黑苹果技术组 iATKOS 制作的 OS X Mountain Lion 镜像。

### 轻薄本新印象

用上 MacBook Air 之后，几个体验上的变化彻底刷新了我对于轻薄本这一品类的观点。**不是哥们儿，轻薄本也可以长续航？** 对的，兄弟，对的。在
MacBook 深陷于 Intel 14nm++++++ 的困境之前，MacBook (或许在同行衬托之下) 有着远超 PC
的续航表现。上文提到的奔腾笔电根本不能离开电源适配器 1 小时，而 MacBook Air 在 OS X 的优化下能在近似的使用场景中坚持 5~6 小时。

**轻薄本也可以做好扬声器音质？** 是的，你没听错。虽然 MacBook Air 的扬声器与 MacBook Pro
的无法匹敌，但在同类轻薄本产品当中却已经是领先的存在。

触控板则是 MacBook 的长期优势。尽管当时力度触控板还未问世，其磨砂的玻璃表面配合 OS X 多指触控手势支持，相比起阻力更大的非玻璃材质 PC
笔电触控板、单点触控以及几乎为零的 Windows 系统手势，MacBook 的触控板以极高的完成度、软硬件深度结合带来优异的用户体验，已经是
MacBook 培养用户黏性、形成技术护城河的重要一环。

在多指触控的支持下，OS X 可以实现跟手的系统动画。抛开最基础的滚动页面、移动、旋转手势支持，OS X 还实现了三指/四指手势功能。我最常用的分别是
Mission Control (调度中心)、打开启动台以及切换桌面/Space。

前文在 Windows 部分里提到，多任务是一个吸引我更新 Windows 10 技术预览版的重要因素。这是因为 Windows 10 引入了类似于
macOS 的多桌面多空间设计。而 macOS 的这一设计又是好评如潮、有效提升工作效率 (尤其是在打开许多窗口时) 的重要功能。

然而当真正用上 Windows 10 这一功能之后我是失望透顶的。当时的 PC 产品并未普及 Precision TouchPad
(高精度触控板)，实际上手体验直言不讳地说可以用「稀烂」来形容。尽管后续用上了搭载 Precision TouchPad 的
PC，不跟手的动画以及不注重细节的设计依旧劝退。

前文还提到「从 Windows 10 版本 1803 一举跳跃到 Windows 11」。除开 Windows 10
本身质量的下降、统一的生态未曾实现的客观事实，苹果产品更强的用户黏性、更佳的日常使用体验、更优的软硬件生态也是重要的因素。

但这并不是对 Windows PC 的全盘否定。Windows PC
在各行各业都有发挥重要的作用，我日常也需要用到。只是在结合个人实际需求、实际场景、实际体验之后，我倾向于使用 Mac
的时间更多一些。**选择电子设备，不求最好，只求最适合自己。**

### 新的观念

使用华为产品之后，我能感受到那颗折腾的心明显放缓了节奏，转而更适合深度技术的探索。我的认知似乎也发生了转变，大概有以下几点值得讨论：

  * **软硬件深度配合：** 除开 Mac 的使用经历，使用 EMUI 加自研的麒麟芯片令我进一步坚信软硬件深度配合的重要性。只有掌控硬件技术，辅以系统软件的配合，才能够真正创造「人无我有，人有我优」的体验壁垒，培养用户黏性。对于硬件制造商而言，这进一步提高了设备的附加值。
  * **品牌即服务：** 随着软硬件间的配合不断加深，用户选择的不再是一个单纯的设备或系统，而是一个品牌及其提供的所有软硬件服务。软件服务包括但不限于云服务、系统更新支持、系统安全补丁支持；硬件服务则包括售后服务、硬件技术支持等。理想情况下，厂商应该通过各类手段建设品牌形象，让用户从相信参数配置转向信任一个品牌。厂商不应该要求用户搞懂复杂的参数配置，而是让用户在购买的时候相信：即便某一品牌某一产品并非所有方面都是当下参数上的最强，但是整合起来的系统体验最佳。
  * **设备生态化：** 随着消费级个人电子数码品类的扩张，电脑、手机、平板、智能手表、耳机还有空间计算设备等品类层出不穷。与此同时随着时间的推移，存储于各类设备中的个人数据不断膨胀，跨设备数据使用的需求不断增长。这意味着各种设备已经不能够像以往那样以「孤岛」的形式独立工作，或是以电脑为中心的「单中心」模式工作，而是要采用多设备生态互联的方式协同工作。而多设备互联则可能要求以品牌为最小单位构建生态，这一生态将成为「品牌服务」的一部分。
  * **迁移成本：** 优秀的品牌服务、多设备协同工作为用户带来了绝佳的体验，生态护城河由此形成。在设备临近更新换代时，部分用户更倾向于沿用长期形成的使用习惯而继续选择同一品牌的迭代产品。这是因为这样做的迁移成本是最低的。

以下可能是体现迁移成本的几个方面：

  * 购机决策成本：(决策成本也是成本！只是大部分人不一定有意识去控制。) 当消费者准备购机时面对市场上丰富的产品选择时，ta 必然要做出一个选择。有的人喜欢看评测、横向对比配置、价格、性价比，那么看评测做比较所耗费的时间精力就是决策成本的一部分。而选择同一品牌的用户则只需要关注数量可控的迭代产品，大幅度降低了决策成本。
  * 数据迁移成本：当消费者购入新机之后往往会从旧设备迁移数据。同一品牌产品间的数据迁移通常有更高的完整性和更低的损失，同时可以利用已有的云服务。而跨品牌、跨平台间的数据迁移往往需要用户投入更多的时间精力来完成。
  * 习惯迁移成本：用户上手新设备必然存在一个熟悉的过程。同一品牌的系统交互、服务功能通常会有更高的一致性或连贯性，用户可以基本沿用已有的使用习惯上手新设备。而使用跨品牌、跨平台的设备则需要用户花费更长的时间精力掌握新的交互逻辑、功能选项等。

### 「养老」选择

基于上一节的内容，我在选择设备和使用设备的习惯上有了很大的变化，可以说「**之前有多折腾，后面就有多** 『**养老** 』****
」。简而言之新的策略就是**从个人需求出发选择软硬件深度配合的设备、选择具备良好服务的品牌、利用已有设备构建完整生态、降低迁移成本。** 在 Mac 和
iPad 的「召唤」下，老的 Mate 手机退居二线，我开始使用 iPhone。于是如今我的主要设备阵容是：

  * 某 iPhone (USB-C 接口)
  * 某 HUAWEI Mate 系列手机 (面向 Android 应用场景继续发光发热)
  * 某 MacBook (Apple 芯片)

其他 (低频使用的) 设备还有：

  * 装有 Ubuntu 的老 MacBook Air
  * 某 iPad (曾使用基于 qemu 技术跨架构模拟虚拟化 Ubuntu/Windows )

在我眼中，iPhone 至今仍然具备一些不可替代的特性，这里简单谈及两点。

首先是**钱包和 Apple Pay** 。相比起其他国产系统 Apple Pay 还支持非银联卡，相比起 Google Pay
则支持银联卡且对网络环境没有任何要求。

在交通卡方面， Apple Pay 不仅支持各地区的交通联合卡，还支持八达通、Suica 等。八达通、Suica
不仅可以用于公共交通场景，还可以当作零钱袋用于支付场景，且市场覆盖率极高。2025
年五一期间落马洲站发生的事件有力地证明了在最不利的情况下，需要联网的在线支付/刷码方式稳定性依旧不敌离线的八达通「钱包」。华为早些年推出的手机官方支持八达通卡，然而近两年发布的新机却不再支持，实在可惜。

Android 版的新八达通虽然在机型上没有太多限制，但是其卡片类型 (NFC Type-A) 仅支持有限的新刷卡机，并且需要配合 Google Pay
使用。Suica 则有效地将旅客从使用现金购买各种繁琐车票的程序中解放出来。然而 Suica 在 iPhone 以外仅有当地销售的小部分 Android
手机支持，尽管美版 Google Pixel 在硬件上具备支持这一功能的潜力，Google 官方在软件上却并未实现。与此同时 iPhone
钱包中的交通卡开卡、充值、使用的流程全部在钱包中完成，无需下载对应程序，大大降低了学习使用的成本。

其次是**第一方应用，包括地图、iMessage** 等。苹果地图以简洁易用、干净无广告、国内外信息兼而有之等特点著称；iMessage
则是简洁高效，几乎没有信息推送延迟的毛病。

### 弥补遗憾

尽管开启了「养老」模式，但我也并没有忘记未能完美降级的 iPhone 4。在被扁平化/类扁平化设计统治十多年产生视觉疲劳的当下，iOS 6
的拟物化设计反而变得眉清目秀起来。幸运的是，属于 iPhone 4 降级「天时地利人和」的时刻已经到来。开源工具 Pluvia 可以利用 iOS 7 固件的
BootROM 为 iOS 6 的固件打上补丁，从而能够将 iPhone 4 完美降级至 iOS 6.1.3，弥补了我以前折腾时期留下的 (可能是)
最后一个遗憾。
