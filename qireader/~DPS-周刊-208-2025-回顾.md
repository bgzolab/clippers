转眼到了写年终总结的时候了。自从 Covid 以来，总觉得时间变得非常模糊，一下子五年过去了，中间明明发生了很多，又好像什么都没发生过。

回看2025年，似乎也是同样的感觉，好像发生了很多，又似乎没发生什么。转瞬之间，一年就这么过去了。

今年最开心的事，就是重新恋爱了，重新进入一段稳定的亲密关系。距离上一段亲密关系已经过去了很久，这中间也陆陆续续见了不少人。直到这回，我才体会到舒服的关系是什么样的。

比如她是一个极其爱干净的人，但她从来没有要求我和她一样追求干净。从我的角度而言，既然她这么爱干净，那我也做出一些改变，像她一样变得爱干净。在家做饭的时候，也就不需要分工谁做饭谁洗碗，一般就是谁想做就做，谁想洗就洗。

我想一段稳定的关系其实是一种动态的关系，就是只有不断变好的关系，才会变得越来越稳定。非常幸运的是，我进入了这样一段关系。也许是因为非母语的关系，感觉我在这段关系中给出了更多的积极肯定，当然我也收获了很多的积极反馈。这样一种正向循环也让我们的关系越来越好。

回头一看，2025年最幸运的事就是遇见这个对的人。

这一年回了五次家，二月，四月，九月，十月，十一月各一次。比前几年都多。主要是觉得父母年纪大了，更需要我的关心。

九月回去的时候，母亲说，有一套房子有三拨人来看，但报价很低，她不愿意卖。我一听三个报价都类似，就劝她赶紧脱手了，不然拖下去更卖不了。劝说了一番之后，她终于同意卖房。于是赶紧陪她处理了这套房子。尽管中间有些小插曲，总体还算顺利。

去年下半年的时候，母亲突然说有一套房子租出去了，签了五年的代租合同，五年房租一分不涨。我一听就觉得有很多猫腻。果然半年不到，这个代租中介就开始拖欠房租。当然母亲也自有一手，直接停了天然气，第二天这个中介就乖乖把房租补上了。可是这也是噩梦的开始，从此之后，每次都会拖欠房租，每次都需要父母反复催促才会交上房租。九月回家的时候，我得知这一情况，就劝说父母把房子收回来，赶紧卖了。本来想着毁约，结果我查到中介的公司已经注销，注销过程中也没有与我们沟通续租，于是咨询了律师朋友之后，决定直接知会对方合同已经执行解除。

这位朋友给了详细的方案，还起草了解除通知书。本来很简单的事，只要按照专业建议执行即可。结果母亲每一步都不放心，都要按照她的想法画蛇添足。我最担心的倒不是房子收不回来，而是把对方和母亲有直接接触会产生意外，所以极力避免他们的直接接触。最后不得已，我十月又飞回去一趟，才把整件事搞定。后面倒是出奇的顺利：微信通知对方自动解除合约之后，收到回复，随即拉黑对方的手机和短信之后，然后通知租客办理，最后停水停电停气。中介无奈之后灰溜溜地把家具拉走，又把自己装的空调拆了。自此把房子彻底收了回来。

十一月又回了一次家，其实主要是去公司提离职。在这家公司呆了两年半，从零开始进入一个完全不同的领域。当初给自己定的目标就是，如果不写代码的话，能不能在一个不同的领域把事情做成。回头来看，这个目标实现得还算顺利：第一年很快把第一个市场的电商渠道打通，然后做到畅销商家；第二年全力准备第二个市场，从零尝试不同的玩法，也顺利把货铺了上去。

不过今年并不是很顺利，老板的意思也让我把手上的一部分业务分出去。正好五月的时候拿 Gemini 开始了 vibe
coding，顿时觉得自己还是应该回去写代码。尝试了几个月用不同的工具进行 agentic
coding，我被当下的工具惊艳到。这种体验像是从现金支付直接跳到了移动支付，完全忽略了中间的信用卡支付（即 copilot coding）。

五月的时候拿 Gemini
把每周的销售财务统计工具写了出来，尽管很粗糙，但是比起手动录入省去了很多麻烦。原先每周都要做的周报，需要从四个销售平台把数据汇总，有
PDF，有后台数据，非常细碎。有了汇总工具之后，省去了很多手工活。

六七月开始使用 Cursor + Claude 写了一个小项目，确实被这两个工具惊艳到。作为写 NLP 出身的我，对后端略懂皮毛，对前端一窍不通。有了这些
agentic coding 工具之后，大大降低了学习成本，我也能连滚带爬地写出一个完整的前后端项目。而且最麻烦的部署也能拿这些工具顺利完成，轻松了很多。

八九月的时候，接了朋友的一个需求，要写一个更大的项目，用上面这两个工具也写出了
MVP，尽管最后没上线，但是我确实学到了很多。也对如何使用这些工具有了更多的理解。十月初提出离职，于是和另外一位朋友讨论一起在2026年一起倒腾一个项目。拿
ChatGPT 和 Gemini 的 deep search 做了好些研究之后，最终确定了我们两人都感兴趣，而且目前有些竞争但还不多的方向。

十月底正式动工，有了前面积攒的经验之后，这回用起 Cursor + Claude 就得心应手很多，当然过去几个月这些工具也成长迅速。比如两者的 plan
mode 可以给出详尽的执行方案，Opus 4.5 出来之后，不仅代码质量更高，而且耗费的 tokens
也少了很多，如果单线程跑任务，几乎不会碰到使用上线。一个月出点头，我们就有了一个完整的 MVP，而且有一个质量颇高的 landing
page。选用的技术栈是 fastAPI + Reflex + Supabase + Astro。除了 Reflex
有些磨合的成本，其他三块用上述两个工具都顺利。

对于台积电创始人张忠谋的采访，里面提到《张忠谋自传》下册也已经出版了。于是我迅速找来上下两册通读了一番，收获颇大。 读着读着，我突然意识到 AWS

的客户不需要投资硬件，只要专心写代码就行，写好的代码部署到 AWS
的云资源上就能跑起来。而之前开一家软件公司是需要自己买服务器，这笔硬件投入非常大，这和之前的芯片公司需要大笔投资建设芯片厂一样。
因此，台积电在1987年的成立，可以说是重写了半导体的游戏规则，使得很多人都可以进入这个产业。它一口气创造了两个工业：第一个是晶圆代工业，第二个是无晶圆厂设计业。
这不就是台积电开创的晶元代工模式吗？无晶元公司都不需要自己投资建厂，只要交给台积电代工即可。有了 AWS
之类的云计算，软件公司都不要自己大笔投资建设机房，只要专心写代码做产品即可。
因此专业代工的出现，不仅大幅提升了晶圆代工的品质，也大幅增加晶圆代工的可依赖度。

周刊 182 - 与老朋友们之间的对话这回在美西旅行，见到了很多老朋友，多是认识了十年，甚至二十年以上的老朋友，所以重新见面之后，有了很多有意思的深度对话。
1. 做个人项目时，传递价值给用户和获得别人的认同并不一定冲突：给用户产生价值是每一个 maker 的目标，同时每一个 maker
也需要别人的认可来激励自己，保持动力。有的 maker 追求给用户带去价值，有的 maker 追求让自己获得他人的认可。这两者并不矛盾，因为 maker
创造的价值并不一定是用户认可的价值，同理，maker 追求的外在认同，也不一定和用户给予的认同保持一致。所以对于 maker
最重要的并不是目标是什么，而在于过程。只要努力了，经历了，最终的结果只是一个副产品。 2.
别人的认同与我们需要的认可并不一定是一致的：当我们做一件事时，我们可能期待别人会给予某种认可，但这种期许也许和别人的真正的认可并不一致。所以我们在开始做一件事时，不需要对别人的认可有太高的期许，只要我们能给他人带去价值，就一定会获得认可，这些认可也许和我们的期许完全不一样，也需会带我们很大的惊喜。

周刊 183 - 美西旅行小记一晃二十天过去了，梦幻般的美西之旅结束了。
我妈问我有什么感受？我说如果早几年成行，我可能早就搬去美国了。因为还是美国的创业土壤最好。 这回在美国，先在 LA 呆了四天，中间参展 CES
的一周，然后逛了 Death Velley 和 Yosemite 两个国家公园，最后又在三番呆了五天。
见到了不少老朋友，有朋友还特地从温哥华飞过来相聚，实在是非常感动。在三番的时候，在一个朋友家睡沙发，旁观他作为一个 startup founder
的工作生活作息，基本上除了吃饭睡觉，就是在工作。 逛国家公园的时候和一个朋友朝夕相处，到三番之后，另一个朋友带我转了城区和伯克利，最后一天又被那个
founder 朋友带着玩了一天，所以有了很多有意思的深度对话。 最后两天在三番和LA
亲眼目睹了砸车撬车抢车（三起独立事件），令我目瞪口呆。也算是让我领略了美国的真实一面。
