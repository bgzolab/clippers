## Google 推出 Fitbit Edge

10 月 12 日，Google 推出 Fitbit Edge 健身手环。产品定位介于 Fitbit Air 与 Pixel Watch 之间。Fitbit
Edge 外壳由 100% 回收铝制成，配硅胶或不锈钢表带，本体重 17.7g。屏幕为 1.34 英寸 AMOLED，手环使用 Ambiq AP5
MCU，支持蓝牙 5.4，电池 65mAh，续航可达七天。内置 64MB 存储，可储存 7
天分钟尺度的详细运动数据。配备血氧、心电、PPG、温度等传感器。有橄榄绿、黑曜石、迷雾蓝、峡谷红四色，售价 179.99 美元，另有库里联名款黑麦色，售价
219.99 美元。[来源](https://store.google.com/us/product/google_fitbit_edge?hl=en-
US)

## 微软扩大 Azure Maia 部署规模

10 月 12 日，微软宣布将从 2027 年起把自研 Azure Maia AI 系统的部署规模扩大至数吉瓦，使其成为微软产品与服务的主要推理平台。第三代
Maia 300 将于 2027 年开始生产部署，主要面向长上下文推理、低延迟对话及持续执行的多步骤智能体任务。微软预计 Maia 300 每兆瓦可处理的
token 数量将比领先的 GPU 系统高出 40%；配备 96 个加速器的完整机架，其 token 吞吐量最高可达 Maia 200 的 7
倍。系统采用多芯粒设计，计算芯粒使用台积电 N2P 工艺；单个加速器配备八组 HBM4，峰值内存带宽为 18 TB/s，热设计功耗为 950 瓦。

目前 Maia 200 已投入生产，支持 Microsoft Copilot，并运行 OpenAI、微软 MAI
及主流开源模型。微软计划在今年年底前将其用于 GitHub Copilot 和 Microsoft
Foundry，目前正向美国、欧洲及澳大利亚扩展部署。[来源](https://blogs.microsoft.com/blog/2026/10/12/microsoft-
to-expand-azure-maia-system-to-multi-gigawatt-deployments/)

## 基于 Android 17 的 LineageOS 24.0 发布，并推出网页刷机工具

LineageOS 项目于 10 月 11 日发布第 32 期更新日志，公布基于 Android 17 的 LineageOS 24.0
正式版，项目团队表示，24.0 版已经达到与 23.2
版相当的功能和稳定性水平，首批支持设备将陆续获得官方构建，后续还会根据维护者准备情况增加更多机型。目前新版本已经将 2025 年 8 月到 2026 年
10 月的安全补丁合并到 18.1 到 24.0 分支。此外还同步推出了网页端刷机工具 Lineage Flash Tools，用户无需在电脑上单独安装
ADB 和 Fastboot 工具，即可通过浏览器与兼容设备通信。该工具提供 ADB、Fastboot、三星 Odin 和 Amlogic Burn
四种模式，分别面向不同设备和刷机协议。该工具基于 WebUSB 协议，因此用户使用的浏览器也需要支持 WebUSB，例如 Google
Chrome。Windows 设备可能需要安装额外的 USB 驱动程序，Linux 则可能需要配置 udev 规则。LineageOS
团队称，网页工具是基于现有安装流程外的补充选项，具体操作仍然以对应机型的官方文档为准。[来源](https://lineageos.org/Changelog-32/)

## Meta 推出 Muse Wonder 模型

Meta 10 月 12 日发布面向智能体任务的 Muse Wonder 和 Muse Wonder Full 模型。两款模型基于 Muse Spark
的技术基础，强化个人与专业场景中的任务处理能力，包括梳理保险理赔、理解租约、分析财务信息，以及编写游戏和应用程序，且达到领先水平。新模型加入 Active
Memory 和 Active Focus，用于跨对话保留并调用与当前任务相关的信息、持续推进复杂任务、尝试其他方法及从错误中恢复。Muse Wonder
已通过 Meta Model API 和 Muse Code 向开发者开放，Muse Wonder Full 面向 Muse Code
订阅用户提供。Muse Wonder 还将用于个人 AI 智能体
Muse，优先向订阅用户推出。[来源](https://about.fb.com/news/2026/10/introducing-muse-wonder-
models/)
