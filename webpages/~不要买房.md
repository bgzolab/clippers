# 不要买房

这可能是最难驾驭的资产

1. 一手房可能存在延迟交付甚至烂尾风险
2. 房屋质量若出现问题,无法保证妥善处置
3. 邻里是谁不受控,若出现恶邻,影响出租出售
4. 众所周知的原因,目前出租困难,除了中心地段,商业地产更难
5. 出租后大小事你需要亲历亲为,国内中介基本不管出租后的事
6. 出租收益极低,很多地方 100 年不回本
7. 房屋耗损,设备折旧,各种维修费用会让你怀疑人生,碰到房客出意外你可能担责
8. 厌烦了出租?你还真不一定卖得出去
9. 可能存在的持有税和近期传说的房屋养老金
10. 原来房屋楼层少,拆迁能带来大收益,但现在普遍高楼层,未来基本拆不动,一旦房屋老化,没人买也搬不走
11. 人口基数趋势大家心知肚明,靠买卖赚钱不切实际了
12. 最重要的,你如果是一个有工作的人,愿意打拼的人,你哪里会有这些时间和心思去打理出租出售中的各种糟心事

有钱别买房,真的不划算,找点其他途径跑赢存款利息吧 资产最重要的属性就是流动性,没有流动性,就会有难以计算的机会成本

什么?首套房刚需? 你确定你一辈子在一个城市? 你确定不会因为离婚导致资产分割? 你确定哪天你不会有国外就业甚至 RUN 的机会?

租房吧亲,每年换个新鲜的街道,还不怕邻居吵闹,房子漏水了直接退,换工作也不怕长距离通勤 何苦自己给自己一个紧箍咒呢
