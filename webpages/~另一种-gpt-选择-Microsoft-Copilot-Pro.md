# 另一种 gpt 选择 Microsoft Copilot Pro

> Microsoft 发布了面向个人用户的付费 Copilot
它的名字叫做「 Copilot Pro 」
优势包括
· 优先访问 GPT-4 Turbo
· 能在 Microsoft 365 应用中使用 Copilot
· 没有 chatgpt 中 40 条/3 小时的限制

目前美区 20 美元/月和 chatgpt 定价相同，日区 3200 円/月比美区贵了一些（相当于人民币 160 块钱）

各位会选择哪个呢，如果改用 Copilot Pro 后还可以拼车吗，有大佬使用了说一下使用感受吗
