# 对安卓生态失望了

如果你从前没接触过安卓社区，你可能会尝试用 Linux 社区类比，但这就大错特错了。相比 Linux 社区的繁荣活力，安卓社区简直就是一潭死水。  
  
首先就是开源相关。按照许可证，理论上，所有基于 Linux 内核的软件都必须开源，然而开源许可证在中国就是废纸一张。别说设备树和驱动了，曾经最受所谓玩机党喜爱的小米，内核装模作样开源，包括fs在内的许多关键文件不翼而飞，无法编译。  
  
不光内核，安卓工具软件生态也烂完了。除了主流的 root 管理器，大部分工具都不是开源的，甚至是收费的，比如众所周知地mt管理器的、性能相关软件 scene、乃至许多模块等等。我就不由产生疑惑：安卓社区的都没用过电脑吗？个人开发者通过网盘分发的闭源收费软件，你们是怎么敢给 root 权限的？  
  
说到这里，就不得不提当前安卓社区的根基了。安卓玩机基于 root，而 root 又基于解锁。实际上，不光国产手机，许多国际品牌也在逐步收紧甚至禁止 bootloader 解锁，这也使得目前的解锁均来源于漏洞利用，就比如小米骁龙最近的漏洞链解锁：SELinux 宽容漏洞、澎湃os提权漏洞，加上骁龙的 UEFI 任意程序不签名加载漏洞，除了最初的实现文件被人放在 GitHub上，而其他机型的类似原理漏洞往往是只分发、不开源的。这也造就了安卓圈子崇拜某几个开发者，发文件就舔、不发文件就骂的奇特景象。  
  
这种基于闭源的极客风味社区环境注定是畸形的。有资源的人可以自由圈钱，不懂技术的人盲目跟风，别有用心者制作病毒文件、格式化手机文件，毕竟大家都不开源，趁机扩散闭源恶意文件也完全不会经过社区审查，一杀一大片。正可谓是群贤毕至、少长咸集，安卓大舞台，有机你就来。  
  
当然，在不违反任何许可证的前提下，对于是否开源自己的程序，开发者说了算，这一点我是坚决资瓷的。但是作为一个随时都在利用 root 权限、本质上与 Linux 极客社区应该联系紧密的社区，实际上却是一个只懂 gui 的小白遍地走、圈钱贩子大挣特挣、闭源收费程序横行的社区。优秀的贡献颇多的开源开发者，撑起了底层 root 体系的运转基础和内核适配的开发者却在角落，最常收到的反馈是催更和谩骂的畸形扭曲社区。恶意文件、root 执行、高价救砖的一条龙难绷邪恶产业链愈发发达，已经实际上将社区扭曲到零信任状态了——当你拿到一个新的社区程序，你必须默认它是个格机程序。  
  
安卓真的低人一档吗？我不知道。但涉足安卓社区的这几个月，我深刻感受到了什么叫安卓逻辑、安卓思维、安卓社区。说实话，写这么多我也不是想批判什么、改变什么，只是分享一下站在一个喜欢 Linux 社区互帮互助、无私开源的充斥着互联网精神氛围的爱好者立场，出于好奇半步踏入安卓社区，又巴不得立刻逃离的主观感受。我唯一能做的，也就是给开源项目加点代码、点个星星，然后下一部手机买苹果了。
