title: 过来人提醒：谨慎开启 FindMy 功能
type: archive-web
---

2017 年送老婆的 iPhone7p ，如今淘汰了，我拿来当备用机用，并用 gmail 邮箱注册了一个新的 apple id 使用，平时很少开机。

大概 1 个月后，上周开机用一会就收到提示登录要输入 icloud ，输密码后提示账户已停用，赶紧上 account.apple.com 发现 id 已经登不上，提示账户已被锁，按页面提示发邮件申请解锁，苹果返回邮件“我们已审核并拒绝访问账户的请求。”

一个没怎么用的 apple id 怎么就被锁了呢？此时想到要退掉手机 icloud 上的 apple id ，但退 id 也被要求输入密码，输入密码又提示账户已停用，死循环。

求助苹果人工客服，客服说无法解锁，这个 apple id 已经永远无法恢复，而因为手机开启了 FindMyPhone ，退 icloud 必须校验密码。也就是说这台手机已经无法换 apple id 了，如果重置手机就无法进入系统。但客服还是给了我一个解决方案：只要我找回买手机的票据，证明手机是我自己的，就能申请后台解绑。但我确实没办法找回 8 年前的单据，当年在香港丰泽买的…

经过这个事情，对苹果产品忽然感觉到畏惧：封 id 可以不给理由不给解封就算了，但封 id 还可能导致影响手机硬件正常使用，就很难接受。虽然 iPhone7p 已经是不值钱的老机器，但好歹也是自己正当渠道掏钱购买的商品。

自己还有一台 mac air 老笔记本，几台老 iPhone ，是用的另一个 apple id ，吓得我赶紧逐个打开关闭 FindMyPhone 和 FindMyMac 功能。
