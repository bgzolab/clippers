坐标福州，在二几年的时候突然启用了"白名单"，如果域名未备案，且域名解析的是境外 IP 地址，则福州运营商网络均无法访问该域名，这样子就不能用域名伪装了，只有明文 IP 能访问，但是明文 IP 有风险，很容易被 GFW 检查到并且直接封禁 IP ，请问各位大佬有什么比较好的绕行方案？还是说只能买中转机？
