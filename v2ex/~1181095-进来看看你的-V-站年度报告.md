之前开发的插件 V2EX Stats 新增了年度报告功能，安装插件后首页会显示年度报告按钮，只做了简单的分析和归类大家看个乐子。

插件代码公开在 github ，不会共享数据~

仓库和下载链接如下：

- Chrome Web Store: [V2EX Stats]( https://chromewebstore.google.com/detail/kclaclglgljalkhaihmicdlcnaacpghp?utm_source=v2ex-v3)
- Firefox addon: [V2EX Stats]( https://addons.mozilla.org/zh-CN/firefox/addon/v2ex-stats/)
- Github release: [V2EX Stats v3.1.1]( https://github.com/geebos/v2ex-stats/releases/tag/v3.1.1)
- Github 仓库： [https://github.com/geebos/v2ex-stats]( https://github.com/geebos/v2ex-stats)
