# 简介
一年前做了[AI 图像判官]( https://v2ex.com/t/1007533)，最近刷小红书得到类似的灵感做了一个 AI 文字判官： https://text.yyhutil.com/

这次没有做花花绕绕的交互，访问者将会直接看到一篇段落，并判断这个段落是由 AI 生成的段落还是作家撰写的段落，也没有限制答题的次数，用户可以在任何时间看到自己的统计数据，我也做了优化保证答题者在一定次数内并不会遇到重复的段落

# 数据来源
这次的数据来源比较杂，分为以下几块
- 名家的散文集节选
- 2020 年以前的报纸报导节选
- 2024 年以前的高分高考作文

AI 方面
- 给定主题和写作风格，不同的模型仿写的散文段落
- 给定高考作文提目，不同模型生成的高考作文
- 给定细纲，不同模型仿写的微型小说

# 技术栈

- 前端：Bolt.new 出设计草图，Cursor+React 后期修改
- 后端：Nest.js ，配合 Swagger 生成 OpenAPI JSON ，喂给 Cursor 出 API Client
- 数据库：Prisma + Postgres ，Neonbase 的免费方案
