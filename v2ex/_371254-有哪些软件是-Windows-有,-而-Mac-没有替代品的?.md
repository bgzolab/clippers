我列举几个没有替代品的:
1. Everything 对文件名的秒搜, 是 spotlight 完全无法比拟的
2. TotalCommander 和 Directory Opus 的强大, Mac 上没有同级别工具可以替代
3. Listary 在任意地方, 任意文件夹内呼起搜索框, 这个 Mac 急需
4. VS 2017, 宇宙第一强大的 IDE, Mac 下的 Xcode 离强大还差得远
5. Office 系列, Mac 上的 Office 渣得不要不要的
6. 一大堆游戏, 包括 Steam 上不支持 Mac 的.
7. 一些行业软件, 比如 CAD,工控等


其他大家还有补充吗? Windows 上特别好用, 而 Mac 下没有替代的?
