# LLMs

LLM 中间文件不应该提交到项目，但也不应该删除，因此这个仓库诞生了，任何不希望提交到项目中的中间文件都应该放在这里，比如：

1. 项目实施计划，用完即弃，长期记忆看 Memories;
2. 会话记录(Session)，跨设备记忆不完整，应该得到保存;

## HOW 

1. 本项目永远不会开源，也不应该开源，这是项目的初衷，任何开源的行径都应该把该项目的文件删除；
2. 所有文件命名应该以 `YYYYDDMM_feature|session|bug_xxx` 开头，因为 Git 管理的文件创建时间不准确;
3. [ ] 提供脚本命令，当一个 SESSION、实施计划没有用的时候，执行命令可以自动提交到改仓库；
