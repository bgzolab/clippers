## Review

#Review 看了一遍，内容大概偏基础，基本面向的是小白，从 GitHub 介绍开始，介绍 Copilot，介绍补全案例，结合了 C\#,Python，JS 和游戏开发。可能对我最有用的是 进阶篇，有几个没见过的用法：

1. 斜杠命令，我发现我一直没有用过，他可以生成测试和文档
2. `@workspace` 允许 Copilot 扫描所有代码库，以回答诸如：寻找代码片段、添加新功能等问题。等等。

然后没了。最有意思的是这句话：

> 這應該會給你另一個解決方案。繼續嘗試，直到達到所需結果。

这不正是我一直做的吗？似乎这篇教程并没有给出我们捷径
