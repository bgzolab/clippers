# 派遣战斗员！

　　晓なつめ翘首以盼的新系列漫画化！秘密结社如月的世界征服触手可及之时，主人公·战斗员六号做了奢侈度过余生的美梦。然而……上司 A「下次派你到行星」→六号「不是吧？」——不幸角色们所编织的新世界侵略战斗喜剧！！存在一个打倒众多英雄，世界征服近在眼前的名为恶之秘密结社如如月的公司。

　　其公司的干部们为了进一步实现侵略，作为先锋派遣了战斗员六号（主人公）和其伙伴人工智能去了其他行星。然而，战斗员六号不仅把侵略地的祭神仪式的名称改为「小丁丁 0 祭」，更是情不自禁地揉玩了队友的胸部。笨蛋人渣的行径极其显眼。是物以类聚吗，前来汇合的新成员也是吃货合成兽和**司教等货色，恶性瞩目度有增无减……

　　此时大肆扰乱侵略地，自称魔王军的同行发起了进攻。这个消息传到了在大街上行痴汉行为，积累恶徳之中的主人公的耳中——

　　「世上不需要两个邪恶组织！」战斗员六号终于发挥本领！？运用和变态女主角们锤炼的鬼畜战术侵略新世界！
