# VenusBlood -FRONTIER-

今回のコンセプトは、以前から軽く触れていた通り。

正統なる女神悪堕ちシリーズ第３弾であり、そして前作ＶＢＡで好評だった部分を継承した

いわばＶＢＥとＶＢＡのハイブリッド＆パワーアップ作品を目指しています！

企画の進行自体は、今年の４月くらいからぼちぼち

進めてましたが、今回は立ち絵の数がハンパないので、

ＣＧのスケジュールを圧縮するためにも、ＶＢシリーズでは初の試み、外注の原画家さんを起用することにしました。

内部スタッフのデザインも、今までの１．５倍くらい時間かけてクオリティアップに励んでいますので、ぜひご期待ください。

また、兼ねてからの懸案事項であった、システム周りの強化も、今回から少しずつ実行に移していこうと思い

天ツ風の時に、カードバトル戦闘の画像処理関連のシステム設計をやってもらっていた tomsan においで頂きました。

あと、機械仕掛けのイヴの時にスクリプトなどのヘルプしてもらってた、懐かしのミスターＮ氏を社内に迎え入れました。

「……誰？」と思う方には、独自判断で九音エンドロールの演出をつけた、

九音に対する深い愛のあるスタッフ、といえば、親近感も沸くやもしれません……。

あ、あと話は変わりますが、ナインテイル社屋の引越しが決まりました。

新社屋向きの物件を探すことおよそ半年、ようやく良い物件を見つけることができ、

ＶＢＡの売り上げが好調なのもあって、ついに引越しが出来ます。ありがたやありがたや。

こうして色々なところに予算をきることが出来るのも、

ＶＢシリーズが新作を重ねるごとに売り上げが上向いているという結果のお陰です。本当にありがとうございます。

２０１２年３月は、他社様も本当に面白そうなソフトが多数発売予定で、

尻込みするばかりですが、ウチはウチなりの流儀で、お客様を満足させられるよう努力する次第です。

結果はその後についてくるでしょう……。ＶＢシリーズは、今のところ黒字打率１０割なので、今回も良い結果を残せると

信じて頑張ります。
