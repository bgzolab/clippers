# 传颂之物

游戏讲述一个名叫哈克奥罗，戴着一个无法摘下的面具的人以及在他身边所发生的传奇故事。某一天浑身是伤的他被一个小村庄的少女艾露露所救，并成为了这个由祖孙三人组成的家庭的一名新成员。虽然完全失去了过去的记忆，哈克奥罗（名字是女主人公艾露露的祖母图斯库尔给他取的，也是艾露露父亲的名字）很快凭借他的智慧和勇气在这个小村庄被大家所接受。之后的一次偶然的事件使哈克奥罗成为了反抗国王暴虐统治的起义军领袖，并在推翻国王统治后成为了这个国家的新国王。但是这仅仅是哈克奥罗战斗生涯的开始。
