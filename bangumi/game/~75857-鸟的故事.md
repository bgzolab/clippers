# 鸟的故事

　“A Bird Story”是一个简单的、离奇的关于一个少年和一只断翼之鸟的短篇。尽管它和自由鸟工作室大部分的游戏一样是故事驱动的，但全程几乎没有对话成分...

　尽管 Dr. Watts 和 Dr. Rosalene 不在这款游戏中出现（从时间上来说, 这部游戏在他们的故事之前发生），游戏中的男孩长大后会成为他们的病人出现在整个系列的 “第二章节” 中。
