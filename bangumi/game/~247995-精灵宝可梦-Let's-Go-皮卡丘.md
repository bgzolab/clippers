# 精灵宝可梦 Let's Go！ 皮卡丘

《精灵宝可梦 Let's Go! ⽪卡丘》和《精灵宝可梦 Let's Go! 伊布》是在Nintendo Switch登场的《精灵宝可梦》系列最新作品。本作是以1998年发行的Game Boy软件《精灵宝可梦皮卡丘版》为基础，对玩法和剧情方面进行了重新构筑的作品。由于交叉活用了Nintendo Switch与《Pokémon GO》的特征，玩家将会获得《精灵宝可梦》的全新游戏体验。
