# 帕斯卡契约

《帕斯卡契约》是由 TipsWorks 开发的一部幻想题材的动作角色扮演游戏。

== 世界观 ==

传说，千百年前，

太阳沉入海底，黑雾铺天盖地而来，世界陷入黑暗。

黑雾是“污秽”，侵染一切，生机灭绝。

此时，巨像出现了。

巨像行走于大地上，放出光芒，驱散黑雾，

为人类照亮一片片栖息之地。

黑暗的世界，唯有巨像脚下，才有人类的一线生机。

巨像，人类奉之为神明。
