# 神秘海域：失落的遗产

备受赞誉的开发商 Naughty Dog 隆重推出由克罗伊 • 弗雷泽担纲主角的全新 Uncharted 游戏。

为了追查传说中的古老宝物，阻止它落入挑起战祸的冷血之徒手中，克洛伊必须与名声远播的佣兵娜汀·罗斯联手出击，深入印度西高止山脉，找出象神的黄金长牙。克洛伊在她这个史上最壮大的冒险旅程中，将会面对自己的过去，并选择作出什么牺牲以为后世留下宝贵的遗产。
