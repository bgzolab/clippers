# 鬼畜王兰斯

兰斯系列的外传性质作品，剧情上与 5D 之后的作品互为平行世界。

兰斯和希露在冒险旅途中加入了赫尔曼东北部山区的一个盗贼团，并成为头领，带领属下侵袭周边城镇，掠夺财富和美女。不料赫尔曼派出了数千人的警备团围剿山贼，盗贼团全灭，混乱中希露被抓，兰斯侥幸逃生。为了利用利萨斯军的力量征服赫尔曼（“顺便”救出奴隶希露），兰斯选择接受莉亚求婚，成为了利萨斯新任国王。

ALICESOFT 地域压制型 SLG 的开山作
