# 对战公主

美少女×横スクロールタワーディフェンス×ローグライト

自分だけのデッキを構築し、お姫様の城を攻め落とせ！

本作は自城からユニットを進行させお姫様の城を攻め落とす横スクロールのタワーディフェンスゲームです。物語をプレイするたびに、新しいデッキの構築を楽しむことができるローグライト要素もあります。　全世界のお紳士様が喜ぶムフフなご褒美要素も多数あり！
