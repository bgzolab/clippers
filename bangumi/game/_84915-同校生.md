# 同校生

与 5 个女孩在一起的岛国生活.

故事的魅力之一就在于，作为一个小电影来向大家展示的。

最热辣的场面，绝对值得一看!

回到故乡 (木见影岛) 的主人公“绯村和树”进入了熟识的美少女们所在的姬有里学院。开始了新的学院生活的和树被迫加入了“神秘事件探求俱乐部”(简称“密探部”)，这样一来，那些与和树有所牵连的女孩子们，也纷纷加入其中，每天的探索活动变得越来越意想不到。

和树的学院里有着这样一个神秘事件，那就是与“铃兰 " 的相遇.

放眼望去，不断延伸的深绿色的草原。

从那天起，不曾开放的花朵，现在变成了铃兰草。

于是，学院里诞生了这样的传说.

只要你对铃兰怀着强烈的愿望，一旦花朵开放，看见它的少女，就能实现心中所想 "。

对铃兰怀着各自心愿的五位少女，唤醒了他早已停止了的时间。
