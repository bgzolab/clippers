# 终天教团

终结快乐…… 恭贺终结

“距世界末日还有168……”
人类即将迎来灭亡的时刻。

在充满绝望与混乱的世界中，出现了一个异样的新兴宗教。“终天教”。他们的思想是，期待人类的灭亡。这个宗教迅速传播，直至信徒们建立了一个名为“终天教国”的小国。然而某天，终天教的教祖被人所杀害了。

教祖死后，通过“神之力”这一奇迹复活，变成了主人公·下边零。但由于复活得不完全，他失去了记忆，并且四天后将再次死去。

两个自称是 神的使者——“天使”的人出现，并告知道：要实现真正的复活，必须进行一项名为“神之试炼”的仪式。“神之试炼”……找出杀害教祖的犯人，并将其杀死。

于是，一场赌上自身性命与世界命运、限期4天的漫长寻凶之旅就此展开。
