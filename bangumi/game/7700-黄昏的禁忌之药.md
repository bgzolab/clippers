# 黄昏的禁忌之药

主人公の皆神孝介は叔母の岩永皐月からのアルバイトをきっかけにして、故郷である御奈神村へとやってきた。
天女伝説の残る地は幼い頃に妹の皆神さくや、幼馴染の春日いろは達と暮らした場所で、新たに岩永翔子、銀子といった少女達と出会う。 やがて日常の間に、不気味で不可解な事件と遭遇する事になる。
