# 尾行 3

尾行シミュレーションとして登場した、「リバーシブルフェイス ～尾行 2～」の続編が遂に登場！ターゲットとなる女の子に気づかれないようにひたすら付いていくこの作品。尾行中見つかってしまわないように、「ゴミ箱の中」「マンホール」「井戸」など様々なもので身を隠しながら相手を追い詰めていくことになる。お馴染みのお邪魔キャラ「警備員」や「カラス」なども登場し尾行の邪魔をしてくるので各種アクションを駆使して切り抜けていこう。
