# 神臂斗士

《ARMS》是一款由任天堂企划制作本部开发的3D格斗游戏，玩家将在一个固定场景中进行拳击对战，一局游戏可以最多有4名角色一起对战。《ARMS》中的角色通常都有可以伸缩自如的双臂，并以此作为攻击的主要手段；不过一些角色会使用可伸缩的头发或机甲进行战斗。除了不同的角色，玩家可以通过更换不同属性和不同重量级的拳套来在游戏时获得不同的特殊能力。游戏发售时将会有10名可操作角色，并将在发售后陆续免费增加角色、道具和场景。

游戏除了主要的拳击对战模式以外，还有1VS1的单挑灌篮、排球赛、打靶、百人斩等小游戏内容，通过这些小游戏，玩家可以获得游戏内的金钱奖励来购买道具。
