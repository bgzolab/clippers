# 仁王

以贼人嚣张跋扈，妖怪四处蠢动的幽玄日本战国时代为舞台的黑暗风格战国动作 RPG，讲述史实人物「三浦按针」为蓝本的金发碧眼武士「威廉」以及历经几番死斗的故事。

本作除了以战国时代末期史实为基础，有众多实际存在的战国武将登场的宏大原创剧情，也是能够提供充分的紧张感与极高成就感，足以称之为“战国诛死游戏”的作品。
