# ネコぱら vol.0 水無月ネコたちの日常！

嘉祥が『ラ・ソレイユ』を開店する少し前のお話。
水無月家長女である時雨と６匹のネコ姉妹たちが、ご主人様を朝起こしに行って、朝食の準備をして、家の掃除をして、お出かけをして、晩御飯を作って、お風呂に入って、みんなで就寝などなどなどなど。
水無月家ネコたちと時雨のゆるーく平凡な休日の１ページ！
【 注意：全年齢作品です 】
