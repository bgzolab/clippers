# ネコぱら vol.3 ネコたちのアロマティゼ

サークル「NEKO WORKs」が贈る「ネコぱら」の最新作の登場です！
水無月嘉祥（みなづきかしょう）の経営するパティスリー「ソレイユ」は、恋ネコも増えて今日も絶賛営業中。
プライドが高くて高飛車なオシャレネコの次女メイプルと、妄想家でひとり暴走しがちな3女ネコのシナモン。
姉妹の中でも仲の良い友人関係のような2匹が、ちょっとしたきっかけで夢を持つことに悩むメイプルと、
親友の力になりたいのにどうしていいか分からないシナモンが、

ふたりの夢に向かって成長していく姉妹ネコと家族の絆を描く、ちょっとHでハートフルなネココメディ今日もまた開店！
