# King Exit

▼故事▼
因为英雄格奥伊斯的存在，魔族被剿灭
对于初出茅庐的少女就能成为救世主，被人们津津乐道的同时
幸福快乐生活，整个世界彷彿都被那耀眼的光芒所包围著
在那之后的3年中
英雄格奥伊斯不仅失去了住的地方，连朋友和家人都遭遇不幸
背负著巨大罪名的她被带到了“地下监狱”

▼角色▼
沦为囚犯的格奥伊斯
被永久性的封印了魔法，连装备和服装都被夺去
被夺走一切的她失去了活下去的意义
这时遇见了双目失明的少女【斯迪阿拉】
两人之间羁绊渐渐加深的同时也下了决心
秘密策划不顾一切逃出监狱

▼游戏介绍▼
・战斗机制简单
採用的是消耗HP，MP，TP的回合制战斗模式
集结遇见的小伙伴一起打倒监狱的敌人
・地下监狱关卡！
在地下生长的植物可以当作是恢复道具
被折断的钥匙或死囚身上的遗物等等
都是逃出监狱的关键线索
・梦！
格奥伊斯梦见了关于战争的梦
逝去不返的同伴们一起战斗的中所学的越狱相关技巧
和在这种环境下的生存之道

▼长篇RPG▼
主线故事通关一般情况下需要18小时
序章～主线九章～最终章开始
这是相遇与分别，绝望与希望共存的故事

▼收集▼
在每次游戏通关后
可以以收集成就奖牌和道具为目标
同时还可以体验每週目游戏带来的不同乐趣
