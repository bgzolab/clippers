# 兰斯 02 －反叛的少女们－

カスタムの街で魔法修行中の四人の少女が反乱を起こし、

街を丸ごと陥没させ、地下に封印してしまった。

彼女らを倒す依頼を受けたランスは、シィルを連れて地下迷宮へ向かう。
