# 微信公众号 ---API 接口发布文章 - 帅到要去报警

最近在做一个项目，需要用到通过 API 接口发布推文。

基本流程：

1、注册微信公众号（订阅号和服务号都可以）

2、开发配置获取 appid 以及 appsecret，以及配置服务器 IP 白名单。

3、开发流程：接口需要 access_token

第一步：上传推文的素材，主要是推文的封面以及文章所需要的图片。

第二步：新建草稿，将文章上传到微信公众号形成草稿。

第三步：发布草稿。

开发流程：

1、素材管理 - 新增永久素材

可以新增：图片（image 10M）语音（voice 2M）视频（video 10M）缩略图（thumb 64KB）

同时提供：获取素材总数、素材列表的接口。

2、草稿箱 - 新建草稿

3、发布草稿 - 发布接口
