## 一、前言

当下，无论是Claude Code 、Codex 还是 Gemini
Cli，都以终端为主要交互形式，而我跟AI的很多交互也以终端为主了。而你在日常使用终端的时候，是否也遇到过这些崩溃时刻：

  * 终端卡得像老牛拉车？
  * Claude写代码时输出一堆文字看不清？
  * 想左右分屏（左边让Claude写代码、右边debug）却不知道怎么加屏幕？
  * 配置一改就弹窗报错？  
  
所工欲善其事，必先利其器。既然用终端的时间多了，那打造一个强悍的终端环境就非常的有必要了。而Claude 官方推荐的Ghostty无疑就是终端里核武器。  
**而这篇入门文章** ，我把所有坑都踩过一遍，用**最简单的话 + 手把手截图 + 基础命令** 教你。 读完5分钟，你就能：  

  * 打开Ghostty就自动进Claude
  * **Cmd + D** 一键左右添加屏幕
  * **Cmd + Shift + Enter** 一键放大Claude输出
  * 配上彩虹状态栏 + 快乐现场

## 二、Ghostty到底是什么，为什么这么香

![](https://picx.zhimg.com/50/v2-bbb07fccd41f1f5e92bfe66b20335af4_720w.jpg?source=2c26e567)

  
**Ghostty 的背景故事** ： Mitchell
Hashimoto在开发Terraform、Consul等工具时，发现现有终端工具性能瓶颈严重。2024年底，他用Zig语言从零开始编写Ghostty，2025年正式开源，2026年已成为开发者圈最火的终端工具。  
  
Anthropic官方**推荐Ghostty作为Claude Code的首选终端，官方推荐理由是** ：

  * ✅ **性能极致** ：超级快，GPU加速，渲染速度比iTerm2快3-5倍，**Claude输出再长也不卡，滚动丝滑像丝绸。**
  * ✅ **AI工具友好** ：完美支持Claude Code、Cursor等AI编程工具，而且持Kitty图形协议（Claude让你画图？图片直接在终端显示！）、Quick Terminal下拉幽灵、一键分屏、永久保存布局。
  * ✅ **资源占用低** ：内存占用仅为iTerm2的1/3
  * ✅ **开发者体验** ：Mitchell Hashimoto（HashiCorp创始人）亲自操刀  
  
如果你对比**Ghostty和其他终端，Ghostty在性能、易用性、AI工具支持三方面全面领先。**

![](https://pic1.zhimg.com/50/v2-b035a72410f32f030124436aeefcc38a_720w.jpg?source=2c26e567)

一句话总结：**Ghostty不逼你“要么快要么丑”，它全都要！**

## 三、Ghostty使用教程

###  
第一步：安装Ghostty（5分钟搞定）

MacOS安装  
**方法1：Homebrew（推荐）**  
brew install --cask ghostty  
  
**方法2：官网下载**  
-访问 [https://ghostty.org](https://link.zhihu.com/?target=https%3A//ghostty.org)  
-下载 `.dmg` 文件  
-拖拽到应用程序文件夹

### 第二步：基础配置-推荐给大家我的极致稳定的配置（5分钟搞定）

  
Ghostty的配置文件位于：

  * **macOS** ：`~/.config/ghostty/config`
  * **Linux** ：`~/.config/ghostty/config`  
  
或者打开Ghostty的setting即可打开 config 文件

![](https://picx.zhimg.com/50/v2-a8a2f35fd0370af664b5886c82ecca4e_720w.jpg?source=2c26e567)

大家可以直接把我的以下这段config配置直接粘贴进去即可

    
    
    === 字体 ===
    font-family = JetBrainsMonoNerdFont
    font-size = 14
    font-thicken = true
    adjust-cell-height = 2
    
    
    === 主题 ===
    跟随系统自动切换明暗主题
    theme = light:Catppuccin Latte,dark:Catppuccin Mocha
    
    
    === 窗口 ===
    background-opacity = 0.9
    background-blur-radius = 20
    macos-titlebar-style = transparent
    window-padding-x = 10
    window-padding-y = 8
    window-save-state = always
    window-theme = auto
    
    
    === 光标 ===
    cursor-style = bar
    cursor-style-blink = true
    cursor-opacity = 0.8
    
    
    === 鼠标 ===
    mouse-hide-while-typing = true
    copy-on-select = clipboard
    
    
    === 下拉终端（Quake 风格） ===
    quick-terminal-position = top
    quick-terminal-screen = mouse
    quick-terminal-autohide = true
    quick-terminal-animation-duration = 0.15
    
    
    === 安全 ===
    clipboard-paste-protection = true
    clipboard-paste-bracketed-safe = true
    
    
    === Shell 集成 ===
    shell-integration = detect
    
    
    === 快捷键 ===
    标签页
    keybind = cmd+t=new_tab
    keybind = cmd+shift+left=previous_tab
    keybind = cmd+shift+right=next_tab
    keybind = cmd+w=close_surface
    
    
    分屏
    keybind = cmd+d=new_split:right
    keybind = cmd+shift+d=new_split:down
    keybind = cmd+alt+left=goto_split:left
    keybind = cmd+alt+right=goto_split:right
    keybind = cmd+alt+up=goto_split:top
    keybind = cmd+alt+down=goto_split:bottom
    
    
    字体大小
    keybind = cmd+plus=increase_font_size:1
    keybind = cmd+minus=decrease_font_size:1
    keybind = cmd+zero=reset_font_size
    
    
    全局热键：下拉终端
    keybind = global:ctrl+grave_accent=toggle_quick_terminal
    
    
    分屏管理
    keybind = cmd+shift+e=equalize_splits
    keybind = cmd+shift+f=toggle_split_zoom
    
    
    重载配置
    keybind = cmd+shift+comma=reload_config
    
    
    === 性能 ===
    scrollback-limit = 25000000
    

  
**配置要点说明：**

配置项| 说明  
---|---  
font-family| 需要预装 JetBrains Mono Nerd Font，Nerd Font 提供图标支持  
theme| 自动跟随 macOS 明暗模式切换 Catppuccin 主题  
background-opacity + background-blur-radius| 毛玻璃半透明效果  
macos-titlebar-style = transparent| 隐藏原生标题栏，界面更简洁  
quick-terminal-*| 配合 Ctrl+`` 全局热键，随时呼出/收起下拉终端  
window-save-state = always| 重启后恢复窗口布局  
  
###  
第三步：高效使用技巧（进阶必看）

![](https://picx.zhimg.com/50/v2-81ca22c7d75d8ec8ad364f83966f3c16_720w.jpg?source=2c26e567)

这个就是一般我的 Claude Code的使用页面，效率高的一批。  
而这里最核心的就是记住以下5 个命令：

  * **Cmd + D** → **左右添加屏幕** （最常用！左边Claude写代码，右边debug）
  * **Cmd + Shift + Enter** → 一键放大当前屏幕（看Claude长输出超爽，再按恢复）
  * **Cmd + W** → 关闭当前屏幕
  * **Cmd + Shift + ,** → 重载配置（改完主题或分屏后一定要按！）
  * **Cmd + Q** → 完全退出Ghostty（重启推荐用这个）

其他的详细功能如下：

** _1️⃣分屏功能（无需tmux）_**  
**水平分屏** ：

  * 快捷键：`Cmd + D`
  * 效果：右侧新建终端

**垂直分屏** ：

  * 快捷键：`Cmd + Shift + D`
  * 效果：下方新建终端

**切换分屏** ：

  * 快捷键：`Cmd + [` / `Cmd + ]`
  * 或鼠标点击

**关闭当前分屏** ：

  * 快捷键：`Cmd + W`

**自定义分屏比例** ：

    
    
    # 配置文件中添加 split-divider-size = 2px split-divider-color = #3b4252

  
** _2️⃣标签页管理_**  
**新建标签页** ：`Cmd + T`  
**切换标签页** ：

  * `Cmd + 1` ~ `Cmd + 9`：切换到第1-9个标签
  * `Cmd + Shift + [` / `Cmd + Shift + ]`：前后切换

**关闭标签页** ：`Cmd + Shift + W`

  
** _3️⃣搜索功能_**  
**开启搜索** ：`Cmd + F`  
**搜索技巧** ：

  * 支持正则表达式
  * 大小写敏感切换：`Cmd + Shift + F`
  * 高亮所有匹配项

** _4️⃣历史记录管理_**  
**查看历史输出** ：

  * 向上滚动查看
  * `Cmd + ↑`：跳到历史开头
  * `Cmd + ↓`：跳到历史结尾

**历史记录大小** ：  
scrollback-limit = 10000

  
** _5️⃣主题切换_**  
**内置主题列表** （部分）：

  * `catppuccin-mocha`（深色，推荐）
  * `dracula`
  * `nord`
  * `gruvbox`
  * `tokyo-night`
  * `one-dark`

**实时切换主题** ：

    
    
    打开配置文件
    修改 theme = dracula
    保存（Ghostty自动重载）

**查看所有主题** ：

    
    
    ghostty +list-themes

###  
  
第四步：Claude 的实际使用场景示例

  
**场景1：Claude Code编程**

    
    
    # 打开Ghostty，分屏布局 Cmd + D        
    # 右侧分屏 Cmd + Shift + D  # 下方分屏 
    # 左上：运行Claude Code claude-code 
    # 右上：查看文件 vim src/main.py 
    # 下方：运行测试 pytest tests/

  
**场景2：多项目管理**

    
    
    # 标签页1：项目A cd ~/projects/A && claude-code 
    # 标签页2：项目B Cmd + T cd ~/projects/B && claude-code 
    # 标签页3：文档 Cmd + T vim README.md
