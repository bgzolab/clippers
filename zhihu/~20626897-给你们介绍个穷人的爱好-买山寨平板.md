山寨平板是对小品牌国产平板的一个代称，这些厂商生产的平板电脑通常价格在 1000 元人民币以下，搭载厂商自己做了一些小改动的安卓系统，如果使用的是 Atom
或者 Core M 的平板，则会搭载 Win10 或者干脆来个双系统。

严格来说，山寨平板和早期的山寨机还是有区别的，早期山寨机的一切设计是以尽可能模仿得很像大品牌手机为目标，达到以假乱真的效果，而寨板们还是有着一些自己的独特设计，比如每一家都有着十分难看的
logo。

## 山寨平板几大特点

第一，造型很山寨，大厂出啥他们出啥

山寨平板之所以被称为山寨平板，最主要的原因就是它们在硬件上唯苹果马首是瞻，苹果上 7.9 英寸屏幕，他们也出 7.9
英寸产品线，苹果上高分屏，他们也上高分屏。然后宣传自己推出了新的平板旗舰。三星，NEXUS 7
平板销量提振之后就跟随一波，出了配置类似的产品，新开产品线，所以山寨平板的产品线要比一般大厂的产品线丰富得多，主要是他们需要跟随的对象太多了，除了屏幕跟随大厂，寨版的更新频率一般也和供应链伙伴提供的
cpu 同步，有啥新 cpu 可以供货了，立马开一个新产品。所以说寨板的一个产品生命周期可能半年都不到，半年过去，就停产了。

第二，经常用坑爹元器件

山寨平板厂商供应链伙伴主要有一些不太上台面的国产面板厂商，国产 SoC 厂商（全志，瑞微芯），国产传感器元器件厂商，以及 intel
和微软（此处应该有掌声）。

  
![](https://pic3.zhimg.com/f17e33e49aa427b01fc0f3e4a2d1b9b6_1440w.jpg)  

简单的说，就是供应链上面什么垃圾元器件都敢拿来用。比如 intel 早期的 atom
处理器，对安卓系统的兼容简直一坨翔。还有七寸低分屏（800X480）的垃圾变形屏，酷比魔方和昂达都用过，分辨率是 15：9，屏幕尺寸是
16：9，用起来真是酸爽的一笔，笔者还曾因为这件事情和电脑城无良商家吵了起来。

第三，大厂出啥他们出啥，而且一定「秒杀」大厂

宣传上面也特别喜欢夸大其词也是山寨平板的特点，单核 CPU+GPU 的 soc 组合宣传成双核 CPU
这种事情也是出现过的，这么做的厂商还被《电脑爱好者》杂志特地挂起来婊。

除了虚假宣传，山寨平板还喜欢夸大宣传，把大家都有的方案说成独有的，把 soc 自带的特性拿出来大说特说，等等。

  
![](https://pica.zhimg.com/5c754a29e87eefa01e84d0fd3c5c59e0_1440w.png)  

第四，基本无视细节，用户体验和优化

在细节和用户体验上，山寨平板基本上就等于没有下功夫。UI 基本上是什么流行抄什么，最开始是抄 iOS，后来抄
win8，把贴磁界面强行套在安卓上面，最后还是绕回来，继续抄扁平化之后的 iOS，顺便借鉴一下
MIUI。硬件做工也很一般，贴合基本上都有缝，时间长了里面全是灰尘污垢，边框基本上都是粗的可以停飞机，跟航空母舰似的。

硬件驱动优化更是弱鸡到令人发指，槽点太多以至于不知道怎么吐槽。

比如台电 X98 AIR 2 的 win8
系统下前置摄像头视频的时候显示的画面是反的，笔者认为这是摄像头应元器件没有做好驱动的缘故，因为我把平板电脑反过来放，重力感应会很智能的矫正，也是拍摄到的画面还是反的。这说明重力感应元器件驱动做得很好，但是摄像头驱动一泡污。让我当时就有一种哭笑不得的感觉。

再比如酷比魔方的 iWork 11 绘画平板，配备了 wocam 的电磁笔，1024
级压感，感觉十分碉堡，但是这个平板有一个特点，那就是当你的手碰到屏幕的时候，平板会自动转变为电容屏模式，电磁笔这个时候就失效了，也就是说，除非你能悬空着手画画，否则这个平板对你来说，就没啥用处。

下图是酷比魔方官方推出的视频，里面的使用者悬空画画，我看着都累，真是辛苦小哥了。

  
![](https://picx.zhimg.com/15aa1b5b5d9d0d2819d65d715a75baa5_1440w.png)  

最后，山寨平板还有一个缺点，就是品控太差太差，运气好买到的寨板会非常耐用，运气不好，基本上是 2
个月内就会坏掉。所以我买寨板基本上在京东买，坏了之后直接可以换新，这个京东是有承诺的，数码产品换新。

我坏过两次平板，第一块是台电的
P90，被我不小心压坏了，理论上这种情况是不给保的，但是我懒得送厂家，还要快递费，所以直接送到京东自提点了，但是京东不知道是不是懒得送修还是怎么，给我换了块新。第二块
X98 air 2，买来一个星期不到屏幕失灵了，直接换了一块新的。

有人可能说二手东之类的，这个我只能说，你都 TM
买山寨平板了，你还在意二手不二手？比起自己和淘宝店家撕逼，京东上面买这种品控不稳定的产品还是比较省心的，尤其是京东自营。

我个人思考过为什么京东如此爽快，究其原因，我觉得主要是山寨平板的更新频率非常快，喜欢用机海战术，我用坏一块再去换新，可能这个产品本身已经进入清库存的阶段了，所以店家比较无所谓。至少
P90 被我用坏的时候我再去京东上面看了看价格，已经是打折销售了。

当然，山寨平板也是有优点的，最大的优点，莫过于便宜。

## 山寨平板的历史

山寨平板的特点基本上随着历史发展一直在变化，山寨平板厂商的历史有四个阶段，mid 阶段，伪苹果阶段，wintel 阶段与后 wintel 时代。

MID 阶段，是 2010 年到 2011 年的一个阶段，iPad 还没有走进千家万户，google 搞了个 android3.0
做平板死得很惨，但是灵敏寨板厂商已经闻到的金钱的气息，开始推出了搭载安卓系统的 MP5，这些 MP5 屏幕尺寸一般是 5 英寸和 7
英寸，屏幕分辨率通常只有 800*480。有的触控屏甚至是用的电压屏，总之，坑坑的，用起来体验不是很好，玩个愤怒的小鸟加载都要 30
秒左右，鸟在空中飞的时候动画还一卡一卡的。这一时期的寨板元器件挑选也十分多样化。基本上没人会在意 MID 平板的 CPU
是什么型号，反正都不是很好用，基本上就是穷学生拿自己的零花钱买来用用的。

从 2011 年开始，全志，瑞微芯开始推出了基于 ARM 架构的 SoC 方案，台电，昂达，原道等厂商推出了造型同 iPad 十分类似的 android
平板，寨板进入了伪苹果阶段。然后在 iPad 3 上市（The New iPad）半年之后，寨板厂商才能够勉强拿到视网膜屏幕的元器件，仿造出游视网膜屏的
android 平板。

2012 年，Win8 上市了，为了推动 win8 在平板市场的占有率，微软联合 intel 向国产山寨平板疯狂推销 Atom CPU 和 win8
操作系统，慢慢的，全志和瑞微芯就被 Atom 取代了，剩下的 ARM 架构份额责备逐渐发力的联发科一并吃掉，由于 intel 和联发科都是大厂商，提供的
CPU 无论在性能还是稳定性上都很有保证，在软件界面设计上还有 miui 可以抄袭，这一阶段的山寨平板体验获得了质的飞跃。有一部分山寨平板开始尝试采用
Win8 系统，但是基本上都会再预装一个 android 系统，因为大家其实还是不是很习惯 win8。

2015 年，Win10 正式上市，伴随着全新架构的 Z8500 CPU 和 Core
M，寨板厂商们开始生产二合一产品，昂达的二合一产品是一款键盘可拆卸的笔记本，装载了 Win10 系统，酷比魔方则推出了造型雷同 Surface
的平板电脑。这些二合一产品售价基本上在 2000 元左右，对于寨板厂商来说，贩卖价格高于 1000
元的产品也是一个不小的挑战，台电，昂达的厂商还开始试水智能手表，一体机等领域。

可以说，山寨平板在短短几年内，还是取得了不小的进步的，但是这些进步和山寨平板厂商没啥关系。主要是因为安卓系统内核优化越做越好，CPU
厂商越来越给力，所以寨板们的体验才水涨船高。在可以预见的未来，寨板的体验可能还是会做得更好。可能以后元器件厂商进一步洗牌，然后寨板门就吃上了以前大厂商才能用的传感器，说不定传感器厂商还附带送驱动，寨板体验更好了，但是离主流产品始终会有不小的差距，毕竟寨板的进步并不是靠自己的努力，而是纯粹靠历史机遇和摩尔定律，他们其实是时代的最低水平，只不过我们所处的时代，最低水平一直在增长。也由于山寨平板厂商自身不努力，所以山寨平板的品控这几年其实一直没有什么进步，甚至有退步的趋势，因为元器件越用越高端，传感器越装越多，但是自己的姿势水平跟不上，所以才出现了上文提到的摄像头显示图像是倒过来的这种低级错误。。

## 主要的山寨平板厂商

目前，国内山寨平板厂商主要有四个重量级玩家，蓝魔，台电，酷比魔方和昂达。基本上都是深圳做 MP3
起家，在移动互联网时代艰难转型做平板的厂商。此外还有七彩虹，中柏，原道等做出过一些让人印象深刻产品的厂商，以及曾经名噪一时，现在已经基本见不到踪影的五元素。

下面我就说说几个大厂商的主要特点。他们都有着山寨平板厂商的共同点，产品线更新速度快，品控差，用户体验差，以及便宜，但是各大厂商还是各有各的特点。

首先说一下蓝魔，蓝魔属于寨板厂商之中比较非主流的一个，它的产品更新频率是要比别的厂商慢一点的，没有那么浓厚的机海战术意味，此外，蓝魔是寨板厂商之中最有逼格和工匠精神的一个，是矮子里的将军，做的产品细节都要比别的寨板厂商要好，当然，和苹果比起来细节还是差远了，毕竟便宜呀。

蓝魔现在重心在蓝魔手机之上，蓝魔手机给我的印象很深刻，他们的发布会非常性冷淡，说 30
分钟就结束了，有一种「参数都在这边你们赶紧抄完发稿子然后拿了车马费回家吧」的王霸之气。此外，蓝魔的手机非常贵，联发科 CPU 的手机硬是买 2999，比
OPPO 还厉害，要是真能卖出去，那就是站着把钱赚了，爽飞了，可惜目前我还没有任何消息渠道可以统计蓝魔手机的销量，目测不会太高。

说完蓝魔，我说一些我最熟悉的台电（买的多）。台电同其他寨板厂商相比，最大的特点就是绝大部分产品都很稳定，部分产品十分拔群（比如
P90），但是有的时候会犯一些神经病一样的错误，让我怀疑他们的产品经理其实是蓝魔的人。

我来说说最近台电的一个超级二逼的错误，台电的旗舰板 X2 PRO 号称是双系统平板，这个平板的安卓系统其实是跑在 win10 上面的虚拟机。

  
![](https://picx.zhimg.com/c82ca40482587f7d82eed15c21aacefb_1440w.png)  

这个事情被人喷的昏天暗地，真是一失足成千古恨。因为这个决策实在是太二逼了，以至于我每次看见 X2
的广告都想笑，虚拟机双系统，哈哈哈哈哈哈，容我笑一会，你咋不装个 mac os x 的虚拟机说是三系统呢！最坑爹的是台电就一直不更新 X2
的固件，相对廉价的产品线却都一直在更新固件，作为年度旗舰的 X2
反而就是不更新固件，就是不给用户提供原生安卓系统，放佛赌气似的，惹得所有用户在论坛骂娘，真是太逗趣了。

此外，台电的品控和工艺和蓝魔差一个档次，同酷比魔方和昂达是同一个水平，但是本人的台电平板摔过很多次，都没坏，也是善哉善哉。最后，强调一点，台电和台积电没有半毛钱关系，一个是深圳的，一个是台湾的，也不存在控股或者股权交叉，java
和 javascript 也没有关系。

说完台电，我再介绍一下酷比魔方的特点。酷比魔方最大的特点就是前戏有余后劲不足，酷比魔方应该是寨版厂商之中第一个同 Remix OS
大规模合作的公司，也是较早采用 core m 的厂商，也是第一个采用 wocam 电磁笔搞了 1024 级压感的厂商，也是第一家推出造型类似于
surface 的大尺寸寨板（最新的 i9）的厂商，第一家在平板电脑上装载了 usb3.1type c
接口的寨板厂商也是它。反正你们知道酷比魔方很有创新精神就是了。

但是，酷比魔方的大部分产品后续完全没有优化，固件更新基本靠民间 ROM 组，i7 手写板用了 core m
的核心，干脆不给适配安卓系统，惹得用户每天都在怒骂，你看看隔壁家台电 / 昂达，我再也不买酷比魔方的产品了！

最后说说昂达，昂达是国产 MP4
的老品牌了，昂达相比其他家，最大的特点就是一个字，稳，稳如狗。虽然说寨版普遍没有什么优化，但是昂达的软件细节是总的来说是比较出彩的，比如昂达的双系统平板都是支持热切换的，固件更新也比较及时，同
Remix OS
的配合也很紧密，基本上是属于相对让人省心的厂商。对旗舰产品的优化更新也比较及时，并没有出现台电那种「我就是不更新旗舰产品固件」的情况。但是昂达在硬件创新上的动作一直很少，昂达目前貌似还没有产品是官方提供良好手写笔支持的，这点要比台电和酷比魔方落后太多了。台电和酷比魔方的
core m
平板都配备了磁吸键盘接口，昂达的产品同样没有跟进，可以说昂达的产品线在硬件进步上的动作是比较少的。昂达近期的产品方向在二合一笔记本上面，所以平板产品上动作比较小。

此外，中柏这样的厂商也做出过一些让人觉得很惊艳的作品，比如一个搭载了 win10 和 remix os 系统的造型很像 surface
的平板电脑，我本来看了十分心动，但是一看京东的评论区，就望而却步了，差评太多了。

## 所以，买还是不买？

寨板这种产品，买来当主力机，是不可能的，毕竟小毛病太多了，不耐用，主力机买这种小问题特别多的机器会爆炸的。但是对于重度漫画控来说，买一各寨板专门用来看漫画还是不错的，毕竟屏幕大，看着爽。需要经常阅读
PDF 的人也可以考虑买一台寨板，用起来其实也是很爽的。如果你喜欢玩炉石，但是想来在床上玩又觉得笔记本太重，也可以买一个寨板就用来床上玩炉石，反正便宜啊！

此外，经常会短期外出办公的人如果钱不是很够的话，也可以买一台装有 win10 的寨板应急用，比如经常需要跑发布会的记者朋友。

不得不承认，寨板还是有很多毛病的。对于绝大部分不差钱的人来说，寨板并没有存在的价值，3000 元的 iPad
可以做到所有寨板能做到的事情，而且只会做得更好。但是这个并不能阻碍我乐此不疲地买来玩。

因为现在的平板，手机，都越做越省心了，放在 5
年前，不会刷机，不会越狱，智能机到手里基本上不是垃圾就是废物，现在手机越做越好，大家玩机，玩数码产品，都是玩的那些 APP，再去倒腾固件，倒腾 ROM
的机会越来越少了。但是山寨平板因为优化实在太烂，厂商有时候还不负责任，经常遇到驱动有问题的情况，所以还是需要刷一下机，折腾一下 ROM
的，而且有些寨板还有多种 ROM 可以选择，Remix，MIUI，乐蛙等等，刷来刷去，其乐无穷！

笔者所在的大学（所在校区接近一半学生都是程序员的理工科大学）大概有三分之一的同学都买了山寨平板来使用，看视频，看电影，床上玩炉石，当安卓开发测试机等等等等。如果有需求，搞一块价廉物美的平板，折腾折腾，感受
2010 年时期智能机一般的「一卡一卡」的时代感，还是很不错的。

况且寨板厂商有时候其实还是蛮有创新精神的，比如把电磁屏电容屏都做在屏幕上面，还用了 wocam 的技术，比如推出可拆卸键盘的平板电脑，surface
造型的平板电脑，可以更换独立显卡的一体机，这些产品有些看上去很丑，但是关注一下的话，生活就会多了很多乐趣。讲真，看寨板厂商的新闻，要比看小米平板 2
的发布会有意思多了，小米有时候真该向他们多学习学习，推出一些能让人感觉眼前一亮的产品才是。

其实吧，说了这么多，我觉得还是回到最核心的问题，我之所以买山寨平板，不就是因为穷吗？而且你看，穷人花个钱吧，事儿还特别多，不相信？有个穷逼买山寨平板还专门写个文章介绍他们的优缺点。足足写了五千多字呢，没错，就是你看的这篇文章。
