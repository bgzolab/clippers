绝大部分的学术论文都是通过word或者latex进行写作的(虽然有时候需要提交的是对应的pdf文件),
但是事实上借助强大的[Pandoc](https://link.zhihu.com/?target=https%3A//pandoc.org/)的帮助,
我们也可以十分便利的用简单的markdown[^footnote1] 来完成学术论文的写作,
之后借助[Pandoc](https://link.zhihu.com/?target=https%3A//pandoc.org/)转换为你需要的word或者latex版本,
亦或者直接生成对应的pdf.

基本的markdown语法对文字, 公式, 图片(除了精细的排版), 脚注(就如我在上一段中使用的那样, :笑)之类的支持已经非常友好了,
接下来主要要谈到的是公式, 图片以及文献的引用.

### 公式和图片的引用

在使用如下代码插入的图片的时候, 我已经添加了对应图片的标签`#fig:Paris`

    
    
    ![Paris](https://zhenyu-liao.github.io/img/Paris.jpg){#fig:Paris}
    

之后可以使用`[@fig:Paris]`来进行引用, 比如:`in [@fig:Paris] we observe`. 之后使用pandoc转换为pdf格式

    
    
    pandoc -F pandoc-crossref test.md --pdf-engine=pdflatex -o example.pdf
    

需要调用[pandoc-
crossref](https://link.zhihu.com/?target=https%3A//github.com/lierdakil/pandoc-
crossref), 在Mac可以使用Homebrew安装

    
    
    brew install pandoc-crossref
    

针对于公式, 表格, 章节也有类似的用法,
请参考[这里](https://link.zhihu.com/?target=http%3A//lierdakil.github.io/pandoc-
crossref/).

### 文献的引用

在文章中直接引用`@goodfellow2016deeplearning`即可.
不要忘记关联对应的`.bib`文件(比如我下文使用的`liao.bib`). 之后使用pandoc进行转换

    
    
    pandoc -F pandoc-crossref -F pandoc-citeproc test.md --bibliography liao.bib --pdf-engine=pdflatex -o example.pdf
    

需要调用[pandoc-
citeproc](https://link.zhihu.com/?target=http%3A//hackage.haskell.org/package/pandoc-
citeproc), 在Mac可以使用Homebrew安装

    
    
    brew install pandoc-citeproc
    

需要额外注意的是, 由于句法冲突, 必须**先使用** pandoc-corssref,**之后** 使用pandoc-citeproc.

### 例子

给大家举个实际的栗子, 编辑`test.md`文件如下

    
    
    # Examples
    
    ## Crossref to a figure
    
    Here is a figure:
    
    ![Paris](https://zhenyu-liao.github.io/img/Paris.jpg){#fig:fig1 width=20%}
    
    In [@Fig:fig1], we observe ...
    
    ## Crossref to an equation
    
    Here is an equation
    $$ f(a)= \frac1{2\pi i}\oint_{\gamma} \frac{f(z)}{z-a}dz $$ {#eq:Cauchy}
    
    By [@Eq:Cauchy], we have ...
    
    ## Cite a book
    
    Here is a citation, reference will appear at the end of the document.
    
    In the recent work of @goodfellow2016deeplearning, a similar case ....
    
    ## References
    

通过调用

    
    
    pandoc -s --toc -F pandoc-crossref -F pandoc-citeproc test.md --bibliography liao.bib --pdf-engine=pdflatex -o example.pdf
    

即可产生如题图的pdf文件. 补充: 有同学问到了多级目录的问题, 都可以在markdown里面实现的. 另外如果需要的话,
上面例子中`--toc`就可以产生对应的目录.

[^footnote1]: 相信大家都赞成, markdown的学习难度是远远低于latex的 :)
