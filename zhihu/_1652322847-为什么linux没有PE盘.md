首先确定 PE 是什么：

Windows PE 是 Windows Preinstallation Environment 的简称，翻译成中文就是 预安装环境。主要用于系统维护。

* * *

那 Linux 里类似的概念是什么呢？当你的安装好的 Linux 系统坏了、密码忘了，你会用什么修复呢？

当然是用一个 live ISO 启动电脑，chroot 到你的 Linux 系统里，进行一系列操作。

这样答案已经呼之欲出了，Linux 发行版的 live ISO 功能就相当于 Windows 里的 PE，把它写入到一个 u 盘里，这个 u 盘就相当于
Linux 的 PE 盘了。
