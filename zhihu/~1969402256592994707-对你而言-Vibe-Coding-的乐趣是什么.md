目前最大的乐趣是在手机上安装termux + node.js + git + claude-code + glm4.6包月。随时随地尝试任意idea。

![](https://picx.zhimg.com/50/v2-da1e5d4283876e8cad45b98fb3dc0a82_720w.jpg?source=2c26e567)

有效降低了上下班通勤、吃饭、工作摸鱼期间刷抖音、B站、知乎……的频率。

ps：

我看很多人问怎么部署这套工具，其实很简单，你直接安装termux，termux内置了pkg命令，可以用它安装nodejs和git，然后用npm安装claude
code，最后设置好大模型的api key和github的ssh key就行了。

这套工具链最大的问题是，目前还没找到一个好用的无头浏览器可用（有一个能在termux里运行的puppeteer，但是需要先通过proot-
distro登录一个隔离环境，不好使），电脑上的浏览器mcp我也没在这个环境里成功运行，导致cc爬内容和调试界面的能力很有限。
