好几年没有用过安卓手机了。最近搞了一台Boost Mobile的Edge+ 2023，重拾解锁/刷机/root这一套，记录一下过程。

## 基本情况

  * Boost有锁机活动价购买，然后在[http://gsmunlockusa.com](https://link.zhihu.com/?target=http%3A//gsmunlockusa.com)花1.95刀可以买到解锁码。总成本约 $120
  * 配置：8gen2，8+512
  * 优点：在美国市场已经算性能比较强的安卓机了。康宁Victus玻璃，比较耐刮。影像凑合可用级别。支持有线ReadyFor（现在改名叫Smart Connect了）

## 解锁bootloader

  * fastboot oem get_unlock_data, 在moto美国站（要登录，但是账号随便注册）获取解锁码，然后fastboot oem unlock <token>
  * 好像刷官方固件的话，不解锁也可以？未验证

## 刷机

  * 老办法：在汐梦社区[http://bbs.ixmoe.com](https://link.zhihu.com/?target=http%3A//bbs.ixmoe.com)和配套下载站[http://mirrors.lolinet.com](https://link.zhihu.com/?target=http%3A//mirrors.lolinet.com)找固件
  * 尝试了RETUS和RETAIL通道的A15最新固件。刷法基本是解开zip，参考flashfile.xml内的steps部分，用fastboot依次执行。（我让ChatGPT帮忙写了个.sh）
  * 遇到的问题：脚本卡在fastboot erase userdata命令（正常应该瞬间完成），强行重启后bootloop
  * 解决：把所有的erase命令挪到了前面。保险起见，我还给boot，init_boot等分区的flash命令加上了--slot all
  * 刷机目的1：减少bloatware——没有实现，software channel永远是DISH Wireless，Boost自带软件也总是会自动安装。ChatGPT表示，可能是硬件写死了CID，无法规避。
  * 好在Boost预装软件都可以自行卸载。
  * 刷机目的2：恢复被隐藏的eSIM相关UI——没有实现；XDA有人说RETAIL通道固件不会隐藏eSIM，也有人说override一些props可以恢复UI，实测都不行，可能新版固件加强了隐藏的强度。
  * 但是只是UI层面的屏蔽，还是有办法查看IMEI2，以及调出eSIM UI，网上容易搜到，具体略。加上eSIM后使用是没有问题的

## Rooting

  * 既然都解锁了就顺便root吧
  * Widevine，SafetyNet（已升级成Play Integrity），Wallet，网银app等，好像很多细节很难整完美。但我想：反正也没打算在这台机器跑那些东西，那应该就还好。
  * 方法大体和以前一样：github下载Magisk Manager的apk，安装，patch boot img（rtwo需要用init_boot.img），刷入
  * rtwo特有细节：fastboot flash init_boot <patched_img>报错“Preflash validation failed”, 解决办法：切换到fastbootD，方法是fastboot reboot fastboot. （fastbootD界面闪一下就自动关机了，但是可以再按VolDown + Power开机回到fastbootD）（adb reboot fastboot应该也可以）

## 尝试修复Play Integrity

  * 刷机、root完之后我才注意到几个点：（1）SafetyNet已经“全面升级”为Play Integrity，这几年Google和整个Android ecosystem对Integrity check的要求一直在变得更多、更严格；（2）今年早些时候的一次Play Integrity升级几乎让rooted device as daily driver变得不可能；（3）这台机器只要解锁bootloader，就连BASIC级别都过不了（Play Integrity API Checker的JSON response显示各项都是“UNEVALUATED”）；（4）BASIC级别不过会导致一些非金融类app也拒绝运行，例如ChatGPT
  * ChatGPT说（3）可能是因为作为Boost/DISH定制机，Play Integrity功能启用了carrier sandbox导致。
  * 因此，我还是想至少修复一部分PI验证，增强一下实用性。
  * 但：尝试了Github/Reddit上找到的很多guide，都完全无效，（据称能搞定全部3个验证级别的guide，照表操课下来也仍然fail BASIC integrity）

## 变砖

  * 我觉得解锁BL失去的功能已经大于root可以增加的了，也想保留Smart Connect能力所以不想用custom ROM，因此：尝试刷回Boost原版固件 + 回锁
  * 回锁后启动失败！显示No valid operation system found之类错误。于是这台机器就这样hard brick了
  * 事后诸葛亮的分析：文镇化的原因猜测是和刷回Boost固件时的一个warning有关：“WARNING: vbmeta_a anti rollback downgrade, 23 vs 27“ —— 也就是vbmeta分区上防降级机制触发了，没有刷入版本23，保留了机器上的版本27
  * 我开始刷机前的版本是刚刚OTA推送的Android 15版本，具体版本号和最后刷回去的是一样的。中间刷过的RETUS和RETAIL通道固件的大版本号也一样（但是回忆一下，刷的时候有类似warning，只是版本号是25 vs 27）
  * 推测：vbmeta版本27，和刷回去的Boost固件其他部分不匹配，导致回锁后的启动校验不能通过
  * 但是为什么下载的Boost A15固件vbmeta是23，RETAIL固件是25？而我机器上一开始就是版本27？这些问题我没有找到答案了。

## 结局

  * 回锁变砖是无法修复的（除非拆机、拆某个芯片刷写后重新BGA；以及moto X30有特殊方法可以线刷恢复），所以这台机器只能作为尸体出掉了。
  * rtwo我买了两台，现在把另一台拿来用了，并且打算永远不解锁BL了。
  * 我另有一台闲置moto pstar - 国行Edge S Pro（870 / 12+256），考虑到（1）在美国使用，国行ROM没有保留价值；（2）机器已经support EOL，已经没有OTA；（3）不同于rtwo的写死CID，pstar可以通过“fastboot oem config carrier reteu”切换software channel（但因为OTA已经结束，并没啥实际意义）；（4）870和12G RAM的组合可玩性应该还可以——我决定把它拿来做“root玩具机“
  * 解锁后刷RETEU、安装Magisk（本来想用KernelSU，但新版只支持GKI kernel而这个机型比较老不是GKI，旧版（0.9.5）要自己编译安装，懒得搞）
  * 遇到和rtwo同样的问题：BASIC integrity过不了，网上找的方法都无效；尝试过ReZygisk/ZygiskNext、PIF-fork/PIF-NEXT配合Tricky Store、Yuri Keybox Manager等等
  * 最后在reddit看到一条评论是关于类似情况的，它提到只有在PIF（PlayIntegrityFix）UI中启用“Spoof SDK version to Play Store“才能恢复BASIC integrity，试了一下果然和我碰到的是完全一样的情况（可能跟跨channel刷机有关？），这样的话至少ChatGPT的app可以用了

## 一点题外话

  * 我用过和玩过很多moto的机器了，见证了它这几年从更丰富的产品线，逐步找到和专注于自己的niche的过程。简单归纳一下几台机器的特点吧。
  * Edge S Pro和我曾经用过的Edge S都是4年前的机器了，是当年一众870机器卷性价比的一员。日常简单用一用，不打游戏的话870性能到现在还是堪用的。
  * Edge S Pro：素皮后盖，比较耐用。机身有点宽所以握持感一般。影像方面有噱头1亿主摄和5倍潜望长焦；素质以今天的标准是不太能看了。其他外围配置中规中矩，定位顾名思义是比Edge S高一点的
  * Edge S：机身明显粗大和粗糙一些，但没有S Pro那么宽，握起来反而还好。塑料后盖稍用一段时间就磨损得惨不忍睹。影像方面，后摄是平平无奇的64MP主摄+16MP超广+两个凑数，比较神奇的点是前摄居然有两个，加了个8MP超广角，还是有点实用性的。这款机器的最大优点其实是服务各种遗老（配备LCD屏和超高科技3.5mm耳机孔）
