我为 AMD 洗白一下……

AMD 自己是做 CPU 起家的，X86 CPU 对 Linux 的支持一直不错，现在基本上会每发布下一代 CPU 之前就推送开源驱动到 Linux
内核。贡献还是很大的。

AMD 的显卡是收购 ATI 而来的。早期的 ATI 显卡产品线非常复杂，常有一些非常奇葩的卡，即使 Windows 下也很难找到合适的驱动。那时候 AMD
也没有能力提供开源驱动。技术太复杂，还没消化过来。

不过，起码从 RX 4xx 显卡系列开始，AMD
会在显卡发布前，提供显卡的开源驱动和闭源驱动。开源驱动拥有大部分功能，而闭源驱动则多了一些新技术。而较早的显卡，以及移动平台上的定制型号显卡，则可能仍然没有驱动。笔记本平台上的很多
AMD 显卡用的是超级老的核心，如果你买到了只能大呼上当。(我就买过，被祸害好几年)

AMD 是 Linux 基金会会员，还赞助了很多 Linux 发行版。

所以说，AMD 对 Linux 的贡献还是很大的。只是出于历史原因，很多老型号显卡还是没有驱动。但是现在和未来这一点会改善。

如果你去买 RX 580/570/560 这样的新显卡，或者新一代的 APU
核心显卡，那么开源驱动应该是足以应付的。闭源驱动的兼容性一直不大好，因为无法针对各个发行版编译优化。

如果对比 AMD 和英伟达，那么 AMD 真应该算是大大的良民了。干死黄仁勋。
