Rime是一个输入法的名字。

区别在于，别的输入法下载就能用，Rime输入法……嗯，得看下五花八门的教程。

问题来了……

## 为什么用 Rime？

明明对于大多数用户来说，类似搜狗输入法、微信输入法、乃至于手心输入法之类的主流输入法，已经完全够用了啊？

事实上，Rime 适合的用户，大多是：

  * 喜欢极简/干净/小而美
  * 极度反感广告
  * 有高度定制需求
  * 对输入安全有需求
  * 对输入速度有追求
  * 对切换多种输入方案有需求
  * 对输入标点快符、自定义短语有需求
  * 使用小众输入方案，如双拼、音形、形码
  * 对输入生僻字有需求，如常常输入古书、文献上的字等
  * 对输入精确的繁体字、外来字、外语字有需求
  * 部分程序员
  * 部分文案、编辑、网文写手
  * 打字圈、竞速圈用户

其中，使用小众输入方案的用户是 Rime 用户群体最常见的来源之一。

例如：使用双拼、音形、形码的用户，是最容易接触到 Rime 的。

说得明确些，对于这类用户，我个人 100% 推荐使用 Rime。

理由是：Rime 对小众方案的支持几乎是开箱即用的，在 GitHub 与任意方案的群里，都能找到现成的方案对应的 Rime 包。直接下载复制到 Rime
的用户文件夹目录，右键一点托盘重新部署，稍等片刻让 Rime 自动生成对应文件，就能直接使用。

  

此时就会发现 Rime 的独一档优势：

  * 主流输入法几乎不可能支持小众方案，即使支持，也不会完善；
  * Rime 的高定制性，让小众方案的开箱即用包基本都定制了大量功能（例如反查、以词定字、辅助码、重复上屏、快捷输入等），非常好用；
  * 几乎所有小众方案都支持的标点快符功能，让输入标点符号时双手再也不用离开主键区，输入流畅度飞跃式提升。（这条对文案、网文写手等用户群体来说非常有用）

  

此外，Rime 引擎的某些特性也非常适合进阶用户，但在此不多赘述，留待用户自己发现。

  

至于很多 Rime 的安利文章喜欢讲的输入 emoji、快捷输入日期、农历、大写汉字等小特性……个人使用 Rime
几年，其实完全没用到过。也许对于一些用户来说，这些更重要。

  

但对于个人来说，Rime 是非常好用的码字工具，比搜狗输入法等主流输入法更好用。

  

或许这正对应了 Rime 的那条著名 Slogan：

  

**聪明的输入法懂我心意。**

  

## 下载使用 Rime

  

网上有太多 Rime 的进阶教程。

  

那些太复杂了。

  

我希望写得最简单、最无脑、最明确、最适合入门：

  

1\. 去[官网](https://link.zhihu.com/?target=https%3A//rime.im/)下载小狼毫，安装。（Rime
的中文名叫中州韵。它有两个分支，**小狼毫就是 Win 版 Rime** ，鼠须管是 Linux 版 Rime——看这教程的应该大多数都是 Windows
用户，Linux 用户一般不会有这个问题）

2\. **安装完，别急，这时候还不能用** 。

a. 右键托盘，有两个图标，其中一个有右键菜单，就是我们要的。右键选择用户文件夹，打开了一个目录。

b. 右键托盘，先退出算法服务（目的是退出占用），切换到其他输入法，再删除该文件夹下所有文件。（Rime
是个平台，可以搭载任意自定义方案。它本身自带了一些示例方案，但不好用，所以都删掉）

c. 去 GitHub，**下载一个自己喜欢的 Rime 方案** ，解压后复制到这个用户文件夹目录。

d. 右键托盘，重新部署。

e. （重要）等待片刻，让 Rime 自动生成方案对应的运行数据。这期间可以乱敲键盘，什么时候打的不是英文字母，就说明生成完毕了。

3\. 此时其实已经可以正常打字了。

大部分 Rime 的方案包都会自带切换方案的快捷键，F4 和 Ctrl+~都比较常见。这能在设置里更改。

4\. （非必须）但你会发现默认的皮肤（配色方案、字体、字号）有点丑。可以看下文自己更改。

  

享受 Rime 的输入体验吧！

## 更新 Rime 方案

  

用 Git 拉取更新应该是更优雅的选择。

但我不是程序员，不熟悉 Git，所以我选择在 GitHub 直接下载 Zip 包，全量更新。

即如下：

  

### 先保存数据（非必须，但建议）

  1.  _（非必须，但建议）若设置了同步，参考后文进阶部分：更新方案后同步词库及设置的教程，同步词库（否则个人曾输入的词库和输入习惯会丢失）；_
  2. 右键托盘退出 Rime 算法服务；
  3. 切换其他输入法，确保 Rime 用户文件夹的内容不会处于正在使用；
  4.  _（非必须，但建议）复制 Rime 用户文件夹里的所有内容到其他处，以防丢失数据；_

### 再全量更新

  1. 删除用户文件夹中的所有文件；
  2. 将下载的方案 Zip 文件解压，复制到用户文件夹中，切换 Rime 输入法，右键托盘重新部署。

  

理论上稍等片刻，Rime 就重新生成了该新方案的数据，你会得到一个崭新的 Rime。

  

**那么问题来了：你原本的个人词库、个人设置、配色字体字号、快符和快捷短语等等……也全都没了，需要重新设置。怎么办？**

这就要用到前面保存的数据了。

请直接参考后文进阶部分的迁移方案，一个个确认恢复。

  

## Rime 常用特性

  

### 换皮肤字体字号

  

（默认 Windows，Linux 鼠须管是 squirrel）

直接在用户文件夹目录（下同）找到 weasel.custom.yaml，没有就新建一个，这是对应小狼毫的 custom（定制）设置文件。

建议所有个人设置都在对应的 custom 里写，这样更新时方便迁移。

  

在该文件里：

    
    
    patch:
      "style/color_scheme": aqua
      "style/font_face": "霞鹜新晰黑"
      "style/font_point": 16

  

这是一个示例，也是个人常用的配色方案。

注意，Rime 的 yaml 语法对于空格的多少、空格与 Tab 占位符的区别、中英文空格都很敏感。如果新手担心出错，建议复制过去，再自己改关键内容。

  

  * 第一行对应皮肤（即设置好的配色方案，Rime 自带几种配色方案，理论上新手不知道不熟悉，就建议 aqua，个人感觉颜值还可以。但多探索也挺好，所有内容都是可以自定义的）
  * 第二行对应字体名称
  * 第三行对应字体大小（注意不同字体的字号其实有区别，自行尝试）

  

另：是否配色方案、字体、字号只能在 weasel 的 custom 里写呢？

并非如此。

你完全可以在对应具体方案的 custom 里写，甚至不考虑迁移的话还可以直接写在方案的 schema 里……但我个人习惯是写在 weasel 的通用
custom 里，这样更干净。

请自行探索。

### 打开或关闭某个开关（简繁、常用字或全集、emoji 开关等）

  

这些玩意看起来很复杂，实际也有点复杂。

为什么？

因为这要看你的方案有没有魔改……

  

不魔改的话，在 default、default 的 custom 里找找，应该能找到通用设置；在具体方案的 custom 和 schema 里也找找；

魔改的话（比如简单鹤的推荐 Rime 方案），就是在诸如 config_base 或者任意你觉得可能的地方找找……

  

但如果你对于修改开关默认状态、或操作的简洁性没有执念，可以直接用一个操作代替：

按键切换方案→在具体方案处空格→自动显示了一大堆开关（**注意可以翻页！** ）→选择具体想更改的开关。

完事。

  

### 修改竖排横排、边框、候选大小、行内输入等乱七八糟的内容

  

同上。

按理说，在 default 与它的 custom、方案与方案的 custom 都能修改；

魔改的话，就不一定在哪儿了，但大体上从名称可以看出来，例如 config_styles 之类的名称；

所以，多找吧，不难找。

候选对应的英文是 inline_edit，横排竖排是 horizontal，这两个比较有用。

  

此外，别忘了不同外观设置互相冲突时：

custom 优先级高于本身设置（因为 Rime 认为这是个人定制设置）；

具体方案的设置高于通用设置（因为 Rime 认为你为具体方案定制了特殊情况）

  

### 修改标点快符

  

快符太好用了。

但不同方案的快符常常不同。在你习惯某一套快符后，换了另一个方案的包，就很容易不适应；而原本提供的快符，某个符号也常常不是那么常用。

所以，修改快符是个常用需求。

  

一句话：

快符一般来说是用 custom_phrase（自定义快捷短语）来实现的。

  

不同方案的包把这东西放的位置不同。

所以，请自行找到对应的 yaml 修改。

对于类似 rime-ice 的包，这东西直接放在用户根目录下。 _注意，rime-ice 把双拼和全拼的 custom_phrase
还分开了，新手注意下，双拼就是带 double 的那个。_

有的包，类似简单鹤的群友 Rime 包，直接开了个 custom_phrase 的文件夹，在里面用 quick_symbol_phrase 来存这个。

其实这东西从头到尾都能自定义，并没有一定之规。

所以自己找就行了，不难找。

  

不过，还是那句话，Rime 对于中英文空格、空格多少、空格与 Tab 占位符等十分敏感。所以，如果不生效或出错，记得别自己打空格，直接复制示例。

还有就是，印象中像 rime-ice 这类功能丰富的包，里面的快符可以设置自动上屏与否、可以设置多个候选等。直接上屏似乎是
commit，按某个键以后是否有候选似乎是中括号还是什么……请直接看具体包里面文件的示例吧。

无论如何，对于新手来说，在进行进阶修改前建议备份用户文件夹的数据，避免搞坏影响输入。

  

稍微延伸一下：

为什么说从头到尾都能自定义？为什么 Rime 能识别到这个叫 custom_phrase 的快符？

因为在方案的主文件里一般写了几行对应的代码，让 Rime 知道去找这个名称的快捷短语。

所以如果你闲着没事多打开看看用户文件夹下的 yaml，就会熟悉各个文件的用途了，也就知道怎么改了。

一点都不难，里面都有中文注释标出对应的功能了，无非就是打开关闭开关的事。

  

### 挂载自己的词库

  

对于全拼、双拼用户来说，这是有些必要的。对于小众方案则意义不大。

  

事实上，如雾凇拼音、白露拼音这类包，本身词库已经很好用了，其实个人建议的话会是直接用就完事了。导入自己已有的词库听起来方便，但会略显折腾，需要一定的计算机知识。

  

请直接参考[雾凇拼音设置
挂载自己的词库](https://link.zhihu.com/?target=https%3A//dvel.me/posts/rime-

## 使用更好的长句模型（进阶）

  

简单来说，这是一个可选的优化。

有什么效果呢？

比如 jian jian de jiu bu zai yi le，用默认模型打，首选不一定对。

用更好的长句模型打，就会打出“渐渐的就不在意了”。

打长句更爽。

  

Rime自带一个长句模型，叫“八股文”，但它体积很小，效果一般。个人建议换成万象拼音的长句模型。

请直接参照[薄荷拼音的更换模型教程](https://link.zhihu.com/?target=https%3A//www.mintimate.cc/zh/guide/languageModel.html)，把万象拼音的模型文件复制到Rime文件夹中，再改下yaml里选择的模型及参数即可。个人体验效果很好。

  

 _顺带一提，简单鹤的模型patch文件写在了config_base.yaml里，很容易改。_

  

## Rime 同步与迁移（进阶）

  

以下内容参考了[oh-my-rime
多设备同步设置页面](https://link.zhihu.com/?target=https%3A//www.mintimate.cc/zh/guide/deviceSync.html)内容。

  

### 原理：Rime 同步逻辑

参考自: [GitHub 上的
issue](https://link.zhihu.com/?target=https%3A//github.com/Mintimate/DocVitePressOMR/issues/5%23issuecomment-1999136683)

新词库| 旧词库| 是否能够合并  
---|---|---  
sync\A\A.userdb.txt| sync\B\A.userdb.txt| √  
sync\A\A.userdb.txt| sync\A.userdb.txt| ✕  
sync\A\A.userdb.txt| sync\B\B.userdb.txt| ✕  
sync\A\A.userdb.txt| sync\A\B.userdb.txt| ✕  
  
  

### 基本迁移：相同方案在不同设备间的迁移

  

在 Rime 的 installation.yaml 里，可以自定义一个方便识别的设备 ID（非必须），比如“我的台式机”。

同时，在里面可以设定同步数据存储的文件夹，比如我的文档目录里搞个 sync 文件夹。

在设置好后，点击了托盘的用户数据同步，Rime 就会在我的文档/sync
里自动生成一个叫“我的台式机”的文件夹，里面都是这台电脑的自定义词库与使用习惯。（注意，不包括配色方案、自定义短语等大量内容，仅是 userdb
的词典内容，所以备份还是要自己做好的）

  

好，此时假如我们换了一个设备，比如说笔记本电脑吧！

下载 Rime、复制好（通常来说）相同的方案。

原本的自定义词库习惯没了。怎么办？

  

先重新部署后找到自动生成的 installation.yaml。在里面设置好 sync 文件夹，以及自定义方便识别的设备 ID（非必须），和原本 ID
不同（比如“我的笔记本”）。不同的理由是让 Rime 识别为不同的两台设备。

  

把原本台式机的 sync 文件夹里的“我的台式机”文件夹也复制过来。（这是笨办法，你懂的话用 WebDAV 之类同步更漂亮——实际上我也喜欢用
WebDAV）

  

此时你会发现：

sync 文件夹里有“我的台式机”和“我的笔记本”两个文件夹。

两个文件夹里有两套文件名相同的 xx.userdb.txt。

再运行一下同步。

此时，Rime 就会识别到：里面有两个设备的同步数据文件夹，名字又对得上——那么就融合！

最后重新部署一下。

你会发现，原本的自定义词库习惯，回来了。

  

不过，皮肤（配色方案）与很多设置不会同步。

这部分我写在下文中了。

  

### 本机更新方案后迁移词库与设置

  

以我使用的简单鹤方案为例。

  

1\. 设置好同步目录，顺便自定义改 installation.yaml 里的设备 ID（这一步非必须，仅仅是便于查找）。

2\. 右键托盘同步，此时在设定好的同步目录下应当自动创建了该设备 ID
同名目录，里面有包括自定义词库在内的一大堆文件。其中，对于简单鹤等方案，比较重要的有两个：

  * luna 的 userdb（存储的是打字的习惯，短语的打字优先级）。 _但某次更新后，变成了 pinyin 的 userdb，所以如果你的迁移横跨了这两次更新，则需要在以下操作到第 6 步前，把同步目录中自动生成的 luna 的 userdb.txt 改成 pinyin.userdb.txt（以简单鹤方案为例，总之就是改成新方案的那个 userdb 的名字，让它能识别合并）。如果没做，到时候就需要做完再同步一次。_ 其他方案以此类推。
  * moran 的 userdb（存储了 Ctrl+T 置顶的词。这些词在更新后已经可以通过 Ctrl+-与 Ctrl+=来上下调整词序）

3\. 退出 Rime 的算法服务，切换其他输入法。

4\. **建议此时手动备份 Rime 文件夹下的文件，避免丢失数据，包括在词库子文件夹里的词库、皮肤等设置。**

5\. 删除 Rime 用户文件夹目录下的所有文件，打包下载 GitHub 的方案 Zip 文件，解压到 Rime 用户文件夹中，重新部署。（若 1
次重新部署无效，再部署 1 次即可）此时应该可以正常打字了。到这一步相当于重新安装了 Rime 方案。

6\. 重新部署后，在 Rime 用户文件夹里应该找到了重新生成的 installation.yaml。在其中设置设备 ID 和同步目录，让 Rime
能够重新识别到先前的同步目录。此时注意，把原本同步目录中自动生成的那个 ID 目录，改名（随便改成什么）。**这是为了让 Rime
误认为那个目录属于另一台设备的词库，从而将它合并进来。** 右击托盘，选择用户资料同步。

7\. 短暂等待后，发现已经同步成功，词库、自定义的置顶词等等应该已经正常了。但皮肤回到了默认状态，说明同步不会改变 Rime 输入法皮肤。

8\. 此时，如果喜欢原本的子文件夹的词库、皮肤设置等，就可以做如下操作：

自定义词库（以简单鹤方案为例）：

在 cn_dicts 找到 my_user.dict，去增量替换；

在 pinyin.dict 里找到并替换所有的自定义词库，同时在 dict 里随爱好自行增加对应的开关；

改变快符：更新后的快符并不好用（个人感觉），请自行在 custom_phrase 文件夹中更改 quick_symbol_phrase，将其改为原本的快符；

改变皮肤：在 weasel.custom.yaml 中修改。（但若皮肤不生效，注意检查下具体方案的 custom
有没有改过，那个也可以存储对应具体方案的皮肤配色、横排竖排等功能。但个人建议以后把这些内容统一存储在 config_color_themes 与
config_styles 中，按需调用，比较整齐。）
_题外话，我现在的体会是：当打字速度上来之后，简单鹤挂接建议使用默认皮肤，最多换一下字号和字体：因为默认皮肤比较简洁，竖排+蓝色高亮显示的首选非常适合音形的挂接输入体验，毕竟音形的首位候选是很重要的。_

若改过默认的方案功能状态，检查两个 config_base 的异同，按需设置；

若改过默认的软件内是否默认英文的设置，在 config_app_options 中加回；

若改过快捷短语、快捷软件，则检查 lua 目录中的 shortcut_config.lua，按需设置；

（个人设置）将字数统计的 py 脚本文件夹复制回原本的目录；在 lua 目录中把 words_counter 也复制回去。
