> 对于很多Windows用户来讲，微软应用商店（Microsoft Store）是个印象不深刻，容易被忽略的好功能。

  

从Windows 8
系统开始，微软开始对其进行了较大的改革，包含功能、界面设计、交互等各方面。其中最具有战略性代表作就是微软应用商店，简称UWP（Universal
Windows Platform），即Windows通用应用平台。你就简单的理解为pc版的AppStore，在里面可以搜索下载各种软件和游戏。

**作为微软代表性作品，那它和传统pc下载的exe应用软件相比有哪些优点呢？**

  1. 它并不是为某一个终端而设计，是一种全新的概念，一款应用可以在所有Win10系统设备上运行，手机 / pc / 平板电脑 通吃，对于开发者和使用者来说都很省事。
  2. UWP应用设计的非常简洁清爽，很纯净，没有任何过多的东西。
  3. 绿色安全。我们知道在网页上下载软件，很多时候往往会给你绑定一大堆没用的垃圾软件，非常恶心，偶尔还会踩雷电脑中毒。而在微软应用商店下载应用一定不会出现这种情况。
  4. 启动速度快，占用内存小 ，安装卸载方便快捷。

  

随着win10的体验越来越好以及市面上大多数笔记本都预装了win10系统，所有越来越多的Windows用户都在使用win10系统，特别是学生和上班族年轻一代群体。

**然而很多人还是习惯之前网页搜索下载软件的习惯，并没有注意到 Microsoft Store 带来的便捷和优点，其实很多应用可在Microsoft
Store里面搜索下载代替传统exe应用程序，以便给自己带来更好的体验** 。

  

Microsoft Store里面优秀的应用有很多，这里就介绍一些实用的给大家。

  

![](https://pic1.zhimg.com/v2-aa07073e0830efe919dab7a3c5b63c18_1440w.jpg)进入微软应用商店入口

  

**1\. Microsoft To-Do**

对于做事情没什么计划的人来说，工作中往往需要一款辅佐工具来记下一天需要做些什么来提高做事的效率。Microsoft To-Do
就是一款很好用的轻量级、简洁待办清单工具。

  

![](https://pica.zhimg.com/v2-c25a1843db6cac8b4e0d24919824bda8_1440w.jpg)

  
左侧为清单分类列表，右侧为具体代办事项。默认有我的一天、重要和To - Do三个清单分类。对于重要的事件可以标星，则出现在在「重要」列表里以便方便查看，To
- Do 则为展现所有的代办事项，哪些完成了，还剩哪些没完成一目了然。  
  
对于有时间段的事项，你还可以添加截止时间，设置提醒，添加分步骤等操作。  

![](https://pic1.zhimg.com/v2-9707cb57d2f5309ce539e369d5014856_1440w.jpg)

  
这样每天早上花几分钟记录好，可以高效合理的完成一天要做的事情，拒绝拖延和遗忘。  
  
  
**2\. 泼辣修图  
**  
一款轻量、高效、顶级的专业修图软件，获得过各类应用商店及摄影爱好者的推荐。作为国内修图软件的翘楚，自然是手机电脑全端覆盖，在pc上如果你有修图需求又不想下载笨重的PS，泼辣修图是你的不二选择，其操作简单，功能强大。  

![](https://pic1.zhimg.com/v2-db28add7b0e1de6f8d5ab3f1a55f3840_1440w.jpg)

  
你可以轻松给照片添加滤镜、蒙版、文字，调整色彩、曝光、光效等，可以说简洁而不失功能。Microsoft Store
提供免费精简版和收费的专业版两个，可以根据个人需求来选。  
  
**  
3\. 画图3D**  
  
无论你是专业的绘画者还只是想随便涂鸦，画图3D都能轻松释放你的创造性。它可以平面画画，也可以绘制炫酷的3D图，大量的画笔和工具带来焕然一新的外观和使用体验。  

![](https://pica.zhimg.com/v2-031802169b689c619b8b393dac915202_1440w.jpg)

  
绘制3D模型  

![](https://pic3.zhimg.com/v2-1bfe52547af30ed1c6a409a0e6cbf2fa_1440w.gif)

如果你有微软的平板，配合触控笔，那使用体验会更加棒。  
  
  
**4\. QuickLook**  
  
苹果用户可能都知道在 OS X 的 Finder
中，有这样一个神操作：选中任意文件（图片、音频、视频、文档、表格、文件夹都可以），只要按一下空格键，就可以快速预览文档内容或者文件夹属性——大家俗称「一指禅」。  
  
而QuickLook 就是一款免费的，也能帮助windows用户通过「按空格键」快速预览文件的工具，这个我之前也推荐过一次，很实用。  

![](https://picx.zhimg.com/v2-b0a276c57a214b74b83d5cf8e57f6893_1440w.jpg)

  
  
**5\. 爱奇艺**  
  
当看电影追剧的时候，你还在为开篇前的广告而烦恼嘛？很多人为了去广告干脆花钱冲个会员。  
  
好吧，怪我没早告诉你。使用 Microsoft Store
里面的爱奇艺客户端，你会发现所有视频0广告！！！播放速度快，没广告，而且整体界面干净简洁看着非常舒适。  

![](https://pic4.zhimg.com/v2-cb89630d665cac51cc9883698c1baa29_1440w.jpg)

  

  
**6\. 微软必应词典**  
  
微软自家产品，亲儿子，一个集阅读、背单词、翻译等为一体的英语学习工具。  

![](https://pica.zhimg.com/v2-3634ae3a3bf70cf0f769fbfffaf39f76_1440w.jpg)

  
  
  
**7\. 网易云音乐**  
  
  
不必多说，很多人都喜欢的音乐软件。每日精准推荐、音乐评论作为它在音乐市场杀出重围的杀手锏。云音乐也是国内最早发布 UWP
版的应用之一，其功能和体验也非常好，不亚于原生的桌面版应用，我自己一直就是使用网易云音乐的 UWP 版听歌。  

![](https://pica.zhimg.com/v2-e09ab7f73e7b165fdd75022707f82846_1440w.jpg)

  
  
除了以上推荐的，还有很多日常使用的软件都有UWP版本，微信、QQ、微博、知乎、B站等等。  
  
至于使用桌面版的exe应用软件更好还是微软的UWP版本更好，那就得看个人的喜好了。我个人建议如果是使用频率很高的话例如微信、QQ、浏览器等，使用桌面版的更好，因为UWP版本的特点是精简，相对桌面版会去除一些功能。而对于使用频次不高的软件，可以使用UWP版本的，占用内存少，启动快，简洁。  
  
Microsoft Store 还有很多应用值得我们去发掘和使用，这次先到这里，下次找到好用的再分享给大家。
