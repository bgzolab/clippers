## 方案一、修改安装包依赖文件后打包安装

> 适用于依赖包升级，安装包未及时更新

### 1.下载向日葵软件

官网地址：[向日葵远程控制软件_app下载_视频监控软件_远程开机软件下载-
Oray贝锐科技向日葵](https://link.zhihu.com/?target=https%3A//sunlogin.oray.com/personal/download/)

根据所使用的平台，选择：Ubuntu/Deepin

下载文件：SunloginClient-10.0.2.24779_amd64.deb

![](https://picx.zhimg.com/v2-26b9e49db50476f4d5d9d595c541c6c7_1440w.jpg)![](https://pic4.zhimg.com/v2-1451787315762a5b7037e63f9b6804ff_1440w.jpg)

### 2.尝试安装

    
    
    sudo dpkg -i SunloginClient-10.0.2.24779_amd64.deb 

![](https://picx.zhimg.com/v2-ad2cfc12d9c02d40bdf58250acdc58bb_1440w.jpg)

出现依赖问题。

### 3.依赖问题解决

> 文章的最后还有两种方式解决，解决方式为安装libwebkitgtk 3.0-0包，一种是寻找各种依赖逐一进行安装，解决；另一种是添加Ubuntu
> 18版本的源下载，如有需求可进行查看

在Ubuntu 20.04版本，libwebkitgtk 3.0-0是Ubuntu 18
版的依赖包，在20.04版本中使用libwebkit2gtk-4.0-37包进行替代，具体替代方法如下：

1.解开deb文件

    
    
    dpkg-deb -X SunloginClient-10.1.1.38139_amd64.deb sun

2.解开依赖文件

    
    
    dpkg-deb -e SunloginClient-10.1.1.38139_amd64.deb sun/DEBIAN

3.修改control文件

    
    
    vim sun/DEBIAN/control

![](https://pic3.zhimg.com/v2-9de9fd1b950f49cb4dc0ae04099d1300_1440w.jpg)

4.修改文件内容

将libwebkitgtk 3.0-0修改为libwebkit2gtk-4.0-37

![](https://pic1.zhimg.com/v2-6102ffc722d74b87c61e418117884daa_1440w.jpg)

5.重新进行打包

    
    
    dpkg-deb -b sun

参考文章地址：

[解决向日葵软件在Ubuntu
20.04依赖libwebkitgtk-3.0-0等问题](https://link.zhihu.com/?target=https%3A//www.jianshu.com/p/289001a00cb1)

### 4.安装

    
    
    sudo dpkg -i sun.deb
    #其他两种方式安装原来的安装包，方式为sudo dpkg -i SunloginClient-10.0.2.24779_amd64.deb 

即可安装成功，正常登录使用，实测有效。

## 方案二、针对缺失依赖逐一下载安装

> 寻找依赖麻烦，安装过程可能出现问题，解决费劲不推荐

### 依赖部分问题解决-逐一安装依赖

> 此方案，如果系统中安装deepin-
> wine版微信，会出现libjpeg62:i386，与libjpeg62-turbo包冲突问题，无法完成安装，仅做备选方案

1.安装wget

    
    
    sudo apt install wget

2.下载libwebkitgtk 3.0-0及其相关依赖

libwebkitgtk-3.0-0下载地址：[http://ftp.br.debian.org/debian/pool/main/w/webkitgtk/libwebkitgtk-3.0-0_2.4.11-3_amd64.deb](https://link.zhihu.com/?target=http%3A//ftp.br.debian.org/debian/pool/main/w/webkitgtk/libwebkitgtk-3.0-0_2.4.11-3_amd64.deb)

libicu57下载地址：[http://ftp.br.debian.org/debian/pool/main/i/icu/libicu57_57.1-6+deb9u3_amd64.deb](https://link.zhihu.com/?target=http%3A//ftp.br.debian.org/debian/pool/main/i/icu/libicu57_57.1-6%2Bdeb9u3_amd64.deb)

libjavascriptcoregtk-3.0-0
下载地址：[http://ftp.br.debian.org/debian/pool/main/w/webkitgtk/libjavascriptcoregtk-3.0-0_2.4.11-3_amd64.deb](https://link.zhihu.com/?target=http%3A//ftp.br.debian.org/debian/pool/main/w/webkitgtk/libjavascriptcoregtk-3.0-0_2.4.11-3_amd64.deb)

libjpeg62-turbo下载地址：[http://ftp.br.debian.org/debian/pool/main/libj/libjpeg-
turbo/libjpeg62-turbo_1.5.1-2_amd64.deb](https://link.zhihu.com/?target=http%3A//ftp.br.debian.org/debian/pool/main/libj/libjpeg-
turbo/libjpeg62-turbo_1.5.1-2_amd64.deb)

    
    
    sudo apt install libegl1-mesa
    wget -c http://ftp.br.debian.org/debian/pool/main/w/webkitgtk/libwebkitgtk-3.0-0_2.4.11-3_amd64.deb
    wget -c http://ftp.br.debian.org/debian/pool/main/i/icu/libicu57_57.1-6+deb9u3_amd64.deb
    wget -c http://ftp.br.debian.org/debian/pool/main/w/webkitgtk/libjavascriptcoregtk-3.0-0_2.4.11-3_amd64.deb
    wget -c http://ftp.br.debian.org/debian/pool/main/libj/libjpeg-turbo/libjpeg62-turbo_1.5.1-2_amd64.deb
    sudo dpkg -i libjavascriptcoregtk-3.0-0_2.4.11-3_amd64.deb
    sudo dpkg -i libicu57_57.1-6+deb9u3_amd64.deb
    sudo dpkg -i libjpeg62-turbo_1.5.1-2_amd64.deb
    sudo dpkg -i libwebkitgtk-3.0-0_2.4.11-3_amd64.deb

附上：libwebkitgtk 3.0及相关依赖下载地址：

[https://debian.pkgs.org/9/debian-main-
amd64/libwebkitgtk-3.0-0_2.4.11-3_amd64.deb.html](https://link.zhihu.com/?target=https%3A//debian.pkgs.org/9/debian-

## 方案三、添加Ubuntu 18版本的源

> 感觉没啥必要，技术向前看，总感觉添加完怪怪的，还是推荐第一种方案

### 依赖部分问题解决-添加Ubuntu 18版本的源（感谢 [@自我实验室-
村君](https://www.zhihu.com/people/ee31e10ce203afd015a7db0f5e19a8c9) 分享）

1.打开并编辑/etc/apt/sources.list 文件：

    
    
    vim /etc/apt/sources.list

2.在/etc/apt/sources.list 文本末尾添加:

    
    
    deb http://mirrors.aliyun.com/ubuntu/ bionic main universe

3.保存并关闭vim操作方式为进入命令模式：wq

4.安装libwebkitgtk-3.0-0

    
    
    sudo apt update
    sudo apt install libwebkitgtk-3.0-0

libwebkitgtk-3.0-0_2.4.11-3ubuntu3_i386.deb](https://link.zhihu.com/?target=https%3A//packages.ubuntu.com/bionic/i386/libwebkitgtk-3.0-0/download)
