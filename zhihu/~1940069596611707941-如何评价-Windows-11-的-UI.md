**这位网友的 “好哥们儿” 在微软工作，他评价说：**

![](https://picx.zhimg.com/50/v2-b0c4d184bdd47601b28113d683f241b1_720w.jpg?source=2c26e567)

我听说问题在于，现在已经没有 “负责人” 了。自从 Windows 被划入 E&D 部门后，简直没人站出来说要为 Windows 负责。

因此，像 WebXT 这样的部门（就是那些在系统里强行塞广告、逼用户用 Edge 浏览器之类的人）现在随心所欲，完全没人管。

在微软，Windows 不再是一级产品了，它的层级在 CEO 之下三层还多，和 Teams、OneDrive 是一个级别…… 难怪它会变得一团糟。

要我说，这也太离谱了。

附：这是我从微软员工朋友那里听来的二手消息。

**这位网友疑似在微软工作过，他评价说：**

![](https://picx.zhimg.com/50/v2-ab1657ef1ff17913e4ccc57bb9e465f0_720w.jpg?source=2c26e567)

微软内部满是怒气冲冲的人，每个人都在互相生对方的气，因为公司里的每个人都不断被朋友和亲戚的愤怒抱怨轮番轰炸。

在鲍尔默执掌的十年里，他解雇了所有不擅长推诿耍滑的人（美其名曰 “无憾离职”），结果公司里满是那些 90% 的时间根本不干活的人。

公司对用户进行了大量的监控（美其名曰 “遥测”），但我所看到的是，这些数据唯一的用途就是用来推诿责任。“哦，只有 5% 的用户用那个功能”，或者
“哦，那个漏洞的发生率只有 0.1%”。

当然了，要是你用的产品有 1000 个漏洞，每个漏洞在任意一个月的发生率都是 0.1%，那你肯定会一直遇到漏洞。

**这位网友真的在微软工作过，他评价说：**

![](https://picx.zhimg.com/50/v2-4d98dcb8b75a234759946470b06326d2_720w.jpg?source=2c26e567)

回复 “这简直就像某个小型极端派系掌控了 Windows 一样”：

这种情况已经有段时间了。我曾在 Windows 桌面体验团队工作，经历了 Win7 到 Win10 的开发。大概从 Win8
开始，设计师就完全掌控了局面，而最关键的是，基本上没有哪个设计师用 Windows 系统。

在职业生涯中，我花了太多时间坐在会议室里，向那些带着崭新 MacBook 的新设计师（他们似乎每 6 到 18
个月就换一批）解释：为什么某些想法在可用性研究中试过了却行不通，因为我们的用户需要的是 X、Y、Z 这些东西。

有时候，我们会说 “好吧，要是真要做这个，得花 N
个开发人年”，用这种方式暂时避开一些事，但更多时候，我们的意见会被明确否决。我曾极力反对一些设计，比如全白的标题栏 ------
这让用户根本分不清哪个是活动窗口、哪个是非活动窗口（记不清是 Win10 还是 Win8 了，反正用户反馈太强烈，下一个更新就改回去了）；还有 Edge
的标题栏顶部没有留白，要是窗口超出右侧边缘，又开了太多标签页，就根本没法移动窗口，诸如此类。

团队里其他人则反对 Win8 去掉开始按钮，还努力想在 Win8 的开始屏幕上加分区标签，让用户清楚可以在不同分区间滚动，等等。最后，设计师得偿所愿，那些说
“好的，我们能做到” 的工程师得到晋升，而我们这些为用户据理力争最激烈的人，要么身心俱疲，要么退休，要么离开了这个团队。

我可能还认识那个团队里的一些人，我觉得他们是朋友，也很聪明，但在虚拟机里试了 Win11
之后，我真的很想找他们中的一些人坐下来聊聊，到底发生了什么。目前来看，这是自 ME 之后，我第一个没有在发布时就升级的消费级 Windows
系统，而且除非他们把侧边任务栏还给我，否则我是不会升级的。

**我跟微软没有半毛钱关系，我评价说：**

感觉 UI 设计正在朝着不好的方向发展，这不仅仅是微软一家的事儿！

我接触到的一些设计师，他们是真的把产品当 “现代艺术品” 来设计，来呈现 ------ 但那个东西本质是工具啊，是让人用的。

这就挺不好的，也可能因为我是码农出身，更看重实用那部分！
