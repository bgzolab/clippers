互联网产品就是要防小人，不防小人，小人就会薅光你羊毛。

DeepSeek 的 API 已经是白菜价了，网页版还免费，这够意思了吧，但是也挡不住小人的贪婪，这些小人已经形成了产业，有羊毛就薅，有便宜就占。

已知（但不是唯一）的小人就是架反向代理，以普通用户的身份访问 DeepSeek 网页版，免费获得结果，但是对另一边暴露 API ，伪装成 Claude 或者
GPT 这样高价 Tokens 的API代理。

人要是贪起来，连白菜价的 DeepSeek 的 API 费都不愿意给，宁可操卖白粉的心去扒取 DeepSeek 的免费网页版。

这其实也是一个漏洞，要禁绝这种漏洞，最简单直接有效的方法，就是对单个用户限流。

毕竟正常人类哪有狂刷重复生成的，狂刷的访问可以诊断为大概率就是恶意羊毛党。

这就是互联网上的攻防战，任何产品都会有可利用之处，肯定会有人消减了脑袋来恶意利用的，都得要防一手，不，一手不够，要处处提防。

一般来说，对付恶意利用的方法，道德上谴责都是浪费时间，羊毛党就没道德，能做的是要让他们意识到付出的代价要比获得的收益要大，他们就退缩了，至少暂时退缩，毕竟没人愿意做亏本生意。

不过，DeepSeek 的 API 都这么便宜了，羊毛党还要去薅免费网页版，真实突破了我的认知底线。

这不，反制就来了，总要让他们多付出一些代价，他们就老实（一阵子）了。
