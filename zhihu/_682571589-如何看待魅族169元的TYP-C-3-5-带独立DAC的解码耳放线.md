先把结论放到前面

如果你手上有魅族 16s 或其它支持 Type-C 口的耳机，售价 169 元（配合 16s 购买只要 99 元）的魅族 HiFi
解码耳放是一个**相当超值的选择，很有成为下一代「神线」的潜力。**

当然，这个「超值」的**前提是你手上有一个素质较高的 3.5 毫米接口耳机** ，否则这根「神线」也发挥不出能力。

如果你对音质没那么看中，我们依旧认为无线耳机代表了一个更加广阔的未来，相关的推荐大家可以阅读极客之选的[无线耳机专题推荐](https://link.zhihu.com/?target=https%3A//mp.weixin.qq.com/s%3F__biz%3DMzA5MTMyNTYzNA%3D%3D%26mid%3D2663972565%26idx%3D1%26sn%3Dc08fefc78266cb368335481cf692e259%26scene%3D19%23wechat_redirect)。

详细体验

![](https://pic1.zhimg.com/50/v2-d33040c66dac7e3ea29e139751fdba41_720w.jpg?source=2c26e567)

在聊魅族 HiFi 解码耳放这根 Type-C 转 3.5 毫米音频线之前，我们先简单说说用 Type-C 接口听歌这事。

过去几年里，越来越多的手机选择砍掉 3.5 毫米耳机插孔，这种情况下，为了让手机使用之前的 3.5
毫米接口耳机听歌，就只能「倚仗」手机剩下的那个数据接口了（iPhone 是 Lightning，多数安卓机是 USB Type-C），于是就有了
Lightning 转 3.5 毫米转接线和 Type-C 转 3.5 毫米转接线。

其中，Lightning 接口只能输出数字音频信号，为了在 3.5 毫米端输出可以驱动耳机的模拟音频信号，就必须在转接头中内置解码和放大芯片，苹果在近几代
iPhone 里随即附送的 Lightning 转 3.5 毫米线就采用了来自 Cirrus Logic 的定制芯片。

Type-C 这边的情况有些特殊，这个接口除了可以输出 Lightning
这样的数字信号，还可以直接输出经过手机内部解码和放大过的模拟音频信号，这个模拟信号可以直接用来驱动耳机，转接线要做的只是将模拟信号以 3.5
毫米的「形式」输出给耳机，这一类的 Type-C 转 3.5 毫米音频线通常被成为「模拟线」。

相比起 Lightning 这种数字线，模拟线不需要内置解码和放大芯片，结构简单了很多，成本自然低不少，目前多数安卓手机标配的是类似的「模拟线」。  

![](https://picx.zhimg.com/50/v2-a01a8491c4b0a86cb918e2e33618c903_720w.jpg?source=2c26e567)

##  HTC「神线」和魅族 HiFi 解码耳放

不过受限于手机内部的音频设计，「模拟线」的音质通常水准不会太高，好在 Type-C 口还可以像 Lightning
接口这样输出数字信号，数字信号再经过解码和放大，通过 3.5 毫米插孔传给耳机，这种线叫做「数字线」，其中最有名的应该就是 HTC 在 U 系列（U
Ultra、U11/U11+、U12+ 等）上附送的那根「神线」了。  

![](https://picx.zhimg.com/50/v2-6a91c07d94d95ddc0d35abdaf2822e7b_720w.jpg?source=2c26e567)

  
回到魅族 HiFi 解码耳放上，这款产品也是一根「数字线」，内置的 codec 为 Cirrus Logic CS43131，它的动态范围可以到
120dB，谐波失真低于 0.0003%，最高支持 32bit/384kHz 的 PCM 解码，规格已经足够放在两千档的 HiFi
播放器上了，怼到「数字线」里的确足够「HiFi」了。  
  
值得一提的是，魅族 HiFi 解码耳放并没有这颗高规格的芯片导致体积过大，4 克的重量和小巧的尺寸并不比一些「模拟线」大多少。此外，魅族 HiFi
耳放还把芯片部分做成了透明设计。  

![](https://picx.zhimg.com/50/v2-dcd6387e9e41e9e8b044be4f0809db93_720w.jpg?source=2c26e567)

  
需要提醒的是，目前大多数手机的 Type-C 可以支持模拟音频和数字音频输出，不过不知道出于什么原因，魅族 16s 的 Type-C
只支持数字音频输出，所以如果你想用 3.5 毫米耳机插孔听歌，必须用魅族 HiFi 耳放或者 HTC「神线」这样的「数字线」，「模拟线」是出不了声的。  

![](https://picx.zhimg.com/50/v2-f7cea656cb44f1b2f1220192ce5918ff_720w.jpg?source=2c26e567)

  
音质方面，我们拿乐之邦 MU2（左一）、 HTC「神线」（左二）、绿联「模拟线」（右一）简单做了对比。

不出意料，绿联的这颗 20 块钱的「模拟线」基本没啥战斗力，凭借较为凶猛的「堆料」，魅族 HiFi 解码耳放的表现相比 HTC「神线」也有比较明显的优势。

相比乐之邦 MU2，我个人认为搭载 Cirrus Logic CS43130 和定制主控、时钟管理器的 MU2 有着更好的驱动力和扎实的低频，但 MU2
的体积更大、发热更高，售价也要高很多（目前 MU2 已停产，升级版 MU2+ 售价 699 元），魅族 HiFi 解码耳放对比之下依旧是一个值得考虑的选择。  

![](https://picx.zhimg.com/50/v2-d33040c66dac7e3ea29e139751fdba41_720w.jpg?source=2c26e567)

  
总结下，如果你手上有魅族 16s 或其它支持 Type-C 口的耳机，售价 169 元（配合 16s 购买只要 99 元）的魅族 HiFi
解码耳放是一个相当超值的选择，很有成为下一代「神线」的潜力。
