如图所示，在iPad上看到了Windows系统界面，渲染分辨率与iPad屏幕分辨率完全一致，配有键鼠和一台安卓手机，全设备无线连接。我在**串流** 。

**串流是指通过网络将一台主机的桌面画面和声音以视频流的方式实时传输到其他设备显示，并让远程设备通过网络将键盘、鼠标等输入操作同步到主机，实现异地访问、操控并完整复用主机硬件性能和原生系统功能的解决方案。**

如果按下Ctrl + Shit +
Esc，能看到CPU是按摩店7945HX，显卡是4060。它们是我游戏本上的硬件，在松江的家里，而我人和iPad在20公里外的杨浦某校图书馆。因为这套串流解决方案支持读取Win+为代表的Windows原生快捷键，所以我可以在这台iPad上无障碍地完成代码、论文、用pr剪视频。

串流用到的软件生态是开源的moonlight+sunshine，原版就可以用。不过我为了增强体验都用了二改版本，大部分是免费的。电脑上用Sunshine基地版，iPad上用VoidLink（尽管名字不叫月光，主要是ui重制和游戏优化），安卓手机上用月光-
阿西西。

很多人以为iPad因系统限制无法读取Win+快捷键，成为iPad远控Windows的最大阻力，这是事实。但他们忽略了视频流和控制流逻辑上是可以分开的，你完全可以让iPad仅承担显示功能，而用其他工具远程**控制**
Windows PC。

在我的解决方案中，我同时用一台安卓手机和iPad远程串流Windows电脑，保持接收分辨率一致。此时电脑只生成一个虚拟显示器，且允许双设备以相同分辨率串流同一台电脑。键鼠外设连接安卓手机，在开启应用无障碍功能下完成含Win+快捷键在内的键鼠控制流传输。如果担心双设备串流拉高网络负载，可以把手机视频码率限制到0.5Mbps，并不影响远控效果；iPad用20~40Mbps就足够流畅清晰了。

网络问题不难解决。有公网ip的固然方便，没有的也可以用免费的Zerotier、皎月连等进行内网穿透。延迟也是毫秒级别的，玩《Hitman》完全无问题。

键盘是某东80买的BOW无线，手感和拯救者笔记本差不多，键程还略微长一些，反正码字肯定不比笔记本差。鼠标是小巴蛇，稍微贵一点，但侧键够强，且映射键盘快捷键就能正常使用。我常用Ctrl
+ C V X K等。虽然外设看起来没那么优雅，但想让它变轻，砸钱就可以。而且不需要你去买妙控键盘，因为连的是安卓手机。

那有会问用安卓平板岂不是绕过了“双设备”框架，单个平板就能实现远程看屏幕和控制？我的答案是“对”，这也是我摸索出这套“针对已经有iPad用户的解决方案”之前的朴素想法。但不需要或需要iPad的理由是多维度的，**这里的解决方案只是扫清一重障碍**
。
