今日访问github，突然发现无法访问，明明上周工作还能用，一度以为墙又高了。

最后发现是dns解析问题，发现域名解析到127.0.0.1。

  

![](https://pic4.zhimg.com/v2-1bc0e2bd6f2234597ad0841a41756c7f_1440w.jpg)

  

家庭使用广州电信的首选dns和备用dns的情况下，github解析到127.0.0.1

  

![](https://pic1.zhimg.com/v2-cb814b74e32c8021faeea4f099fdab62_1440w.jpg)DNS设置

  

  

![](https://pica.zhimg.com/v2-1166525f8941338bc1a07a9f03c7f942_1440w.jpg)路由器自带诊断工具

  

看到这里我甚至以为我路由器出了问题。

使用nslookup指向广州电信dns试试

  

![](https://picx.zhimg.com/v2-b410b71e4ee96d1af344182c1c1c5f3f_1440w.jpg)手动nslookup测试

  

并没有冤枉他。

使用互联网多地ping，发现广东广州和深圳的电信自动指向127.0.0.1

  

![](https://pic2.zhimg.com/v2-a17942d6c0f39cdc494a258a2c8d8f49_1440w.jpg)多地ping

  

可恶，又是运营商的DNS污染 。

解决方案：

1、指定DNS为其他知名DNS服务器：如1.1.1.1，8.8.8.8等（速度可能会慢一些）；

2、添加hosts文件记录，将github的ip地址增加进去；

3、评论区推荐DoH、DoT（DNS over HTTPS、DNS over TLS）
