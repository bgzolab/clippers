## 方案1

android 手机用wine可以打开

wine可以把exe的x86的指令翻译为arm。并且翻译windows下的 API 为 android下的 API

[wine下载链接](https://link.zhihu.com/?target=https%3A//dl.winehq.org/wine-
builds/android/wine-3.0-arm.apk)，官方版本。（官方版本需要外置键盘，并且手机设置成英文，才能使用）

另外，有一些软件基于wine修改，比如exagear。这种软件不需要外置键盘，并且手机不需要设置成英文。但是要么收费，要么收集隐私。有破解版，但是安全性不能保证。如果你有能力，可以自己编译wine

android 版wine可以运行大多数window xp时代的软件。但对于高版本NT系统的软件支持不是很好

## 方案2

**大多android 是arm架构，可以安装 Windows10 arm版。 Windows10
arm版的x86指令翻译效率高于wine。有人在手机上刷入windows10 成功过**

[小米6成功刷入Windows 10
ARM64](https://link.zhihu.com/?target=https%3A//new.qq.com/omn/20200413/20200413A09FKL00.html)

但我不建议直接在刷入物理设备，我建议在手机上安装容器后再刷入容器中，这样不会影响真的系统。

如果你的手机有root权限，建议使用linux deploy容器，它可以跑出最高性能

如果你的手机没有root权限，建议使用Termux+AnLinux容器,它不需要root权限。性能一般。

如果你什么都不会，懒得动脑，又愿意用隐私换取便利。可以试试一款盗用github上[GPL协议](https://link.zhihu.com/?target=https%3A//baike.baidu.com/item/GPL/2357903)源码，又不开源的软件：wmos
pro（专家看来是容器，不是虚拟机。官网混淆两者概念）。优点就是操作简单，不需要动脑。性能一般。但是广告特别多。

[linux
deploy下载地址（开源软件）](https://link.zhihu.com/?target=https%3A//github.com/meefik/linuxdeploy)[Termux](https://link.zhihu.com/?target=https%3A//termux.com/)[AnLinux下载地址（开源软件）](https://link.zhihu.com/?target=https%3A//github.com/EXALAB/AnLinux-
Adfree)

Windows10 arm仅能运行32位x86 架构的exe（通过x86翻译）和arm 架构的exe（32位，64位都行）

  

## 方案3

安装虚拟机

不推荐，因为虚拟机卡。相同性能下，通过linux deploy容器
或Termux+AnLinux容器，可以跑windows10系统，但是通过虚拟机只能跑windows xp系统（arm架构上，虚拟机性能折损太大了）

如果要安装，可以试试bochs虚拟机，qemu虚拟机。都是开源虚拟机。可以基于arm架构来虚拟化。都有android版本

都是开源虚拟机，为什么不推荐VirtualBox呢？ 因为VirtualBox基于x86架构来虚拟化。手机上是arm架构

但是虚拟机不是通过arm API翻译来运行x86程序的。可能兼容性高一些吧
