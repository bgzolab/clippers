今年，我最开心的事情是我有了一个小棉袄，我做爸爸了。

还有一个开心的事情是发现了南大的蒋yy老师。

初次看他的视频，语速飞快，敲代码快的飞起，看他敲击命令就像看高手打水漂，石头歘歘就飞过去了。还得回放暂停才看的清。

好家伙，这也太装逼了，快的都不让学生看清楚，我们老师写的都是伪代码，他来真的，而且让他装成了，他的代码，抄下来就能运行。

jyy是我见过的计算机基础最好的人，如果读书那会知道他，我就不需要上计算机课了。

你知道他怎么装的吗？

他有一个视频。讲静态库的链接和加载，前面十分钟就信息量很大。

![](https://pic1.zhimg.com/50/v2-afd2043e2ba0277aa54995fb6af0b34b_720w.jpg?source=2c26e567)

  

看这个帅气的男人，他说：程序是状态机，操作系统里面everything is a file,
摄像机数据、鼠标数据是字节流文件，磁盘数据是字节数组文件，比如我们常用的ls命令，其实是个可执行文件，在

/bin/ls下面。可以运行，同时可以编辑，比如 vim 里面编辑。

接下来装逼时刻到了，他在里面敲击了:%!xxd, 乱码一样的二进制文件立刻变成漂亮的文本文件。

:%!xxd

我草，这是啥。:我知道，%表示全局我也了解，**！是啥？xxd是啥子？** 我vim用的少，不要骗我。

  

我自己试验了下：

vim /bin/ls,显示只读的二进制文件

![](https://pic1.zhimg.com/50/v2-a395e1f614919bcf6dd66f7211742fd5_720w.jpg?source=2c26e567)

按esc，输入:%!xxd

我擦。回车后就好看了，elf都出来了。

![](https://picx.zhimg.com/50/v2-373ec776a04d04e676c7705938a177e4_720w.jpg?source=2c26e567)

  

我再查了下：:%!xxd，一共四个知识点 ： % ！ xxd

![](https://picx.zhimg.com/50/v2-9b87426ada9b792cca98247582d6b3f1_720w.jpg?source=2c26e567)

  

我擦，这个好像很有用，但是为没有用过。

：进入命令模式，可以执行set sed 等命令，但是还可以用！在不退出vim时执行终端命令

我在vim里面 :!ls 就输出了为当前目录下的所有文件。

![](https://pic1.zhimg.com/50/v2-50927f61358a68cc43b6e6405f32dc2c_720w.jpg?source=2c26e567)![](https://picx.zhimg.com/50/v2-581cccc8119e7c2a2ee03e921f1e5368_720w.jpg?source=2c26e567)

  

  

这样就清楚了，

在vim里面:%!xxd

就等效于 xxd /bin/ls

或者用cat读再送管道：cat /bin/ls | xxd

  

然后 :%!xxd -r 就是返回二进制显示。

  

:%!xxd 后把7f45 4c46 改成 7f45 4c47

然后 :%!xxd -r 返回二进制显示，发现ELF变成了ELG

![](https://pic1.zhimg.com/50/v2-7cfdb498fae4472a74b73eccfbdf3a2a_720w.jpg?source=2c26e567)

  

![](https://pic1.zhimg.com/50/v2-b4d670a8dcec72045bd791263c39ea38_720w.jpg?source=2c26e567)

  

jyy 说不能修改，否则出问题，我就改，直接:wq!修改不了，发现

sudo vim /bin/ls 就可以改了，后果是输入ls或者/bin/ls：

![](https://picx.zhimg.com/50/v2-a5ed88b65a8b537dea7487a498f33ff3_720w.jpg?source=2c26e567)

sudo vim /bin/ls 把 7改回6：

![](https://pica.zhimg.com/50/v2-68487a6a0b135d12265833d3873994d6_720w.jpg?source=2c26e567)

我草。不行了，玩完，没有保存。

我先保存被弄坏的ls:

cp /bin/ls ls2

dir可出看到ls2,我擦，这个linux里面可以用dir替代一下。

文心就我一命：

![](https://picx.zhimg.com/50/v2-744df51025228a0464c5f6510086e21b_720w.jpg?source=2c26e567)

  

sudo apt-get install --reinstall coreutils

![](https://picx.zhimg.com/50/v2-a47212ea334e41d82fde88b1860819ae_720w.jpg?source=2c26e567)

他怎么知道我改了ls?

然后奇迹出现了：

/bin/ls 和 ls都可以了。

然后我最想要做的是比较新安装的ls和我改了又恢复的ls哪里不一样：

diff /bin/ls ls2

输出：二进制文件 /bin/ls 和 ls2 不同

md。哪里不同也不告诉我，这不是我要的结果呀。

![](https://pic1.zhimg.com/50/v2-3e3ab78ae757bac5d3ed4f7526e2b2b5_720w.jpg?source=2c26e567)

  

这样可以看出不同，但是太多了。搞不懂为啥。

  

后面我反复试验，发现：

1：sudo vim /bin/ls

如果我直接把ELF改ELG.

报错是：

![](https://picx.zhimg.com/50/v2-68487a6a0b135d12265833d3873994d6_720w.jpg?source=2c26e567)

这个和我在文本格式修改是不一样的错误，这个应该还是二进制格式，只是找不到

elf, executable link file ,就执行不了了，上面我改了6成7
，就直接找不到命令了，就不是一个二进制文件了，喔喔，对呀，我改成7没有放回二进制，就是文本格式当然不能运行了。

![](https://picx.zhimg.com/50/v2-0291749162640a42db00e7dd3575c138_720w.jpg?source=2c26e567)

2:sudo vim /bin/ls

我 进入文本格式，把6改成7，再返回 二进制格式，保存，报错和1一样。

方法1 和2 可以直接进去把G改成F，就恢复了。

3：sudo vim /bin/ls

我 :%!xxd 进入文本格式，把6改成7，保存，再:%!xxd -r回到二进制，这个就是我第一次的方式，这样就不行了，

再怎么重新修改都回不去了。

综合1 2 3 ，不能在:%!xxd 后的格式下保存文件，需要:%!xxd -r放回到二进制保存才能回复可执行文件。我sudo vim
/bin/ls,接着%!xxd进去文本格式，不做修改，直接:wq!,不出我所所料，找不到ls命令了，这时候sudo vim
/bin/ls发现是文本格式，:%!xxd -r回到二进制保存，这样不行，这一点奇怪，vim里面二进制能改成16进制，16进制不能改回二进制！

一般人到这里就结束了，贯彻jyy提到的hack精神。

3为啥不行，既然二进制能转成16进制度，那么就算保存成16进制文本文件，应该还是能转回二进制的，既然vim里面改不行，我在终端试试。

于是，我做了一个大胆的实验，

实验4：我sudo vim /bin/ls,接着%!xxd进去文本格式，不做修改，直接:wq!,然后找不到ls 命令了。

接着我在终端反转化

sudo xxd -r /bin/ls > /bin/ls

我想把16进制改回二进制，然后覆盖修改的ls原文件，因为我就改了格式，改回去这样不就可以吗？

报错：

bash: /bin/ls: 权限不够

喔，第一个sudo有权限，第二个写没有，我记得yjj 之前讲过的：

![](https://picx.zhimg.com/50/v2-2e681af94b011a75540cc0785b305ae0_720w.jpg?source=2c26e567)

他给了一个重定向失败的例子；他说：重定向和管道是先把文件描述符准备好再执行sudo，左右两边的命令文件描述符在准备的时候没有权限。所以执行失败。

膜拜！

迂回一下子：

sudo xxd -r /bin/ls > kkkkk

sudo cp kkkkk /bin/ls

先重定向再拷贝

  

ls输出：

  

![](https://picx.zhimg.com/50/v2-5a2194a9513e1084031e535537cd6396_720w.jpg?source=2c26e567)

终于可以恢复ls了！！

原本，我只是想写写在老师那里学到的一个命令，结果突发奇想把老师没有保存的7保存了，增加了许多实验，边输出边学习，计算机里面的细节真多。

毕业五六年，计算机专业的我感觉才开始学计算机。研究生毕业的时候我不知道什么是管道、什么是重定向、什么是内核态、什么是内存分页。不知道vim里面gg就是返回首行，不知道dd是删除一行，dG是删除全文，u是撤销操作，不知道我今天写的这些知识。

上学那会，老师是浙大的博士，总是吹牛说自己数学多么好，编程多么棒，然而，除了吹牛，我没见到他讲好一个公式，演示一行代码。

装逼不可怕，就怕没实力还装。

最后，其实用不用vim无所谓，要不是工作出差经常是无界面的系统而且没有网络，我也不用vim。但是就像蒋炎岩说的，vim里面有unix里面的哲学思想，无用也是大用。
