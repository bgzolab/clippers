讲真的，Windows 的软件生态，一直都有点魔幻。

你想安安静静装个软件，却总感觉像是在玩扫雷。

搜索排名第一的永远不是官网，下载按钮旁边总藏着暗坑，一不小心就是全家桶伺候。

明明是2026年了，装个软件还需要像做贼一样小心翼翼。

直到最近，我挖到了这个叫做 **UniGetUI** 的开源神器。

![](https://pic3.zhimg.com/v2-59d48640c9393fc971558db0eed8ee80_1440w.jpg)

装上它那一刻，我的 Windows 终于清静了。

今天就跟大家，聊一聊它。

先简单说下它的逻辑。

其实微软为了解决乱象，早就搞了个官方神器叫 **WinGet** ，干净、官方、库极其全。

但问题是，这玩意是个命令行工具。

你需要打开那个黑乎乎的框框，输入 `winget install xxxx`。

![](https://pic1.zhimg.com/v2-a2b85ada4fa6b7738e2b8201d3bec6a0_1440w.jpg)

这对程序员来说叫高效，但对我们普通用户来说，这叫劝退。

而 **UniGetUI** 做的事特别直接：

它给这个强大的内核，穿上了一层每个人都能看懂的、漂亮的图形化界面。

而且，它不只是支持 WinGet。

它把 Scoop、Chocolatey、Pip 这些大名鼎鼎的极客包管理器，全都聚合在了一个类似应用商店的界面里。

![](https://picx.zhimg.com/v2-93c2443e95491c96a2303f6211889e0d_1440w.jpg)

简单说就是。

如果你觉得自带的微软商店像个缺货的店铺。

那这玩意，就是把全网的商品都搬到了你面前，要啥有啥。

另外项目在 GitHub 上已经拿到了 20.4k 的 Star，这数据，在开源界已经是顶流了。

![](https://pic3.zhimg.com/v2-c8e14afb35d98667f5ec9ec1898efcb4_1440w.jpg)

你想装什么，直接在顶部的搜索框里搜即可。

比如我想装个 Chrome，搜一下，勾选，点安装。

完事。

没有下一步，没有捆绑，没有那些乱七八糟的干扰。

它会自动去官方源或者受信任的源下载，然后静默安装。

你需要做的，就是看着进度条跑完，然后开始用。

但这还不是最离谱的。

![](https://picx.zhimg.com/v2-6e188c03d1103ab4919e1d3ed51737c3_1440w.jpg)

最离谱的，是它的 **批量更新** 。

你们肯定有过这种经历：

打开电脑，右下角这也弹窗说要更新，那也弹窗说要更新，点进去还要跳转网页下载安装包，烦得要死。

在 UniGetUI 里，你点一下软件更新那个标签。

![](https://pic3.zhimg.com/v2-eb6ec85dc9fc65ad1fe167a455a0fa5e_1440w.jpg)

它会把你电脑上所有能更新的软件，全列出来。

然后，你只需要做一个动作：

点击右上角的 **更新所选软件包** 。

然后你就可以去倒杯咖啡了。

它会在后台，一个接一个地，把你电脑上几十个软件全部更新到最新版。

那种看着列表一个个变绿的感觉，对于强迫症来说，真的，太治愈了。

![](https://pic4.zhimg.com/v2-4cb94c691cfc72debecf3d1522a670ad_1440w.jpg)

而且，它还支持导出和导入。

这简直是重装系统爱好者的福音。

你可以在旧电脑上导出一个列表文件，等到了新电脑上，把 UniGetUI 装好，把列表文件一拖进去。

它就开始全自动帮你把熟悉的软件一个个装回来。

不用再去一个个搜官网，不用再去一个个找安装包。

这才是科技该有的样子啊。

![](https://pic4.zhimg.com/v2-9bfdcee9701a2908074144900147beaf_1440w.jpg)

不过，这里必须要**特别提醒** 大家一件事。

因为这工具太火了，所以网上出现了很多第三方的。

大家下载的时候一定要擦亮眼睛，不要去信那些第三方的所谓官网，很多都是假的。

最稳妥的方式，还是直接去 GitHub 或者正规渠道下载。

![](https://pic1.zhimg.com/v2-e0957cc8e3cb7bdcab43272ca906af44_1440w.jpg)

说实话，用了 UniGetUI 之后，我最大的感受不是方便，而是尊严。

我们使用电脑，是为了创造，为了娱乐，为了生活。

而不是为了跟流氓软件斗智斗勇，不是为了在满屏的陷阱里找那个真正几 KB 的链接。

软件，本该就是这么简单、纯粹、且安静的。

UniGetUI 做的，其实就是把这种控制权，重新交回到了我们手里。

它让我们知道，在那个充满了干扰和捆绑的互联网之外。

还有这么一群人，在用爱发电，在维护着一片干净的净土。
