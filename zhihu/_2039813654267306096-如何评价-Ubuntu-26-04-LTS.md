如果你养虾养马的话，不要安装Ubuntu 26.04 LTS。

Ubuntu 26.04 LTS搭载了 GNOME 50 桌面环境，这是第一个完全移除 X11 会话选项的 Ubuntu LTS 版本。

对，仅支持 Wayland。登录界面不再提供 X11 切换选项，GNOME Shell 和 Mutter compositor 已完全删除 X11
后端代码。

Wayland 的输入隔离和屏幕捕获权限控制比 X11 严格得多。

养虾养马搞出来的自动化能力很多都要失效。

Openclaw官方状态："完美兼容 X11，对 Wayland 环境提供实验性支持"。

Openclaw很多功能都要依赖截图的。然而 gnome-screenshot 这种截图工具都是X11的；全局输入模拟则依赖 X11 的 XRecord
扩展，在 Wayland 下无法工作。

Hermes Agent也没好多少。

官方宣称在 v0.9.0 之后的开发版本中添加了初步 Wayland 支持。

说是截图使用 grim（wlroots）/ gnome-screenshot / spectacle；输入模拟使用 ydotool；活动窗口查询使用
Sway IPC / hyprctl（仅支持特定 compositor）。实际上吧，一用一个不吱声。

在 Ubuntu 24.04 中，你在登录界面还可以切换到 X11 来恢复完整的桌面自动化能力。但在 26.04 中，这个选项没有啦。彻底被干掉了。

牛*的。

老老实实继续使用 Ubuntu 24.04 LTS吧。好歹它仍然提供 X11 会话选项，是目前运行 OpenClaw 和 Hermes Agent
桌面自动化功能的最佳选择。
