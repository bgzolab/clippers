强烈推荐 GitHub 大佬tw93的两个开源软件，完美符合我对简洁、优雅、轻量的执念。真正的 Mac 味，respect！

## 1.KAKU——终端

  

![](https://picx.zhimg.com/50/v2-3b2e6d6c984fb3c15f28b6e104a1b09d_720w.jpg?source=2c26e567)kaku终端，fastfetch
花里胡哨查看状态

非常轻量，oh-my-zsh、字体、主题、自动补全都已经一键配置好，还可以多开窗口，接入 ai，有丰富的快捷键。

我曾在 iterm2 上折腾了很久，用下来还是 kaku 更舒服。

GitHub 链接：

[https://github.com/tw93/kaku](https://link.zhihu.com/?target=https%3A//github.com/tw93/kaku)

brew 可一键安装：

    
    
    brew install tw93/tap/kakuku

## 2\. Mole——免费版 cleanmymac

![](https://pic1.zhimg.com/50/v2-60aa39d532220acef86eeb7e30da154a_720w.jpg?source=2c26e567)安装后终端输入
mole 即可开始清理

mole 我真的是用一次爽一次，柠檬清理太冗杂，cleanmymac 要花钱。mole 开源轻量，可以清理磁盘、卸载软件，优化系统 ，status
功能还可可爱爱的。

![](https://picx.zhimg.com/50/v2-c7915a3426e2050581ba6181fd875e72_720w.jpg?source=2c26e567)终端输入
mole status，获得一直可爱小猫

GitHub 链接：

[github.com/tw93/Mole](https://link.zhihu.com/?target=https%3A//github.com/tw93/Mole)

brew 可一键安装：

    
    
    brew install tw93/tap/mole
