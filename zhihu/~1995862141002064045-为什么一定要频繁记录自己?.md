title: 为什么一定要频繁记录自己?
type: archive-web
---

因为可以进行科学长期自我干预，看到个体的趋势和周期性。

用一个学历史的朋友的话讲，就是能用 historiography 的方法论来研究个人发展史。

作为一个做心理咨询/哲学的，大概从8年前开始很系统地记录自己，

每天基本会稳定至少 2000 字左右的日记 / 反思 / 笔记 / 理论构建 （直到近年 LLM 盛行, 自己开始写的少了，但是产出反而多了，因为会把和
LLM 的对话记录都留存下来）。后来发现口述（讯飞输入法或者最近的 OpenAI
家的whisper）也能大幅提升效率，整个自我记录工作流发生过很多升级。到现在大概存了快700万字的“个人民族志”(autoenthnography)了。

最大的体验就是，能对自己的文本集合做知识图谱分析，词云分析，词频统计，时间序列分析，topic modeling，thematic
analysis，discourse analysis + frequent pattern mining，entity/asepct-based
sentiment analysis 等等比较高级的自然语言处理级别分析。

然后就能看到自己在各个年龄段，保持着各种不同的社会角色心理认同，以及价值观和世界模型 (mental model)
在想一个问题的时候究竟小脑瓜里在想什么了。结合现在的 LLM + Claude Code + MCP更是可以做到生成个人周报，月报，年报。

这对于长期习惯养成和技能习得，个人修行，不依赖外界的创伤疗愈，亲密关系发展和修复，认知体系和知识体系搭建都是必不可少的基建。

时长回看过往的记录（还可以在培训员工/做咨询时分享给别人，可以让他人看到自己面临过的困境，以及自己一系列的自我干预和修复过程）能够维持一种很强的自我稳定性和连贯性，对自我觉察（self-
awareness），自我内核搭建都是核武器级别的。
