正在找工作的我写个感受。

两边都在用，不是人格分裂或者吃饱撑的，中国版的会员便宜，首月更有优惠。

在开了会员以后，就能发现中国版的公司，是国内公司，好像废话？并不是，美版的外国公司也有同步过来，但有又国内公司。

然后，之前我误以为美版积累那么多年了，讨论区的质量会高些？其实未必，两边都有高人，也都有坑货。讨论都比较朴素，美版没有用户题解，国内版就有用户题，所以就比较，社会。

总的来说，两边不相伯仲，中国版会员便宜。

但是，[leetcode-cn.com](https://link.zhihu.com/?target=http%3A//leetcode-cn.com)
用 API 登录个人感觉比较难搞，平时用
[leetcode.el](https://link.zhihu.com/?target=https%3A//github.com/kaiwk/leetcode.el)
刷，美版顺利登录但是，如果写中国版就会直接卡死，貌似国内版故意给登录设置了坑？我看过19年早些时间拿 Python
爬自己AC代码的，稍微试了下，略有坑，可能是我自己的问题。

最后，个人觉得要是中国版的要是能用 leetcode.el 刷，我就异常开心了，嗯， VSCode 也有插件，太慢了。
