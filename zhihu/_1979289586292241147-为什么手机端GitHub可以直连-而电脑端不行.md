**评论区出现了不少民科。这个回答继续被点赞的话，我就会把辟谣民科的更多内容更新出来。**

* * *

现在知乎上都是些啥东西啊，用 AI 胡诌的也能获得如此高赞。这方面的互联网谣言、民科是真的多。这整个提问只有一个人提到了正确的原因，那就是访问的域名不同。

一个网站，一个软件，它们在和服务端通信的时候，可能使用不同的域名。例如 Steam 的社区页面通常是非常难以访问的，而商店页面则流畅很多。为什么呢？因为
wall 对不同的域名的屏蔽策略是不同的。  
  
社区是`steamcommunity.com`

商店是 `store.steampowered.com`

在 GitHub 上，不同域名的访问难度也是不一样的。一般公认的是 `raw.githubusercontent.com`难以访问，主站页面会好一些。

这里的`raw.githubusercontent.com`就是呈现文件原始内容的 GitHub 服务使用的域名。例如在
[README.md](https://link.zhihu.com/?target=http%3A//readme.md/)
中的图片等资源加载时就会用到这个域名。所以你可能发现自己勉强能访问仓库页面，但基本无法呈现仓库中的图片。

而 GitHub 移动端，它是不需要加载网页的。它主要调用 API。这里的 API 又是一个域名了，即 `api.github.com`。

这是 `https://raw.githubusercontent.com`的访问情况：

  

![](https://picx.zhimg.com/50/v2-d0083ff15ef00484d196243bffe6ee93_720w.jpg?source=2c26e567)

这是对 `https://api.github.com`的访问：

  

![](https://pica.zhimg.com/50/v2-d700dfc876cba21235d0b119edf40844_720w.jpg?source=2c26e567)

GitHub 主站 `https://github.com` 的访问也较差，可能比
`raw.githubusercontent.com`好一点点。所以你们能用移动端直连，原因仅仅是
`api.github.com`在全国范围都绿，几乎没有受到屏蔽。

* * *

最后再补充一下。为什么你在湖北、四川、重庆这些绿色的地方，似乎也难以访问 GitHub
呢？因为服务器和家庭宽带走的路线不同，一般来讲服务器的网络路线会更通畅一些。且这个测试服务可能在一个省份仅使用了一台服务器不能表现整个省份。但整体而言，你还是能明显看到
`api.github.com`的访问是几乎没有受阻的。
