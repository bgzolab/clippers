首先 macOS 是一个**部分开源** 的系统，我们来看下 macOS 的架构图：

![](https://pic1.zhimg.com/50/v2-7719bcafc4561b66e71c53adc7d20e01_720w.jpg?source=2c26e567)图片来源：https://zh.wikipedia.org/wiki/MacOS

**其中 Darwin（达尔文）这部分是开源的，它是 macOS 的核心和基座** 。

![](https://picx.zhimg.com/50/v2-5c642be98b1ce353cb460b10092d2e4a_720w.jpg?source=2c26e567)macOS
上执行 uname 命令，可以看到 Darwin 内核信息

比如内核部分 XNU 的源代码在这里：[https://github.com/apple-oss-
distributions/xnu](https://link.zhihu.com/?target=https%3A//github.com/apple-
oss-distributions/xnu)。Darwin 其他组件的开源代码也可以在这个网站上找到：[Apple Open
Source](https://link.zhihu.com/?target=https%3A//opensource.apple.com/releases/)。

![](https://pic1.zhimg.com/50/v2-5067a2658a9b531db07aabbee5095de9_720w.jpg?source=2c26e567)

而架构图中 Darwin 之上的部分基本都是闭源的，比如 Aqua（用户界面）、Cocoa（应用框架）、Quartz（绘图层），以及和 Darwin
相关的驱动程序。

我让 Google Gemini 整理了一张线框图，能够更详细地看出 macOS 的开源和闭源部分：

![](https://picx.zhimg.com/50/v2-fb2ab361066e253a2e2198b09a6c6a88_720w.jpg?source=2c26e567)

* * *

不过，不要以为 Darwin 开源了，你就可以基于 Darwin 自由定制操作系统。核心是因为 Darwin 的相关驱动并没有开源，理论上 Darwin
只能在 Apple 自家的硬件上运行。（后面会提到为什么）

当然也有黑苹果这种方式在 PC 上运行 macOS（而非 Darwin），以及
[darling](https://link.zhihu.com/?target=https%3A//github.com/darlinghq/darling)
这样的 Darwin/macOS 模拟器项目（可以运行部分 macOS 应用）。不过都没法在非 Apple 硬件上完美运行 Darwin 或者
macOS（虚拟机不算）。

**更重要的是，macOS 的亮点其实在于 GUI 层和软件生态，和这部分相关的组件都没有开源。** 单纯基于 Darwin
定制操作系统没啥意义（不如直接基于 FreeBSD 定制桌面）。

另外，虽然 macOS 是一个类 Unix 系统，Linux 也是一个类 Unix 系统，但两者还是有不少差异的，之前在
[从程序员角度看，日常开发主力机应该选 macOS 还是
Linux？](https://www.zhihu.com/question/1962130705275397432/answer/1971619210594607361)这篇回答里也介绍过，macOS
和 Linux 的命令重合度大概在 80%-90%，就算 macOS 完全开源，还是需要做一些定制，才能兼容 Linux 上的一些命令和功能。

**如果是想拥有比较好的 GUI 体验，同时又想使用 100% 的 Linux 功能，完全可以选择 Ubuntu 或者 Fedora。**

* * *

当然还有一个更深层次的问题，那就是 macOS 大概率不会整体开源。如果真开源了，乔布斯估计会从坟墓里爬出来。前面也提到过，Darwin 理论上只能在
Apple 的硬件上运行，如果你看过《乔布斯传》，你就知道为什么。

**核心原因是乔布斯贯穿始终的一个理念：端到端一体化，或者叫软硬件一体化。**

乔布斯认为，**最好的产品是“一体的”​，是端到端的，软件是为硬件量身定做的，硬件也是为软件度身定制的** 。正因为此，才使得 Mac
有别于微软（以及之后谷歌的安卓）所创造的环境，Mac 上使用的操作系统只能在自己的硬件上运行，而微软和安卓的操作系统可以在许多不同厂家制造的硬件上运行。

![](https://picx.zhimg.com/50/v2-034c71c3043427c41a1a1cb7337c12f0_720w.jpg?source=2c26e567)《乔布斯传》提到了二十多次“端到端”

比尔盖茨的思路是只做操作系统，然后把操作系统卖给硬件厂商或者用户，让 windows
在更多不同的硬件设备上运行，从而占领更大的市场。而乔布斯则不认同，他认为微软是一家没有品味的公司，虽然比尔盖茨这么做占领了市场，但他创造出的产品称不上伟大。

乔布斯把他的端到端一体化理念，从 Mac 延续到 iPod，再到 iPhone 和
iPad，一次又一次颠覆历史，缔造了伟大的产品。当然，从商业上来说，他也取得了巨大的成功。

如果 macOS 真的彻底开源了，甚至能够在 PC（非 Apple 硬件）上运行，由于软硬件没有达到最佳的适配状态，最终可能会是一个比较鸡肋的结果。**就像
iOS 开源了，能够在安卓设备上跑，那 iOS 可能就不再是 iOS 了。**
