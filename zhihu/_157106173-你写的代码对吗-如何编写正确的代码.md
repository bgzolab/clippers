> **什么快速排序** ？  
> 选取一个元素，将数组分为两部分，一部分小于这个元素，另外一部分大于等于这个元素。然后递归地将两个数组进行快速排序。

## **如何论证程序的正确性**

每当我们写程序， 我们都要问自己一个问题，这样写对吗，边界条件处理了吗？

每当我们有思路的时候，一写就废！怎样正确地代码呢？

不同的程序有不同的论证方式，也有不同的行码思路。本文介绍常用的循环不变量(下文介绍分治，如果有下文的话）。

  

## 循环不变量

以快速排序为例，我们将数组分为如下四个部分：

![](https://pic2.zhimg.com/v2-3e822976792fc0a9ff443c50be38801b_1440w.jpg)

  

  * 绿色的是基准元素，又叫pivot，也就是快排一开始选取的元素。
  * 黄色从 ![start+1](https://www.zhihu.com/equation?tex=start%2B1) 到 ![j](https://www.zhihu.com/equation?tex=j)[1]，这部分小于pivot。注意：本文的区间都是左闭右开。
  * 洋红从 ![j](https://www.zhihu.com/equation?tex=j) 到 ![i](https://www.zhihu.com/equation?tex=i) ，这部分大于等于pivot。
  * 紫色从 ![i](https://www.zhihu.com/equation?tex=i) 到 ![end](https://www.zhihu.com/equation?tex=end) ，这部分数组元素还未处理。

所以当紫色部分长度等于0，那么数组分成了三个部分：pivot，小于pivot，大于等于pivot。

这时候将pivot与j-1交换，那么我们就成功将数组分为了两个部分：一部分小于pivot ，![\[start,
j-1\)](https://www.zhihu.com/equation?tex=%5Bstart%2C+j-1%29) ，一部分大于等于pivot，
![\[j-1, end\)](https://www.zhihu.com/equation?tex=%5Bj-1%2C+end%29)
。（为什么是j-1而不是j，请看下面分解)

然后递归地快速排序这两个部分，就可以实现数组排序。

简单的Python代码如下

    
    
    from itertools import permutations # 这是是为写测试用例
    
    def quick_sort(vec, start, end):
        if end - start <= 1:
            return
        q = partition(vec, start, end)
        quick_sort(vec, start, q)
        quick_sort(vec, q+1, end)
    def partition(vec, start, end):
        pivot = vec[start]
        j = start
        i = start+1
        while i < end:
            if vec[i] < pivot:
                vec[i], vec[j] = vec[j], vec[i]
                j += 1
            i += 1
        vec[j-1], vec[start] = vec[start], vec[j-1]
        return j
    
    def test():
    
        vec = [1, 2, 3, 4, 5, 6, 7, 8]
        for case in permutations(vec):
            case = list(case)
            quick_sort(case, 0, len(case))
            assert case == vec
        
        print('test pass')
    
        
    if __name__ == '__main__':
        test()

程序的主要两个函数是partition和quick_sort。

quick_sort简单直观。重点是partition函数。我们如何论证它是正确的？或者论证它是错误的呢？实际上面的代码有错误，请问错在哪里？

## 分析

循环不变量，登场！

**循环不变量**[2]**是指程序的循环(for, while)在执行完成一个迭代**[3]**(iteration)的时候，程序中保持不变的性质。**
正因为不变量的存在让我们可以知道循环结束(termination)的时候某些性质保持不变，从而得到我们想要的。

在快速排序的例子中，上图的四个数组部分就是我们的循环不变量。

我们要在循环开始前和循环结束时，保证不变量成立。

![i](https://www.zhihu.com/equation?tex=i) 作为常见循环下标的索引。所以它从
![start+1](https://www.zhihu.com/equation?tex=start%2B1) 一直到
![end](https://www.zhihu.com/equation?tex=end) 。

partition一开始的时候，pivot选取第一个元素（可以选取其他位置的元素，具体实现类似），

![j](https://www.zhihu.com/equation?tex=j) 一开始的值应该是多少？根据上图，我们可以知道
![start+1](https://www.zhihu.com/equation?tex=start%2B1) 到
![j](https://www.zhihu.com/equation?tex=j)
表示小于pivot的数组。那么一开始的时候，while循环没有开始，小于pivot的数组部分应该是0，加上区间是左闭右开，那么
![j=start+1](https://www.zhihu.com/equation?tex=j%3Dstart%2B1) 。而上面的代码是
![j=start](https://www.zhihu.com/equation?tex=j%3Dstart) ，所以这是第一个错误。

循环开始前，下面的条件成立，

  * ![\[start+1, j\) = \[start+1, start+1\)](https://www.zhihu.com/equation?tex=%5Bstart%2B1%2C+j%29+%3D+%5Bstart%2B1%2C+start%2B1%29) ，包含0个元素，满足上图。
  * ![\[j, i\) = \[start+1, start+1\)](https://www.zhihu.com/equation?tex=%5Bj%2C+i%29+%3D+%5Bstart%2B1%2C+start%2B1%29) ，包含0个元素，满足上图
  * ![\[i, end\)](https://www.zhihu.com/equation?tex=%5Bi%2C+end%29) 为还没有处理的数组元素，满足上图

所以循环不变量在循环开始前成立。

当循环结束的时候， ![i=end](https://www.zhihu.com/equation?tex=i%3Dend) ，那么
![\[start+1,j\)](https://www.zhihu.com/equation?tex=%5Bstart%2B1%2Cj%29)
小于pivot， ![\[j, end\)](https://www.zhihu.com/equation?tex=%5Bj%2C+end%29)
大于等于pivot。这时候我们将pivot和j-1交换，那么我们成功将数组分为两个部分： ![\[start,
j-1\)](https://www.zhihu.com/equation?tex=%5Bstart%2C+j-1%29) 小于pivot，
![\[j-1, end\) ](https://www.zhihu.com/equation?tex=%5Bj-1%2C+end%29+)
大于等于pivot，并且下标为 ![j-1](https://www.zhihu.com/equation?tex=j-1)
的元素等于pivot。我们只需将 ![j-1](https://www.zhihu.com/equation?tex=j-1) 返回，然后递归地对
![\[start, j-1\)](https://www.zhihu.com/equation?tex=%5Bstart%2C+j-1%29) 和
![\[j, end\)](https://www.zhihu.com/equation?tex=%5Bj%2C+end%29)
进行快速排序即可实现对整个数组排序。所以我们应该将 ![j-1](https://www.zhihu.com/equation?tex=j-1)
从partition返回，而不是将j返回。（这是第二个错误）

  

论证了循环开始前和循环结束时，那么具体的循环怎么写呢？

**简单来讲就是编写循环的代码保证迭代结束时，不变量成立。**

细心的读者就会发现这就是数学归纳法啊！100%正确。

  * 在循环开始前，不变量成立，对应数学归纳法的基本情况成立。
  * 循环迭代的时候，保持不变量成立，对应数学归纳法里面的证明当 ![k-1](https://www.zhihu.com/equation?tex=k-1) 成立时， ![k](https://www.zhihu.com/equation?tex=k) 也成立。
  * 当循环结束时， 循环不变量成立，程序正确。

这种对应关系，也点出了我们如何编写循环来得到正确的程序。

**循环代码要做的事情：假设** ![k-1](https://www.zhihu.com/equation?tex=k-1)
**成立，编写相应的代码保证** ![k](https://www.zhihu.com/equation?tex=k) **成立。**

以partition举例，根据上文，我们已经将 ![j, i](https://www.zhihu.com/equation?tex=j%2C+i)
正确初始化，那么编写的循环就是迭代时，在vec[i]小于pivot的时候，将vec[i]与vec[j]交换位置。然后将 ![j
+=1](https://www.zhihu.com/equation?tex=j+%2B%3D1) ， ![i +=
1](https://www.zhihu.com/equation?tex=i+%2B%3D+1) ，那么迭代结束时， ![\[start,
j\)](https://www.zhihu.com/equation?tex=%5Bstart%2C+j%29) 小于pivot， ![\[j,
i\)](https://www.zhihu.com/equation?tex=%5Bj%2C+i%29) 大于等于pivot，这样子编写的代码保证了
![k](https://www.zhihu.com/equation?tex=k) 成立。

正确的代码为

    
    
    from itertools import permutations # 这是是为写测试用例
    
    def quick_sort(vec, start, end):
        if end - start <= 1:
            return
        q = partition(vec, start, end)
        quick_sort(vec, start, q)
        quick_sort(vec, q+1, end)
    def partition(vec, start, end):
        pivot = vec[start]
        j = start+1
        i = start+1
        while i < end:
            if vec[i] < pivot:
                vec[i], vec[j] = vec[j], vec[i]
                j += 1
            i += 1
        vec[j-1], vec[start] = vec[start], vec[j-1]
        return j-1
    
    def test():
    
        vec = [1, 2, 3, 4, 5, 6, 7, 8]
        for case in permutations(vec):
            case = list(case)
            quick_sort(case, 0, len(case))
            assert case == vec
        
        print('test pass')
    
        
    if __name__ == '__main__':
        test()

## 总结

**首先我们要知道算法的思路，然后在程序编写时，通过分析确定一个循环不变量(命题），接着初始条件设置正确(当**
![k=1](https://www.zhihu.com/equation?tex=k%3D1)
**时命题成立），编写代码保证循环不变量在迭代后成立（即在** ![k-1](https://www.zhihu.com/equation?tex=k-1)
**成立的前提下，保证** ![k](https://www.zhihu.com/equation?tex=k)
**也成立），最后在循环结束做最后的处理获取我们想要的结果。**
