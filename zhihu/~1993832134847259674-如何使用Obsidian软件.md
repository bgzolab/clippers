Skills，作为本地的笔记管理软件，结合能直接读取本地文件的 AI 工具，效果简直起飞。

才发布几天，GitHub 上 Star 数九已经破 4 k，本次他更新了 3 个有关于 Obsidian 的技能，分别是：

  * [json-canvas](https://link.zhihu.com/?target=https%3A//github.com/kepano/obsidian-skills/tree/main/skills/json-canvas)：生成 Canva 无限画布，你可以根据某个指定主题生成可视化的白板。
  * [obsidian-bases](https://link.zhihu.com/?target=https%3A//github.com/kepano/obsidian-skills/tree/main/skills/obsidian-bases)：生成.Base 文件的过滤器和公式，对不熟悉 Obsidian 数据库的人有福了。
  * [obsidian-markdown](https://link.zhihu.com/?target=https%3A//github.com/kepano/obsidian-skills/tree/main/skills/obsidian-markdown)：写出 Obsidian 风格的 Markdown （内链、属性等），这样你就完全不用自己搞明白 Obsidian 的格式，可以完全专注于创作。

直接根据读书笔记生成可视化的白板，对我这种需要视觉学习的人简直是刚需，也可以制作成每个概念单独的「卡片笔记」，AI
帮助实践「卡片笔记写作法」，当然你也可以去发现更多能你需要的 Skills。

可能很多人会问，为什么要用 Qwen Code 而不是 Claude Code，主要原因有三：

  * 一是我觉得 Qwen Code **开源免费** ，算是国内版 Claude Code 平替，CC 太贵。
  * 二是 Qwen Code 对**中文支持友好** ，对话输入输出中文减少了很多认知负担。
  * 三是 Qwen 系列模型算是国内比较强的，**直接`/auth` 认证**，我也懒得太折腾。

如果已经安装过 Qwen Code ，直接下载对应的 Skills 放在 `.qwen/skills` 文件夹下就 OK 了。

## 如何使用？

  1. 安装 Qwen Code：下载 Node 之后，打开终端输入命令：`npm install -g @qwen-code/qwen-code@latest`
  2. 安装完成后启动：`qwen --experimental-skills`
  3. 然后就可以直接开始对话了，Qwen Code 会自动调用相关 Skills。
