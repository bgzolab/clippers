因为 Ubuntu 蠢，仅此而已。说详细点就是，Ubuntu
本意是好的，它将应用程序崩溃（非正常退出）通知给你了，应该是想告诉你你有个程序出错崩溃了，但是提示文字却是“内部错误”。

也就是说，我开发的程序自己没处理好一些情况导致进程崩了，然后 Ubuntu 帮我背了这个锅。

  

你们自己展开所谓**内部错误** 的弹窗，里边的进程有几次会是 Ubuntu 自己开发的软件的或者是系统的核心进程？几乎没有。我记得用 Ubuntu
那会儿如果关机前没结束 Chrome 直接重启，那么启动以后马上就会弹出一个内部错误，错误进程就是 Chrome 的。

  

**卡死崩溃** 不知道你指的是什么？桌面是有可能卡死的，通常是驱动之类的原因。像 KDE 曾经因为 Intel 驱动不稳定天天崩溃还撕过逼。

不过我通常都是 Gnome 用户，卡死之类的半年遇不到一次。如果遇到了，切入一个 TTY 重启一下 DM 就行了，它会自动重启图形服务器。
