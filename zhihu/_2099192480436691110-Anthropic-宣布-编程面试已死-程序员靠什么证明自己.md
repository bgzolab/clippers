我看了deepseek公司的招聘要求，供大家参考：

1在开源社区上保持活跃：请在简历中附上 GitHub 主页，我们看重的不是 star 数，而是 commit 记录 ——
无论是对大型开源项目的贡献、长期维护的个人项目，还是热心帮人排查 issue 的历史，都是极好的证明。

2在知名开源项目（如 CPython / PyTorch / LLVM / Linux 内核等）有实质性贡献，或长期维护有影响力的个人开源项目。

3大型项目经验

4动手能力强、见到问题就想修：喜欢用自动化消灭重复劳动；有 homelab、硬件改造、3D 打印、芯片逆向、安全攻防、古法配环境等折腾经验。

5具有开阔的架构视野，能针对系统不足主动提出改进方案并推动实现。

6有跨层问题排查能力：能从表象深入到运行时、系统库乃至硬件层面定位根因。

7我们在寻找的是那种对计算机系统（从机房里的铁疙瘩到内核再到上层框架）有广泛好奇心、动手能力极强的系统工程师（Hacker /
Geek）：各种领域都懂一点、在不少领域懂很多，遇到问题不挑活儿，撸起袖子就能解决。

  
8在高性能计算相关赛事（如 SC/ASC/ISC 和 PAC 等）或算法竞赛（NOI/IOI 和 ICPC 等）中取得优异成绩。

  

9在 OSDI/FAST/VLDB 等高水平系统会议发表过论文，或者有同等水准的工程影响力

10熟悉 C / C++ / Rust / Python 之一，具备优秀的设计能力、极强的动手和工程能力以及代码质量意识。
