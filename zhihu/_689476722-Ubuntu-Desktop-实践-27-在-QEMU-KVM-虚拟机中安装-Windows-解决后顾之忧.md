从这一篇开始，我们来研究虚拟机。对于现代社会来说，虚拟机早就不是一个陌生的概念了。各种虚拟机软件也是百花齐放，比如
Bochs、Qemu、KVM、Hyper-V、Xen、VmWare、Virtual Box 等，个个名字都如雷灌耳，其中有不少还是开源和免费的。

那么我在 Ubuntu 中折腾虚拟机，主要有两个目的。一是看一下这些虚拟机在 Ubuntu
下运行的效果怎么样，界面没不美观呀？速度快不快呀？用起来方不方便呀？二是使用 Ubuntu 的时候，还是有一些 Windows
下的软件没有替代方案，比如微信、迅雷等，那么在虚拟机中安装一个 Windows 系统，也可以解决一些后顾之忧。

这一篇，我们先来看一下 QEMU/KVM。

QEMU 本来就是一个非常强大的虚拟机软件，在我前面的文章[使用 GCC 和 GNU Binutils 编写能在 x86 实模式运行的 16
位代码](https://zhuanlan.zhihu.com/p/683649987)中就使用过 QEMU 来运行过
FreeDos。对于喜欢自己写操作系统内核的人来说，更是少不了 QEMU。QEMU
可以完全以软件的形式模拟出一台完整的电脑所需的所有硬件，甚至是模拟出不同架构的硬件，在这些虚拟的硬件之上，可以安装完整的操作系统。在 Ubuntu 中搜索
QEMU 软件包，可以得到下面这些结果：

![](https://pic3.zhimg.com/v2-feeca325c499ce35ed2ea991525f5930_1440w.jpg)图1、QEMU
可以模拟不同架构体系的电脑

可以看到，我安装了 qemu-system-x86。QEMU 的运行模式如下图：

![](https://pic1.zhimg.com/v2-f06bb2b101ab70d3bdb1c2fda9d5d318_1440w.jpg)图2、QEMU
的运行模式

很显然，这种完全以软件模拟硬件的形式虽然功能强大，但是性能难以满足用户的需要。模拟出的硬件的性能和物理硬件的性能相比，必然会大打折扣。为了提高虚拟机软件的性能，开发者们各显神通。其中，最常用的办法就是在主操作系统中通过内核模块开一个洞，通过这个洞将虚拟机中的操作直接映射到物理硬件上，从而提高虚拟机中运行的操作系统的性能。如下图：

![](https://pic4.zhimg.com/v2-f45da1a98ae73ab93c205aef325ed4ef_1440w.jpg)图3、KVM
的运行模式

其中 KVM 就是这种加速模式的典型代表。在社区中，大家常把 KVM 和 Xen
相提并论，但是它们其实完全不一样。从上图可以看出，使用内核模块加速这种模式，主操作系统仍然占主导地位，内核模块只是在主操作系统中开一个洞，用来连接虚拟机和物理硬件，给虚拟机加速，但是虚拟机中的客户操作系统仍然受到很大的限制。这种模式比较适合桌面用户使用，主操作系统仍然是他们的主战场，不管是办公还是打游戏，都通过主操作系统完成，客户操作系统只是按需使用。至于
Xen，则完全使用不同的理念，比较适合企业级用户使用，桌面用户就不要轻易去碰了，具体内容下一篇我再讲。

其实 VirtualBox 也是采取的这种内核模块加速的模式。

KVM 和 QEMU 是相辅相成的，QEMU 可以使用 KVM 内核模块加速，而 KVM 需要使用 QEMU 运行虚拟机。如果使用`man
kvm`查看`kvm`命令的帮助文档，会发现它运行的命令其实是`qemu-system-x86_64`。如下图：

![](https://pic4.zhimg.com/v2-037948dc2d2ca28b800dee82492dfa13_1440w.jpg)图4、使用
man kvm 查看帮助

那么问题来了，kvm 内核模块究竟是由哪个包提供的呢？其实，自从 Linux 2.6 开始，kvm 就已经被加入内核了。

对于桌面用户来说，有一个好用的图形化界面也是很重要的。QEMU 和 KVM 自身不带图形界面的虚拟机管理器，我们只能使用 `virt-
manager`。只需要使用 `sudo apt-get install virt-manager` 即可安装该软件。运行 `virt-manager`
的效果如下图：

![](https://pic1.zhimg.com/v2-5aeb57aa12962e64bc1faf4b64bf4896_1440w.jpg)图5、Virt
Manager 图形界面

使用图形界面创建和管理虚拟机还是舒服多了。我新建了一个虚拟机，给它分配了 8 个 CPU 核心，分配了 8G 内存，显卡默认选择
QXL，然后给它安装了一个精简版的 Win10 系统，如下图：

![](https://pic3.zhimg.com/v2-194809817ee29fb95ea7800357d8298e_1440w.jpg)图6、虚拟机中的
Win 10

然后在虚拟机中的 Win 10 中安装一个微信和迅雷，就可以解决我们日常工作中的一些问题了。如下图：

KVM 还有很多高级玩法，比如显卡透传，可以直接让虚拟机中的系统使用物理显卡。

可以这么说，如果没有 Virtual Box 的话，那 QEMU/KVM 的组合绝对是桌面用户的首选。至于 Virtual Box，我们后面也会尝试到。
