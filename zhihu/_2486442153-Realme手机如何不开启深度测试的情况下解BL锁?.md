三、解锁流程

  

1、电脑上把刚刚下载的文件解压，打开，放在C盘 C:Windows\System32 目录下，如图；

![](https://pica.zhimg.com/50/v2-00d6831cc83665b58e89c91e82838934_720w.jpg?source=2c26e567)

2、Win+R打开cmd窗口，输入adb reboot bootloader / 打开深度测试APP，点击开始深度测试（两个方法皆可）；

![](https://picx.zhimg.com/50/v2-feded88c226eb2687cf01cbfe8672d08_720w.jpg?source=2c26e567)

3、手机重启看到 DEVICE STATE ：locked，说明此时 BootLoader 处于锁定状态；

![](https://pic1.zhimg.com/50/v2-1b0216c0431cc05fd3172b80d99cdff7_720w.jpg?source=2c26e567)

4、开始解锁：

连接电脑后，在电脑cmd窗口输入 fastboot flashing unlock或者 fastboot flashing unlock_critical

![](https://pic1.zhimg.com/50/v2-c027e357f45b6c158c7b2207c12151ff_720w.jpg?source=2c26e567)

5、询问是否解锁，确认解锁就使用音量键选择 UNLOCK THE BOOTLOADER，"否"则选择 DO NOT UNLOCK THE
BOOTLOADER (此时后悔还来得及)，电源键确认；

![](https://picx.zhimg.com/50/v2-36911a598d52aa858cff54f27f226cf4_720w.jpg?source=2c26e567)

6、此时，手机会重启进入 recovery 模式格式化 data 分区，然后自动开机，恭喜你，手机已解锁成功。

  

  

四、查看解锁状态

  

1、Win+R打开cmd窗口，输入adb reboot bootloader /打开深度测试APP，点击开始深度测试；（两个方法皆可）;

  

2、再次进入 Fastboot 模式，可看到 DEVICE STATE ：unlocked;

![](https://picx.zhimg.com/50/v2-f49f617ddac82ba77d5d1a568f183835_720w.jpg?source=2c26e567)

3、说明此时 BootLoader 处于解锁状态，此时你就可以使用 fastboot flash [分区名] [文件路径]刷入文件了;

  

4、玩机刷入 TWRP在 FastBoot 模式.将 twrp.img 刷入 recovery 分区. (twrp 需要能人进行编译）;

  

5、fastboot flash recovery twrp.img；

  

6、音量键选择 recovery mode，按电源键确认，进入 TWRP （recovery模式）。

  

  

五、致命科普

  

1、什么是解锁 BootLoader？

BootLoader是在操作系统内核运行之前运行，可以初始化硬件设备、建立内存空间映射图，从而将系统的软硬件环境带到一个合适状态，以便为最终调用操作系统内核准备好正确的环境。在嵌入式系统中，通常并没有像BIOS那样的固件程序，因此整个系统的加载启动任务就完全由BootLoader来完成。

  

2、什么是root 权限？

root权限，就是手机取得了最高权限，例如计算机的管理员，可以任意的修改手机软件及手机的一些功能。

  

3、怎样使用 adb 和 fastboot ？

这里我们用到的不多：

adb reboot bootloader 重启进入，bootloader模式

fastboot flashing unclock 解锁bootloader模式

fastboot flash recovery xxx 刷入文件到recovery分区或boot分区

fastboot flashing lock 上锁bootloader模式

  

4、怎样使用 TWRP 吗？如何进行双清、卡刷等刷机操作？root后能做什么？

①TWRP使用 双清：主页->清除->滑动恢复出厂设置（此项操作会清除你的 data 分区除内置存储外的文件）.

②格式化 Data：主页->清除->格式化 Data ->输入 yes （此项操作会清除你的 data 分区全部文件，含内置存储.

③卡刷：主页->安装->浏览到自己需要的卡刷包，点击，滑动刷入.

④备份：主页->备份->选择自己需要备份的分区->滑动备份.

⑤还原：主页->还原->选择需要还原的版本->选择需要还原的分区->滑动还原.

⑥高级：主页->高级->文件管理;主页->高级->终端命令行可以输入终端命令.

⑦root后我们可以修改 ：软件 、用户数据 、系统 、或刷入三方系统。（三方系统需要适配）
