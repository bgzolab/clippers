Omarchy 是一个帮你配置好了 Hyprland 的、做好了美化的 Arch Linux，并且直接提供了一个 6G 多大小的安装 ISO 镜像，连安装
Arch Linux 的麻烦都帮你解决了。

对于我这样的懒人，属于一站式装逼神器了。我现在就是在用 Omarchy 答题。如下图：

![](https://picx.zhimg.com/50/v2-bda1e3c30f32a8f7b2aac594b853a0ba_720w.jpg?source=2c26e567)图1、使用
Omarchy 自带的 Chromium 上知乎答题

Omarchy 这几天比较火的原因，是因为他的创始人 David Heinemeier Hansson (DHH) 最近在大力号召大家使用 Linux，而
DHH 本身的号召力又比较大，所以最近 YouTube 上有很多宣传 Omarchy 的内容。DHH 这个人比较神奇，他是 Ruby On Rails
框架的作者，他的“约定优于配置”的思想，影响了后面很多 Web 开发框架的理念。

过去十几年 DHH 一直使用 Mac 和 Textmate（Mac 上的一个编辑器）编写代码，早年甚至还给 Mac 拍过广告。

这次转投 Linux 是因为不满苹果 App Store 30% 抽成的政策，以及对库克领导的 Apple 缺乏创新而感到失望。

他所在的公司 37signal 还是 Hyprland 的白金级赞助商。

听说DHH自从从Mac迁移到linux后，Rails不上心了，赛车也不玩了，书也不写了，整天折腾Linux美化，相继推出Omakub和Omarchy两大力作。

所以，Omarchy 就是 Arch Linux + 平铺式桌面管理器 + 美化定制的集大成之作，妥妥的装逼神器。

下面具体来讲一下使用体验。

**一、安装**

安装起来很简单。直接到 Omarchy 的官网
[omarchy.org](https://link.zhihu.com/?target=http%3A//omarchy.org/) 下载 ISO
镜像，烧录到 U 盘，就可以像安装其它 Linux 发行版一样安装了。安装的过程中不需要联网，安装过程很快，5
分多钟就安装完了。唯一需要注意的是，它会占用整个硬盘，所以别试着用它来装双系统免得把你的 Windows 搞没了。

对于英文用户来说，安装完就可以直接使用。但是对于中文用户来说，还得设置一下 Locale 和输入法。这个要参考 Arch Linux 的 Wiki。如下图：

![](https://picx.zhimg.com/50/v2-fbe8d10925f9f74d2a4dabb2122b0633_720w.jpg?source=2c26e567)图2、安装中文
Locale

所以我学会的第一个快捷键和第二个快捷键就是 `Super+B` 打开浏览器和 `Super+Enter`
打开终端，然后它们平铺起来的样子，就是上图这样。都是经过了美化的，效果挺不错。

至于中文输入法，系统已经预装了 fcitx5，我们只需要再装上 fcitx5-pinyin、fcitx5-pinyin-
zhwiki、fcitx5-configtool 就可以了。这属于 Arch Linux 的知识了，就是在终端中使用 `pacman`
安装就行。哦，对了，`yay` 命令和 AUR 也是直接可以用的。

虽然提倡全键盘操作，但是其实键盘和触摸板也是可以用的，把鼠标移动到顶栏的右侧，找到输入法指示器的图标，右键，点配置，就可以配置输入法了。联网也一样，鼠标点吧，懒得记快捷键。

\-------- 补充一点内容 -------

前面说过，大神的技术选型是可以作为我们的学习方向的，比如 NeoVim、Btrfs，比如这里面的 Web 应用程序、TUI 应用程序。

除此之外，我觉得还有一个地方很值得我们学习，那就是对系统的备份和恢复。在 Omarchy
中，每次当你更新系统的时候，它会先对系统做一个备份，也可以说是做一个快照，然后再开始更新软件包。这个快照的功能，可能是使用了 Btrfs
文件系统的特性。但重点是，它做完快照之后，还把它加入到了启动菜单中。当我们每次启动电脑的时候，我们可以选择是不是恢复到某一个快照。

这种技术我觉得还是挺值得我们学习一下的。
